# 用它的时机

- 要**写**那张假图的 annotation 或节点（`use_figma`）；
- 要**核**自己刚写的东西落没落（回读）；
- 要判**图有没有被改**、**被谁改**、**改在哪一版**。

> **前置**：官方 `figma-use` skill 是**调 `use_figma` 前的必读**（本仓通过 MCP 资源 `skill://figma/figma-use/SKILL.md` 取）。
> 本 skill 是**项目侧补充**，不重复它 —— 两者一起用。

# 一、三条不可协商

1. **整组读 → 只改目标 → 整组写 → 回读整组。**
   `node.annotations = [...]` 是**整组替换**：追加一条，会把同组里别人的条目**静默吃掉**。
2. **读源用 `labelMarkdown || label`；写时每条只给一个字段。**
   ⚠️ **字数／sha 这类计数必须写明走哪条通路，且前后走同一条。** 两条通路对 **md 型**条目取到的**串本身就不一样**（Plugin API 给 **md 源** ／ REST 只给**派生形** `label` —— 派生形会掉 `- ` 前缀、把空行折成双空行）⇒ **不只长度不同**（实测同一条 `896` vs `891`，全页 `43,305` vs `42,715`）⇒ **跨通路比会得到假的「别人覆盖了我」**。
3. **写后必回读**。**连回读都做不了时，不许说「已落」** —— 那等于没背书。（工具断了、连不上，都属于这种。）

# 二、坑表（全部为实测）

| 现象 | 因 | 怎么办 |
|---|---|---|
| 某条 annotation **被我写没了** | 判 `labelMarkdown !== undefined` 取源 ⇒ `label` 型条目的 `labelMarkdown` 是**空串**（不是 undefined）⇒ 取到空串、静默覆盖成空 | 用 **`labelMarkdown \|\| label`** |
| 每回写一次，串里**多一层 `&amp;`** | annotation **读出是转义形、写入按字面存** | 读→写之间**先 unescape**；回读**报 `&` 计数**（正常＝0） |
| 写入报 `Only one of label or labelMarkdown should be given` | 同一条给了两个字段 | 整组替换前**逐条归一**（按它原本的类型回写）—— 否则连没改的邻居也会让写入失败 |
| 往实例里加子节点报 `Cannot move node…` | **实例不接受子节点** | 改**母件**（会连带别的线实例化它的组）或画**组级 overlay**（`parent=` 它所在的组、`layoutPositioning="ABSOLUTE"`） |
| 设 `visible=false` 后**那个节点找不到了** | 在**实例子节点**上它是**移除**，不是藏，**不可逆**（实例又不接受 `appendChild` ⇒ 补不回来） | 要「藏」就**用 overlay 盖** |
| overlay 一加不透明填充，**下层文字被糊住** | overlay 在卡之上 | 二选一：**无填充**借下层文字显形／**自带文字**并把下层那份藏掉 —— 而「藏」**在实例内只能用 overlay 盖，别动 `visible`**（上一行那条坑：在实例子节点上 `visible=false` 是**移除**、不可逆；**非实例节点上它可逆**） |
| master 上挂了 annotation，**帧内实例读不到** | annotation **不随 master 传 instance** | 注必须挂在**帧内节点**上 |
| 下游按名取到**错的节点** | 同名多实例 | 新节点**按用途区分命名** |
| 图与包里的说法对不上，但**看不出谁改的** | 在同一段里**既有我的写入、也有别人的** | 见 §五「分层对拍」 |
| 脚本报 `Invalid selector: unexpected character` | `query` 的**属性值不能带空格／非 ASCII**（`[name=FIXED TEMPLATE]`、`[name=丢弃未保存的改动]` 都不合法；`[name=topbarActions]` 合法）。**且整段脚本回滚** | 别用选择器找带空格 / 汉字的名字 —— 用 `findAllWithCriteria({types}).filter(n => n.name === X)` |
| 那个文本节点**按名找不到了** | **「名字＝内容」的那类**文本节点在其 `name` 上**跟着 `characters` 走**（这类在本文件居多数，**但不是全部** —— 也有 `unimpl`／`note` 这种**名≠内容**的） | 按 **id** 找；或**新旧两串都试** |
| 快照报「无差异」，而**明明动过** | 拿 REST 的**顶层 `x`/`width`** 当几何 —— **REST 不给**，只给 `absoluteBoundingBox` ⇒ 几何**全 `null`** ⇒ 对拍**恒绿**（2026-09-21 实测 119/119 全 null，徽标 974→1027 与行宽 232→285 都没被看见） | 读 **`absoluteBoundingBox`**；并给快照加**非空转自检**（几何非空 ＝ 0 ⇒ **退 2**，fail-closed） |

# 三、写：标准动作序列

0. **记住你不是唯一写者** —— 那张画布可能同时被别人（含**非本机 Claude 会话**，如 GPT）改。见 §五。
1. **开工前存快照**：`annotation 清单（宿主 × 条数 × 字数 × sha）` ＋ `每个宿主的 x/y/w/h` ＋ `子树节点数`。（**字数／sha 要记下走的是哪条通路** —— 见 §一2。）
2. **整组读**目标宿主的 annotations。
3. 只改目标条目，**其余按原字段类型原样回写**。
4. 写。
5. **回读整组** ＋ `&` 计数（§四）。
6. **收工分层对拍**（§五）—— 这一步在收工前做，不是等推送。

# 四、验：回读判据

逐项报，**别只报「对上了」**：

- **整组条数**不变（除非有意增删）；
- **邻居条目逐字未变**（这是「整组替换吃掉邻居」的探针）；
- **`&` 计数 = 0**（＝无二次转义），**报原始数字，不写「通过」**；
- **几何未变**（被改宿主与其容器的 x/y/w/h）；
- **页节点数 Δ ＝ 我新建的节点数** —— ⚠️ **按「建的每一个节点」算，不是按「建的每一个控件」算**（一个 chip ＝ frame ＋ text 两个节点；这条 2026-09-21 已实测把人算错一次）。

> **判据要与实物同源**：回读要**读回实际串**比，**不要拿记忆里的串**去比。**「逐字未变」也必须同通路**（见 §一2）—— 拿 REST 的字数与 Plugin API 的比，会报出假的「被覆盖」。
>
> ⚠️ **证伪要覆盖签名里的每一种字段** —— 只种一种（例如只改 `t`）会漏掉**整类**变化。
> **实测（2026-09-21）**：几何一个字段都没种 ⇒ 几何对拍**空转**却报绿，一整天没人发现。

# 五、断：图有没有被改 / 被谁改 / 改在哪一版

## 5.1 时间戳怎么用
- **`lastModified` 单向可信**：**前进 ⇒ 一定写过**；**没前进 ⇒ 不能反推没写**。
  ⚠️ **理由不是「分钟粒度」** —— 观测值**带秒**（`02:39:12Z`／`05:13:51Z`／`05:18:34Z`）⇒ **不是分钟量化**（「分钟粒度」那句是从别处搬来的，与实测不符，已撤）。
  **真正的理由**：**REST 读的是「已保存版本」，刚做的写入会滞后**（见 §5.2）。
- **文件级 `version` 字段不是「动没动」的判据**（2026-09-21 受控实测：写了三处 annotation 而它一字未变）。
- ⚠️ **`lastModified` 可以晚于「当前版本的 `created_at`」** ⇒ 有改动没落进版本快照 ⇒ **两者不是同一个量**。
- ⚠️ **`/versions` 的 `[0]`（最新一条）是「活的」＝ 当前内容；真正的冻结从 `[1]` 起。**
  `[1]` 冻结的是「**`[0]` 打开前的那一刻**」⇒ **`[1]` 的 `created_at` 可以早于它自己的内容**
  （**2026-09-21 实测**：`[1]` 标 `04:45:48Z`，内容却是 `05:13Z` 那笔写入的产物）。⇒ **拿 `[0]` 当 before 恒绿。**
  ⇒ **用某版本做 before 之前，必须先做「区分性预探针」**：拿一个你**确知改过**的节点在两版对读，**必须读到不同**；**读不出不同 ⇒ 不许**用该版本做 before。（**别用 `created_at` 当「那一刻的冻结」的判据** —— 它是槽位开启时刻，不是内容时刻。）

## 5.2 定窗口 ＋ 读过去态（**查"谁在什么时候改了什么"的正路**）
- `GET /v1/files/:key/versions` ⇒ 每条 `{ id, created_at, label, description }`。**用 `created_at` 钉事件窗口。**
- `GET /v1/files/:key/nodes?ids=<ids>[&version=<id>]` ⇒ **能读那个版本里这些节点的内容**（annotation 在内）⇒ **把「两处读数不同」变成「哪一版、什么时候、变了哪几处」**。
- ⚠️ **version id 只能从 `/versions` 列表里抄**，按形似手打会 404。
- **全宿主差值对拍**是量「爆炸半径」最快的办法（2026-09-21 实测一次就把范围收成「恰好 N 个宿主」）。

## 5.3 ⚠️ 分层对拍 —— **裸的「前后对拍」分不开「我改的」与「别人改的」**
因为**我自己那一笔必然出现在对拍里**。⇒ 按「我有没有打算动它」分层：

| 对拍对象 | 用什么核 | 变了说明什么 |
|---|---|---|
| **我打算动的宿主** | **对我自己的写入记录**（**内容**逐字对拍，**且同通路** —— 见 §一2；长度/哈希**不够**——等长替换看不出） | 不对 ⇒ **要么别人覆盖了我、要么我写歪了**，两种都要报 |
| **我没打算动的宿主** | **对开工前快照** | 变了 ⇒ **一定是第三方写的**（无歧义探针） |

> **一句话：我碰过的用「我的记录」核，我没碰的才用「快照」核。**
> 只用后者，会漏掉「**我写的被换掉**」—— 2026-09-21 实测发生过两次，而且**当场读到了却没发现**。

> ⚠️ **「我改动的容器子树」要把母件本身算进去。**
> 动**母件**时波及面 ＝ **母件 ＋ 它的全部实例**（实例内子节点的 id 形如 `I<inst>;<child>`）。
> **实测**：改一个母件、波及 6 个实例 ⇒ 要排除的是 **7 棵**子树；**漏掉母件那一棵就少算一层**。
> 同族还有一条：**「位于我移动过的容器之内」的宿主**也要算进去 —— 只按「子树里含我碰过的宿主」去排除，会漏掉它（2026-09-21 实测被误报成第三方写入）。

> ⚠️ **另一条射程坑：「与基线无差异」的语义是「基线覆盖到的那些没变」，不是「没有新东西」。**
> 拿**基线里的宿主清单**去对拍，**新增的宿主天然不在遍历面里**（2026-09-21 实测：新加一条 annotation 的那个宿主，回归探针照旧报「变 0」）。
> ⇒ 报这句话时**必须带出「基线里有哪些」**；**新增物要用另一条按区域枚举的探针覆盖**。

## 5.4 认写者：跨会话转录全文检索
- 若写者**可能是一个 Claude 会话**，可搜转录：**先证正例**（搜一个你确知存在的串），再搜目标串。
- ⚠️ **0 命中的作用域要如实限定**：只能得出「**不在检索面内**」；**本机之外的通路、以及人在 App 里手改，都不产生转录** ⇒ **证不了「不存在」**。
- 同类时间巧合（某会话 `lastActivityAt` 落在窗口内）**是并列，不是证据**。

# 六、不要做

- **不要把说明画进画面主体** —— 说明走 annotation；画面里只放「入口控件本身」。
- **不要为了让间距好看去挪别人范围内的东西** —— 判据是**能读、不重叠**，不是间距整齐。
- **不要发明新术语／新记号**；已有记号（`⚑UNIMPL（GAP-ED-NN）`／`⚐UNVERIFIED`／`⏸BLOCKED`）。
  ⚠️ **别把「未实现但没号」降成 `⚐UNVERIFIED`** —— 画布自己的定义块把两者分开（`⚑UNIMPL ＝ 未实现（挂 GAP-ED 号）`／`⚐UNVERIFIED ＝ 未核`），且**画布上两种写法都在用**（既有「没有 GAP 条目 ⇒ `⚐UNVERIFIED`」，也有 **`⚑UNIMPL …, GAP-ED 号待实现线补`**）。
  ⇒ **知道「没实现」就仍标 `⚑UNIMPL` 并写明号待补**；**只有「不知道实没实现」才落 `⚐UNVERIFIED`**。
  ⚠️ **这些记号的权威定义与使用落在画布（Figma 文件）里** —— **别把"仓里搜不到"读成"体系没人用"**。
  （⚠️ 仓里**能**搜到这几处记号 —— 那几处是**本 skill 对它们的引用**，不是「有人在用」。**权威面在画布上。**）
- **不要「元素在」就当「读得出是入口」** —— 本文件同一个病犯过两次（2026-09-21：下拉在但太小／框了但不像控件）。
- **不要在一次改动里既动母件、又动别人的投影组** —— 母件被别的组实例化，改它＝改别人的画面。
- **不要把「取不到数」读成「没差异」** —— 脚本的退出码要留**第三态**（见 §八）。
- **不要在"以为自己在清理"时删东西** —— 本族栽过：**引用锚 ≠ 内容锚**，一条 annotation 可以引着权威页、同时携带页上没有的东西。**任何「可删」判断，动手前必须先有全量快照。**

# 八、边界

- **本仓是公开仓**（规则见仓根 `CLAUDE.md`）⇒ **本 skill 及此后新增的文件**里**不写**：fileKey、页面／节点 id 清单、Notion 页面 id、凭据。**要用就在会话里现取。**
  ⚠️ **别把这条读成"本仓已全仓体检"** —— 它是对**新增内容**的要求，**不是**对仓内既有文件的断言。
- **退出码三态**沿用本仓已有约定（见 `tools/check_doc_hygiene.py` 首部）：
  **`0`＝干净 ／ `1`＝有发现 ／ `2`＝没能真正检查**（取不到凭据、网络失败、一个都没匹配到）。
  ⚠️ **`2` 必须自成一档且 fail-closed** —— 否则「没检查成」会被读成「干净」。
