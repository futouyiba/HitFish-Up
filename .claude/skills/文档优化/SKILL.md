# 文档优化总流程

按需调用以下 Skill，默认顺序如下：

1. `清理文档`：诊断历史残留、状态漂移、矛盾、死链和权威漂移。先报告，获批准后再改。
2. `通俗化编辑`：整理主线、结构、主谓关系、术语和事实边界。
3. `中文优先`：中文优先，首次术语用“中文（English）”，保护技术标识。
4. `去AI腔`：最后清理模型腔、套话和不自然节奏，不覆盖前一步的术语和标识。

用户只要求其中一项时，只调用对应 Skill。完成后检查链接、结构、术语、事实、公式、代码标识和裸英文。
