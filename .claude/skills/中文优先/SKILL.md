# 中文优先技术文档编辑

把说明文字改成中文。保留必要的英文技术标识，但不要让普通说明句裸写英文。

## 规则

1. 标题、段落、列表和表格说明默认用中文。
2. 必须保留的术语首次出现写成“中文（English）”，后续可只写中文。
3. 保留代码块、反引号内容、字段名、枚举值、变量名、公式、路径、链接、命令、产品名和外部原文。
4. 普通英文说明翻译成中文；不要为了提高中文比例翻译技术标识。
5. 优先复用仓库术语表，不自行创造同义译名。
6. 不改变事实、数值、公式、链接目标或技术语义。

## 快速检查

- 每个说明性标题和句子都有中文；
- 裸英文只出现在代码、标识、正式名称或外部原文中；
- 主要英文术语首次出现时有中文解释；
- `Unknown`、`Reject` 等枚举值未被翻译成新的枚举；
- 代码块、字段、路径和链接未被改动。

## 处理方式

用户要求改写时直接编辑文件。只发现问题时报告文件、行号、原文和中文建议，不改文件。
