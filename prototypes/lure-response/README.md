# 路亚响应原型

这些脚本是方案推导的可执行探针，不是生产实现，也不是生物学标定或中鱼概率模型。

## 方案 C 第 3 步

`presentation_state_probe.py` 将实际呈现转换为按猎物类型分开的状态解释，同时保留原始支持 map。它实现了 handoff 中的候选规则：

- 速度条件确认移动与低位移，并在阈值之间保留已确认状态；
- 记录移动段、停留起点、近期移动后停留及三秒关系窗口；
- 区分水面/近底事实、世界运动缺失、正常下沉与带持续侧翻的失衡样下沉；
- 缺失、缺口、乱序、同刻冲突、重复记录、换装配来源和新抛投不互相混淆；
- 同一呈现可以同时给多个猎物类型输出状态，但不生成响应或重复收益。

阈值集中在脚本顶部，均为待评审的设计假设。脚本中的 `support_map` 只读透传，不参与状态判定，也不会因状态变化被改写。

运行：

```bash
python3 prototypes/lure-response/presentation_state_probe.py
```
