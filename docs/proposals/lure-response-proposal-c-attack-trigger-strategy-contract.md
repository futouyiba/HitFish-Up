# Proposal C｜攻击诱因的策略职责与准入边界

状态：Working Closure / Candidate。不是 Current，不是生产参数。

## 1. 结论

“攻击诱因”保留，但职责必须收窄。

它只表达：

> 在目标已经被解释成某类可接受猎物的前提下，当前猎物状态是否额外提高了捕食出手倾向。

例如：

```text
受伤样状态
逃逸样状态
失衡 / 虚弱样状态
```

可以作为候选的正向诱因。

它不负责：

```text
领地防御
攻击性
烦躁 / 驱赶
护巢
调查 / 好奇
```

这些如果未来要做，应属于 Feeding 之外的独立 Interaction / motivation family，再由更上层组合；不能为了“低摄食意愿时也能咬”而全部塞进 Feeding 的攻击诱因。

## 2. 它购买什么玩家策略

攻击诱因存在的主要价值不是增加真实感，而是购买：

```text
低摄食意愿
→ 普通稳定呈现不容易跨过出手门槛
→ 玩家可以尝试具名的高诱发猎物状态
→ 用更高的局部诱因换取一次出手机会
```

也就是：

> 正常摄食口不足时，仍存在“反应口”式的策略空间。

但“反应口”只有在诱因伴随自然代价时才成立为策略。

## 3. 不允许免费诱因

攻击诱因增加时，不额外发明统一的“刺激惩罚”。

优先让代价由已有机制自然产生：

```text
更快的逃逸运动
→ 追赶负担上升

突然破坏近期运动预期
→ 可能产生预测困难

为了制造强动作而持续绷线、机械操控
→ 风险顾虑上升
```

因此同一个“强刺激”在不同鱼情下结果不同。

示例：

```text
低摄食意愿 + 高活性 + 低警惕
→ 强诱因可能很划算

低摄食意愿 + 低活性
→ 诱因收益可能被追赶负担吃掉

低摄食意愿 + 高警惕
→ 粗暴、机械的诱发操作可能被风险顾虑抵消
```

这才形成策略，而不是固定按钮。

## 4. 攻击诱因不是动作强度

禁止直接：

```text
转向越大 → 攻击诱因越高
加速度越大 → 攻击诱因越高
抖动次数越多 → 攻击诱因越高
```

原因：

- 同一动作对不同猎物解释意义不同；
- 一次逃逸动作可能同时包含加速、转向、停顿，直接求和会重复奖励；
- 高频操作不能因为事件次数无限累积；
- 很强的动作也可能完全不构成有意义的猎物状态。

正确边界仍是：

```text
实际呈现
→ 按猎物解释当前状态
→ 得到攻击诱发强度
→ 转成 Response 正向贡献
```

## 5. 第一版不需要完整状态识别

不要求建立复杂轨迹模式识别或机器学习系统。

第一版可以只准入少数能低成本识别、又有明确策略价值的具名状态，例如：

```text
Escape-like / 逃逸样
Distressed-like / 受伤挣扎样
Vulnerable pause / 逃逸后的虚弱停顿（若后续验证成立）
```

每个状态必须满足：

1. 玩家能通过可理解的操作较稳定地产生；
2. 它对特定猎物解释有明确意义；
3. 它不是单个原始运动量的别名；
4. 它有自然的收益与代价；
5. 它不会因为事件数量而无限加成。

如果某状态无法低成本、稳定识别，则不应仅因“现实里可能存在”进入第一版。

## 6. 与食物价值、摄食意愿的关系

三者职责不同：

```text
食物价值
→ 这个目标本身有多值得吃

摄食意愿
→ 当前整体愿不愿意为了食物出手

攻击诱因
→ 当前这个猎物状态是否额外推动一次捕食出手
```

因此：

- 攻击诱因不能把 Reject 食物救活；
- 攻击诱因不能永久替代低摄食意愿；
- 攻击诱因只能提供有限的局部正向贡献。

这也是保留 effect-size budget 的原因：避免“反应口”成为绕过整个食物价值和摄食状态的万能解。

## 7. 与非摄食咬击的边界

如果未来要表达：

```text
护巢攻击
领地驱赶
攻击性咬击
烦躁 / irritation bite
调查后啄咬
```

它们不应继续扩充 Feeding 内的攻击诱因。

原因：这些行为不是“这个猎物状态更值得捕食”，而是不同的行为动机。

更合理的拓扑是：

```text
Feeding response
Defense / Territorial response
Investigation response
...
→ Interaction composition
```

当前仓内尚未找到这些非 Feeding family 的完整 Current Contract，因此这里只冻结边界，不补造其算法。

## 8. 当前最小主体公式

在 Feeding 内：

```text
出手余量
= 食物价值
+ 攻击诱因
- 追赶负担
- 风险顾虑
- 摄食意愿对应的出手门槛
```

“预测困难”目前只作为待证明的局部代价，不再默认属于必选主体项。

攻击诱因的存在要求：

```text
它必须改变某些真实策略排序；
并且收益不能脱离已有代价单独增长。
```

## 9. 当前设计决策

保留：

- 攻击诱因作为 Feeding 内有限的、猎物状态条件下的正向贡献；
- 用于购买“低摄食意愿时仍可能通过反应口式呈现获得机会”的策略；
- 只允许少量具名、可生产、可验证的状态；
- 诱因的代价优先由追赶负担、风险顾虑以及可能的预测困难自然产生。

不保留：

- 通用“动作越大越诱发”；
- event count 累积；
- 把攻击性、领地、防御、烦躁等非摄食动机塞进 Feeding；
- 新造一个统一“刺激成本”去平衡免费加成。

## 10. 待讨论

1. 第一版究竟准入哪 1~3 个具名猎物状态；
2. “逃逸后短暂停顿 / 虚弱”是否值得作为独立诱发状态；
3. 各猎物 family 是否共用一套诱发强度标尺；
4. 非摄食咬击是否需要在后续版本建立独立 Interaction family；
5. 攻击诱因的最大作用量应如何与当前摄食意愿范围配平。
