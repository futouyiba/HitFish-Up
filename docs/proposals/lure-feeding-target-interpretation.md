## 1. 主体结构

实际呈现提供猎物线索，线索组合支持一个或多个猎物类型；运动与情境在这些支持范围内形成呈现状态；鱼针对各份猎物呈现分别评价食物价值与行动代价。对同一呈现、同一评价点的完整替代摄食响应，本候选采用最强响应主导的 max 聚合；主导响应不反写目标解释。

三个对象分别保存：

| 对象 | 内容 | 不包含 |
|---|---|---|
| 实际呈现 | 感知到的轮廓、裙丝、附肢、反光、运动、接触与相对水层事实 | 商品名称直接指定的 TargetId |
| 猎物解释 | 类型、支持它的线索组合、该类型条件下的状态与匹配支持 | 鱼因为喜欢某食物而选择的解释 |
| 鱼的响应 | 食物偏好、大小、该呈现状态的价值、行动要求与能力比较 | 用最高响应反过来决定目标身份 |

这不是静态外形先唯一分类、运动再打分的强制流水线。一个线索组合可以包含动态线索；关键是一个解释必须获得自身需要的支持，其他条件不能无限补偿缺失的必要线索。

## 2. 本轮采用的设计约束

- 少数有意义的线索可以提供猎物支持，不要求解剖学完整逼真。
- 单目标和多目标支持都合法；不把所有饵设为模糊，也不把商品类别与食物类型绑定。
- 明显鱼形米诺仅因贴底不能获得甲壳类支持。
- Tube、带裙丝组合可以同时提供饵鱼与甲壳类线索，再由呈现状态区分。
- 蛙类呈现包括水面停留，不规定只有运动才有效。
- 运动不合适可以削弱该解释下的呈现、或暴露状态覆盖不足，不自动改换类型。
- 感知事实缺失与已知无某特征分开；无支持不等于非食物，更不等于整个 Interaction 输出零。
- 目标解释不读取食物偏好或当前行动能力；同一作用不得以不同名字重复结算。

## 3. 案例依据与设计假设

职业钓手的第一人称经验支持多种呈现用途：

- [Shaw Grigsby 的 Tube 案例](https://www.bassmaster.com/how-to/news/be-a-better-tube-fisherman/)：螺旋下落用于伤鱼模拟，落底慢拖用于小龙虾模拟，同一抛投可以切换用途。
- [Mark Davis 的 Swim Jig 案例](https://majorleaguefishing.com/bass-pro-tour/mark-davis-dives-into-the-diversity-of-the-swim-jig/)：同类裙饵与拖尾组合用于小龙虾、鲱形饵鱼、蓝鳃太阳鱼模拟。
- [Andy Montgomery 的方舌 Crankbait 案例](https://www.strikeking.com/en/learn/tips/tips-from-our-pros/andy-montgomerys-three-favorite-cold-water-baits)：将方舌 Crankbait 与 Jig 用于小龙虾模拟。

这些是策略用途证据，不等于直接测得鱼脑分类。下列线索字段、门槛、状态样本和价值参数全部为本项目的人工探针假设，不能借上述案例获得生物学标定身份。蛙类规则本轮主要承接对话中认可的设计要求。

## 4. 线索支持：先定义哪些解释有依据

代码中的输入都是有明确量纲或归一化口径的感知事实：

| 字段 | 含义与口径 |
|---|---|
| r | 主体长宽比 L/W |
| filaments | 可见轮廓中细长柔性丝状部分的占比，0～1 |
| front_pair / rear_pair | 主体前端／后端成对突出部分的伸展尺度除以 L；各自有几何标记口径 |
| flash | 指定已发生短窗内的接收者侧明暗变化对比，0～1 |
| oscillation | 指定短窗内周期性横摆的振幅除以 L 后限幅到 0～1 |
| impact | 指定近期接触事件的接收者信号强度，按固定参考量归一化到 0～1 |
| bottom / surface | 离底间距／低于水面的距离，均除以 L |
| L、v、vertical_v | 主体感知长度、当前运动总速、当前向下为正的垂直速度，m 与 m/s |
| j、age | 指定近期速度变化事件幅度及距今时间；已知无事件使用 j=0、age=0 |
| d、v_away、V | 当前距离、径向远离速度、行动代价能力尺度 |

这些不是“像虾程度”等最终语义评分。主体、附肢和柔性部分须有上游几何或材料标记；光学、运动和接触短窗须有明确时间及接收者信号记录。代码从已解析的事实起算，尚未实现 Mesh／物理源到上述感知量的提取，也没有承诺这些新增短窗事实已获生产 Cue 契约支持。缺失不能补零。

本探针采用以下充分支持组合。表中 AND 是一条组合内条件同时成立；OR 表示有其他充分支持组合。它们不是全体自然猎物的必要定义。

| 猎物类型 | 本轮支持组合（满足任意一行即可） |
|---|---|
| 小鱼 | r ≥ 3 且 filaments ≤ 0.30 |
| 小鱼 | r ≤ 2.5 且 oscillation ≥ 0.50 |
| 小鱼 | flash ≥ 0.50 |
| 小鱼 | filaments ≥ 0.40 |
| 甲壳类 | filaments ≥ 0.40 |
| 甲壳类 | front_pair ≥ 0.50 |
| 甲壳类 | r ≤ 2.5 且 impact ≥ 0.50 且 bottom ≤ 0.50 |
| 蛙类 | r ≤ 2.5 且 rear_pair ≥ 0.50 |

丝状线索只需提供支持，不必附带完整虾体。较圆、横摆并触底的物体可以支持鱼与甲壳类；长身米诺即使发生同样触底事件，也不满足“短粗主体＋接触”的甲壳类组合。该门槛是待攻击的设计限制，不声称所有米诺绝无甲壳类线索。

每条组合返回 True / False / Unknown。已知有一项不成立即本组合不支持；若无 False 但必要事实缺失，则 Unknown。某类型有任一 True 即 Supported；否则仍有 Unknown 则保持 Unknown；全部已知不成立才为 NoSupport。新增规则不会因为数量更多而自动叠加数值奖励。

## 5. 类型内部评价呈现状态

获得类型支持后，只与该类型内的状态比较，不在所有食物之间继续用统一距离竞争。

运动向量：

```text
u = v/L
e = (j/L) × exp(-age/1秒)
w = vertical_v/L
x = [ln(1+u), ln(1+e), w]
```

u、e、w 使用每秒体长为单位的数值，进入对数前对应每秒一体长的参考量。三个共用容差为 [0.65, 1.0, 1.0]。每个状态按下表中心计算标准化平方距离；涉及水层时再加入相应标准化层差。

| 类型 | 状态 | u | e | w | 层中心与容差 | 激励倍数 g |
|---|---|---:|---:|---:|---|---:|
| 小鱼 | 游动 | 6.25 | 0 | 0 | 本例不限制底层／水面距离 | 1.865 |
| 小鱼 | 短促动作后停留 | 0 | 4.549 | 0 | 同上 | 1.517 |
| 小鱼 | 停留 | 0 | 0 | 0 | 同上 | 1.00 |
| 小鱼 | 下落 | 2 | 0 | 2 | 同上 | 1.60 |
| 甲壳类 | 近底慢移 | 0.50 | 0 | 0 | bottom=0.15，容差0.60 | 1.60 |
| 甲壳类 | 近底停留 | 0 | 0 | 0 | 同上 | 1.30 |
| 甲壳类 | 近底快速位移 | 5 | 5 | 0 | bottom=0.50，容差0.60 | 1.80 |
| 蛙类 | 水面游动 | 1.50 | 0 | 0 | surface=0，容差0.50 | 1.60 |
| 蛙类 | 水面停留 | 0 | 0 | 0 | 同上 | 1.30 |
| 蛙类 | 短促动作后水面停留 | 0 | 3 | 0 | 同上 | 1.80 |

```text
D²(t,k) = 各运动维度的标准化平方差之和 + 可选的该状态层差
k* = 该类型内 D² 最小的状态
Q_t = exp(-D²(t,k*)/2)
```

同一类型内状态距离完全并列时保留 AmbiguousState；所有状态 D² > 9 时返回 UnsupportedState。二者不自动变成零响应或切换到另一目标。

Q 是本套状态样本上的匹配支持，不是普遍“越逼真越好”系数。不同状态有不同 g；这些值须由策略需求进一步检验。本轮小鱼游动与抽停倍数沿用前篇示例结果的近似值，便于核对，不是新增实证。

## 6. 食物价值、摄食动机与行动代价

每个已支持且状态已解析的目标分别计算：

```text
F_t = exp(-0.5 × (ln(L/L_pref,t)/0.70)²)
S_t = Q_t  # 当前探针的数值支持代理，仅使用一次
B0_t = S_t × p_t × F_t × g(t,k*)
B_t = H × B0_t

q = d/1秒 + v_away
E = 0.50 × (q/V)²
U_t = max(0, B_t-E)
R_t = U_t/(1+U_t)
```

H 是已解析的当前基础摄食动机，参与激励与代价的权衡；不改变目标解释或运动能力。其参考倾向、时段偏移、近期摄食负荷的具体推导及历史边界见[Feeding motivation](lure-feeding-motivation.md)。代码将 H 设为必要输入，缺失保持未决。

S_t 表示对这份猎物解释的激励保留比例，不是分类概率。当前以状态 Q 单次代理；连续的外形支持尚未闭合，未来完整联合 S 必须替换该代理，不能再乘一次 Q。g 表达状态本身的激励价值，不是第二份“像不像”。

本例 p 与 L_pref 分别为：小鱼 [1.00,0.08m]，甲壳类 [0.60,0.04m]，蛙类 [0.70,0.06m]。均为人工假设，缺失则 Unknown。

本轮撤掉旧版对所有类型共用的 M 运动奖励，改为各类型状态下的条件激励；因此旧版结果不应混入本版对比。此处乘法只表达本候选局部关系，不晋升为全体响应必须采用的固定流水线。

V 仍是代价换算尺度而非最大游速。大小不另增匿名惩罚；任务仍限当前直线局部几何，加速、转向与耐力约束未闭合。R_t 也仍非实测咬口概率或生产 captureRetention。

## 7. 实际执行结果

探针运行了 13 个受控案例，以下均明确固定 H=1 作为结构对照；商品名称仅为阅读标签，代码不读取它来决定类型。另有摄食动机派生及联算见对应专题。

| 案例 | 支持的类型 | 本轮解析结果 |
|---|---|---|
| 长身米诺持续游动 | 小鱼 | 游动，R=0.6183 |
| 同米诺贴底慢拖并接触底部 | 小鱼 | 低速落在“停留”样本附近，R=0.4427；不新增甲壳类 |
| 同米诺短促动作后停留 | 小鱼 | 抽动后停留，R=0.5995 |
| 能力降低的米诺持续游动 | 小鱼 | R=0.3958 |
| 能力降低的米诺抽停 | 小鱼 | R=0.5865，保留操作排序反转 |
| Tube 下落 | 小鱼、甲壳类 | 小鱼“下落”匹配1；甲壳类状态超范围，整体未闭合 |
| 同 Tube 贴底慢拖 | 小鱼、甲壳类 | 甲壳类“近底慢移”匹配1；小鱼“停留”匹配0.823；聚合R=0.4427 |
| 短粗横摆主体＋触底 | 小鱼、甲壳类 | 两份解释保留，max聚合R=0.4427；未用主导响应定类 |
| 蛙形线索在水面静止 | 蛙类 | 水面停留，R=0.4709 |
| 同线索在水面游动 | 蛙类 | 水面游动，R=0.5188 |
| 同线索位于深水静止 | 蛙类 | UnsupportedState，不自动变成小鱼 |
| 无任一支持组合的输入 | 无已支持类型 | UnsupportedTarget，无数值结果 |
| 必要丝状事实缺失 | 存在未决支持 | ResolutionIncomplete，无数值结果 |

Tube 慢拖时甲壳类状态匹配更强，并不保证它的摄食响应最高：若假设这条鱼更偏好小鱼，小鱼解释的 R 仍可能更高。这正说明不能用 max(R_t) 反推类型。

本轮还检查：食物偏好变化不改变解释及状态；缺失食物偏好保持未决；一条组合内已知 False 不被另一缺失值变成 Unknown。

这些案例是设计集，支持组合与状态中心由同一任务人为设置，不能称为识别准确率或盲测验证。

## 8. 完整替代摄食响应采用 max

本候选将 S_t 定义为对应解释的激励保留比例，而不是互斥分类概率。因此，这里的 t 是同一呈现能够支持并激活的不同食物评价路径，不是对一个隐藏真实类别的概率猜测。

采用的设计规则为：同一候选、同一局部评价点，共享同一机会且后果高度重叠的完整替代摄食响应，由最强的一条主导。

```text
每个支持分支：
B_t = H × S_t × p_t × F_t × g_t
U_t = max(0, B_t-E_t)
R_t = U_t/(1+U_t)

全部必要分支闭合后：
R_feeding = max_t R_t
```

这个 max 是局部响应候选规则，不是实测鱼脑运算，也不是多个独立咬口事件的概率并集。不推广到多感官融合、空间密度、不同鱼的群体混合或所有行为 Mode。

### 为什么先选 max

假定两份完整响应分别是0.60和0.40：

| 聚合 | 得到的数值 | 额外引入的含义 |
|---|---:|---|
| max | 0.60 | 完整替代路径由最强响应主导 |
| 求和后 clamp | 1.00 | 仅因多一种解释就获得额外增强 |
| 独立事件并集 | 0.76 | 假设两次独立响应事件；本模型没有该依据 |
| 等权平均 | 0.50 | 假设两种解释各占一半；支持程度并未提供该概率 |

max 不按分支数量加分；复制同一分支不会增强结果，增加一个较弱分支也不会压低或抬高原结果。多功能饵的优势可以是适配不同鱼、状态与操作，而不是每增加一个可解释类型就在同一时刻叠加奖励。

若多种线索本身产生新的联合效果，应有明确的联合解释与响应依据，不能靠重复枚举食物类型制造 bonus。若后续证据需要真实混合、竞争或解释概率，再替换对应聚合结构。

### 先完整计算，再比较结果

不能分别取最大的 S、p、g，再拼成一条不存在的强分支。H、支持、食物价值、状态价值与行动要求都在各分支内闭合，之后才比较 R_t。

例：同一 Tube 近底慢拖，H=1，其他物理及感知输入固定。

| 人工食物偏好配置 | 小鱼分支 R | 甲壳类分支 R | R_feeding | 主导响应 |
|---|---:|---:|---:|---|
| p_fish=1，p_crust=0.60 | 0.4427 | 0.3586 | 0.4427 | 小鱼路径 |
| p_fish=0.30，p_crust=1 | 0.1791 | 0.4875 | 0.4875 | 甲壳类路径 |

两行的支持组合、状态及匹配强度完全相同。改变的是响应权衡，不是把饵重新分类。“主导响应”仅为 Explain，不能拿它设置 TargetId、改写感知事实或驱动另一轮偏好筛选。

相同最大值可以保留多条主导路径；不为输出一个名字强制打破并列。所有已闭合路径为零时输出已解析的零响应，目标支持和 Mode eligibility 不因此消失。

### Unknown 不能被 max 吃掉

- 任一仍可能成立的类型支持为 Unknown：ResolutionIncomplete。
- 已支持路径的状态、价值、能力或动机未闭合：ResolutionIncomplete。
- 无已支持类型且支持检查完整：UnsupportedTarget，不当作确认非食物。
- 全部已支持路径已闭合：Resolved，输出 R_feeding 与各分支解释。

Tube 下落仍有一条未覆盖的甲壳类状态，本轮保持未闭合。不能把它填零，也不能直接忽略后取小鱼分支。max 本身不替代类型排除依据或状态覆盖。

### 验证范围

更新后的探针运行原13个呈现案例，并执行聚合语义检查：重复路径不增益、弱路径不稀释、并列保留、全零正常输出、非法数值拒绝、未知支持或未解析分支阻止输出。还核对食物偏好变化只改变主导响应，不改变支持与状态。原五个动机派生联算场景继续通过。

这是结构检查与人工设计集，不是对 max 生物学真实性或体验质量的验证。当前局部匹配、状态激励与任务代价仍是候选；“局部 R 可聚合”不等于完整生产 captureRetention 已闭合。

## 9. 当前边界

支持门槛与最近状态切换可能造成不连续；尚未做连续化或多参数稳健性验证。支持组合也未覆盖所有小鱼、甲壳类和蛙类线索，表中 NoSupport 不能外推为生物学排除。

蛙类前提仅覆盖本轮成对后部突出线索，尚未涵盖所有蛙饵轮廓；甲壳类与鱼类还有大量未覆盖呈现。新增维度或规则须能购买具体策略区分，不能按每个商品增一条规则。

这轮确定的是可解释的主体方向，并提供了一版明确规则与可运行条件评价。感知信号生产、广泛证据、完整攻击任务与生产接入仍未完成。多分支聚合已有 max 候选，尚需策略反例与玩法验证；若分支实际表示互斥认知概率，不能套用此规则。
