# 路亚目标解释：外形、运动到局部响应的可执行探针

日期：2026-10-22  
状态：候选计算模型。所有样本中心、容差、食物偏好及权重组合均为人工设计假设；没有生物学标定。  
前篇：[黑鲈局部计算案例](lure-feeding-response-bass-worked-case.md)。

## 1. 新补出的计算

此前直接给定“小鱼目标”。本篇补上有限字典内的联合解释：从明确的感知几何和运动事实生成目标权重，对每个目标计算局部响应，再按权重合成。

输入到局部 R 的计算已可执行，不再使用空的 selectTarget / selectCurve 函数。覆盖范围仍有限：本篇不实现 Unity Mesh 到接收者信号、感知可见性或图像识别，也不实现完整时序操作、其他行为 Mode、生产 captureRetention。输入必须来自已经解析的感知事实，不能用饵商品类型代替。

## 2. 输入与特征

沿用前篇静水、无遮挡、同一局部评价点和功能能力尺度 V。当前目标运动沿远离鱼的方向；代码另保留径向速度 v_away，用于与运动总速 v 区分。

| 输入 | 明确含义 |
|---|---|
| L、W | 同一感知几何口径的主体长、宽，单位 m |
| A | 突出主体的附肢最大伸展长度，单位 m；确定无附肢为 0 |
| h | 该主体到局部底面的距离，单位 m |
| v、v_away | 当前运动总速、径向远离速度，单位 m/s |
| j、a | 已记录的指定近期速度变化事件幅度及距今时间 |
| d、V | 当前目标距离与鱼的行动代价能力尺度 |

主体与附肢需要几何标记或上游可重放的解析口径；不是从商品名称填写“像虾程度”。本探针接收这些几何值，尚未建立自动几何分割。感知姿态、遮挡、尺寸估计不确定性暂固定，不假设 Unity 原始包围盒天然等于鱼看到的外形。

计算五个联合特征：

```text
r = L / W
b = A / L
z = h / L
u = v / L
e = (j / L) × exp(-a / 1秒)
x = [ln(r), b, ln(1+z), ln(1+u), ln(1+e)]
```

大小既参与相对运动解释，也在后续参与大小偏好；两者解释不同后果。运动解释使用总速，行动代价使用远离速度，不把两者混为一个量。

## 3. 有限目标字典

字典以外形与运动共同定义样本。以下全部为探针锚点，不声称是真实猎物的典型值。

| 目标解释 | 呈现样本 | r | b | z | u（每秒体长） | e（每秒体长） |
|---|---|---:|---:|---:|---:|---:|
| 小鱼 | 持续游动 | 4 | 0.05 | 2 | 6.25 | 0 |
| 小鱼 | 短促运动后停留 | 4 | 0.05 | 2 | 0 | 4.549 |
| 小鱼 | 已知无近期动作的停留 | 4 | 0.05 | 2 | 0 | 0 |
| 甲壳类 | 近底慢移 | 2 | 0.70 | 0.15 | 0.50 | 0 |
| 非食物 | 一个紧凑、无附肢、近底静止物的样本 | 1.2 | 0 | 0.15 | 0 | 0 |

非食物只有这个明确支持的局部样本，不是“所有其他东西”的兜底。小鱼也不只允许表中三种状态；目前只是尚未覆盖其他状态。超出覆盖范围应请求新依据或返回不支持，不能据此宣称某种真实运动不是小鱼。

这些是目标呈现样本，不是按商品 SKU 配最终响应。跨鱼种复用字典是本探针的成本约束假设；不同感觉能力带来的解释差异尚未验证。

## 4. 联合匹配与解释权重

把表中各行按同一变换得到中心 mu。五维容差共用：

```text
sigma = [0.35, 0.25, 0.80, 0.80, 1.00]

D²(t,k) = sum_i [ (x_i - mu(t,k,i)) / sigma_i ]²
K(t,k) = exp(-D²(t,k)/2)
S(t) = sum_k K(t,k) / n(t)
w(t) = S(t) / sum_s S(s)
```

t 为目标类型，k 为该类型的呈现样本。每个类型先按样本均值形成支持，再在类型间归一化；本例类型先验相等、类型内部样本权重也相等。这两种相等都是明确假设。

取均值避免简单把小鱼的三个样本相加，使它仅因行数更多就获得三倍支持。增加不同状态仍会改变类型内部的分配，不能将复制样本或新增样本当作无影响操作；后续需要显式状态权重时再设计。

w 是本模型有限字典内的解释权重，未校准为真实认知概率。没有把弱匹配样本直接提升为可靠识别：

- 任一必要感知输入或目标食物评价缺失，返回 Unknown。
- 如果所有样本均 D² > 9，返回 Unsupported，不输出 R。
- 有明确输入、落在覆盖范围但解释模糊时，保留多个权重。不能直接挑鱼最爱吃的那个解释。
- 本探针的覆盖阈值 9 是设计取值，尚未标定。

匹配使用的是外形、运动与离底情境的共同关系；没有先分别计算一个外形加分和一个运动加分，再假定它们总能相互补偿。对数域的平方距离仍然是一个具体结构假设，可能被反例否定。

## 5. 接入食物评价与行动代价

各目标分别计算，沿用前篇公式：

```text
M = 1 - exp(-(v/0.25 + (j/0.50) × exp(-a/1秒)))

F_t = exp(-0.5 × (ln(L/L_pref,t)/0.70)²)
B_t = p_t × F_t × (1 + M)

q = d/1秒 + v_away
E = 0.50 × (q/V)²
U_t = max(0, B_t - E)
R_t = U_t/(1 + U_t)

R = sum_t w_t × R_t
```

| 目标 | p_t：本例食物偏好 | L_pref |
|---|---:|---:|
| 小鱼 | 1.00 | 0.08 m |
| 甲壳类 | 0.60 | 0.04 m |
| 明确的非食物解释 | 0 | 此项不参与价值，代码保持统一字段 |

甲壳类偏好 0.60 是人工假设，不是大口黑鲈食谱证据；非食物的零为明确的该解释下无摄食价值，不是缺失值默认零。改变偏好不改变目标解释权重。能力变化也只改变行动代价。

这里的加权和是一种明确的、待验证的解释不确定性处理：对互斥目标解释各自的完整局部结果取模型内期望。不是多感官独立联合，也不是 Mode 相加。不能将这条公式直接推广为 Current 的跨 Mode 聚合规则。

R_t 和 R 都是局部探针输出，尚非完整生产 retention。先算每个 R_t 再平均；不能先平均食物价值再通过非线性映射，二者一般不等价。任一有权重的目标评价缺失时，返回 Unknown，不能跳过该项或重新归一化剩余目标。

目标匹配中的运动负责“像哪种目标呈现”，M 负责“已解释目标上的运动激励”，q 负责“行动要求”。三者必须分别有依据；不能因用了不同名字就宣称不会重复计算。本篇只声明其假设含义，尚未从实证识别这三条作用。

## 6. 已执行结果

所有数据均为 Development 探针，不是盲测或识别准确率评估。

| 案例 | 小鱼权重 | 甲壳类权重 | 非食物权重 | R |
|---|---:|---:|---:|---:|
| 小鱼形持续游动，正常能力 | 0.9989 | 0.0010 | 0.0002 | 0.6179 |
| 同外形抽动后停留，正常能力 | 0.9981 | 0.0011 | 0.0007 | 0.5988 |
| 小鱼形持续游动，能力降低 | 0.9989 | 0.0010 | 0.0002 | 0.3952 |
| 同外形抽动后停留，能力降低 | 0.9981 | 0.0011 | 0.0007 | 0.5858 |
| 甲壳样本近底慢移 | 0.0009 | 0.9931 | 0.0060 | 0.3812 |
| 非食物样本静止 | 0.0005 | 0.0060 | 0.9935 | 0.0018 |
| 模糊外形慢移 | 0.2139 | 0.7233 | 0.0627 | 0.3171 |
| 同一模糊外形加快游动 | 0.6322 | 0.3564 | 0.0114 | 0.4998 |

模糊外形两行均为 L=0.08 m、r=2.7、b=0.35、h=0.04 m、d=0.20 m、已知无近期事件。仅 v 从 0.04 改为 0.50 m/s，V=1。它们展示运动确实参与目标解释，未通过人工切换 TargetId 获得结果。

前四行保留了原有能力变化后的局部操作反转。解释权重由呈现决定，能力和偏好不反过来替鱼挑选解释。

还执行了扰动小鱼外形、超范围外形、必要字段缺失、非法宽度和食物评价缺失的检查。归一化与输出范围检查通过。超范围返回 Unsupported、缺失返回 Unknown；均无数值 R。

非食物样本出现约 0.0018 的摄食响应，来自相似度模型仍分给食物解释的微小权重，不是非食物解释自身有摄食价值。这是明确的模型误判能力和局限；不能用最终 clamp 隐藏。如果产品要求某种直接负证据绝对排除食物解释，需要定义对应规则，不能把所有非典型呈现都设为硬负例。

## 7. 配置与仍需攻击的地方

新增的是共用目标呈现字典、共用容差与食物偏好；没有增加每个饵 × 每条鱼 × 每个动作的最终响应表。但参数数量、样本中心及容差的证据依据仍未解决，不能据此宣称配置成本已受控。

同样的五个特征必然产生同样的权重。木棍与小鱼形饵若在本输入上完全一致，模型无法区分；是否值得增加材质、闪光或细部动作，须由需要区分的策略案例决定。

近底小鱼、游动甲壳类、其他食物类型、浑水造成特征不确定、直接身份线索与情境线索冲突等尚未覆盖。没有根据少数原型推广否定证据。

这轮完成的是有限、已声明感知输入域内的数值链路。下一步优先攻击两个假设：距离度量是否保留策略差异，以及对目标解释加权平均是否符合需要的响应行为。不要先扩充几十种目标或将本字典当作已确认的生物分类模型。
