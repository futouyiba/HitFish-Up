# Proposal C｜策略空间数值回归

状态：Working Probe / Candidate。不是 Current，不是生产参数。

## 1. 目的

本页不标定生产数值，只验证当前主体公式是否能给出目标策略排序。

当前主体：

```text
出手余量
= 食物价值
+ 攻击诱因
- 追赶负担
- 风险顾虑
- 摄食意愿门槛
```

响应映射沿用当前 Working：

```text
响应强度
= clamp(出手余量 / 0.40, 0, 1)
```

摄食意愿门槛沿用当前 Working：

```text
M <= 0.80:
    门槛 = 0.60 - 0.40M

M > 0.80:
    门槛 = 0.60 - 0.40M - 0.50(M - 0.80)
```

以下全部数值都是用于检查排序的示例，不是生产参数。

---

## 2. 先区分两种“策略收益”

一个重要结论是：

> Response 只决定“单次遇到这个呈现时，鱼有多愿意出手”，不能单独判断整套钓法的单位时间收益。

快速搜索的核心收益往往不是更高的单次响应，而是：

```text
单位时间覆盖更多水体
→ 产生更多有效遭遇 / 作钓机会
```

因此至少要区分：

```text
单次机会响应
= Response 输出

单位时间作钓效率
≈ 单位时间有效机会数
× 单次机会响应
× 后续命中 / 起鱼等其它环节
```

这意味着：

- finesse 可以降低追赶负担和风险顾虑，提高单次机会质量；
- 快速搜索可以接受较低单次响应，换取更多空间覆盖和机会数；
- 两者的策略取舍不应被强行压进 Response 一个公式里。

---

## 3. 回归用 Working 样例

统一使用：

```text
Good 食物价值 = 0.70
强合法攻击诱因 = +0.12
```

为了只看排序，假设几类操作产生如下示例负担：

### 高活性 / 低警惕

```text
快速搜索：
追赶负担 = 0.10
风险顾虑 = 0.03

finesse：
追赶负担 = 0.03
风险顾虑 = 0.01

强刺激呈现：
追赶负担 = 0.14
风险顾虑 = 0.04
攻击诱因 = 0.12
```

### 低活性 / 高警惕

```text
快速搜索：
追赶负担 = 0.30
风险顾虑 = 0.18

finesse：
追赶负担 = 0.05
风险顾虑 = 0.03

强刺激呈现：
追赶负担 = 0.25
风险顾虑 = 0.10
攻击诱因 = 0.12
```

这些值只表示“目标排序”，不是对真实鱼行为的测量。

---

## 4. 高活性、低警惕：快速搜索应该可用，但不必拥有最高单次响应

取中等摄食意愿：

```text
M = 0.50
门槛 = 0.40
```

### 快速搜索

```text
余量
= 0.70 - 0.10 - 0.03 - 0.40
= 0.17

响应强度
= 0.425
```

### finesse

```text
余量
= 0.70 - 0.03 - 0.01 - 0.40
= 0.26

响应强度
= 0.65
```

结果：

```text
finesse 单次响应 > 快速搜索单次响应
```

这是合理的。

快速搜索不需要在 Response 内反超 finesse。它的收益来自更高覆盖率。

例如若快速搜索单位时间产生约 2 倍有效机会：

```text
快速搜索：2 × 0.425 = 0.85
finesse：1 × 0.65 = 0.65
```

则单位时间结果仍可以由快速搜索占优。

因此当前 Response 主体不应加入匿名“搜索速度奖励”。

---

## 5. 低活性、高警惕：finesse 应明显翻转

仍取：

```text
M = 0.50
门槛 = 0.40
```

### 快速搜索

```text
余量
= 0.70 - 0.30 - 0.18 - 0.40
= -0.18

响应强度 = 0
```

### finesse

```text
余量
= 0.70 - 0.05 - 0.03 - 0.40
= 0.22

响应强度
= 0.55
```

这里即使快速搜索提供更多覆盖，其单次响应已经被压到零附近，finesse 会明显翻转为优势策略。

这正是：

```text
低活性
→ 高速追赶负担增加

高警惕
→ 暴露 / 机械呈现风险顾虑增加

两项共同作用
→ 慢、自然、隐蔽显著受益
```

---

## 6. 低摄食意愿：攻击诱因可以救回一部分鱼口，但不能免费

取：

```text
M = 0.30
门槛 = 0.48
```

在高活性、低警惕环境下，先比较同一组较积极动作有没有合法攻击诱因。

### 没有攻击诱因

```text
食物价值 = 0.70
追赶负担 = 0.14
风险顾虑 = 0.04
攻击诱因 = 0

余量
= 0.70 - 0.14 - 0.04 - 0.48
= 0.04

响应强度
= 0.10
```

### 有强合法攻击诱因

```text
攻击诱因 = 0.12

余量
= 0.70 + 0.12 - 0.14 - 0.04 - 0.48
= 0.16

响应强度
= 0.40
```

攻击诱因把低摄食意愿下的单次响应从很弱拉回到可用区间。

因此它确实购买：

> 正常鱼口差时，通过制造合适的猎物状态争取反应口。

但它不是免费奖励，因为同样动作已经承担更高追赶负担和一定风险顾虑。

---

## 7. 同样强刺激在低活性、高警惕时应该失效

继续取：

```text
M = 0.30
食物价值 = 0.70
攻击诱因 = 0.12
追赶负担 = 0.25
风险顾虑 = 0.10
```

得到：

```text
余量
= 0.70 + 0.12 - 0.25 - 0.10 - 0.48
= -0.01

响应强度 = 0
```

这说明同一个“强刺激打法”没有成为低摄食意愿的固定解：

```text
低摄食意愿 + 高活性 + 低警惕
→ 强刺激可能有效

低摄食意愿 + 低活性 + 高警惕
→ 追赶与风险代价把收益吃掉
```

这是当前主体公式最重要的策略回归之一。

---

## 8. 这轮回归暴露出的重要边界

### 8.1 搜索收益不属于 Response

Response 负责：

```text
一次有效呈现
→ 鱼有多愿意出手
```

搜索效率负责：

```text
单位时间产生多少有效呈现 / 遭遇机会
```

不能为了让快速钓法“看起来有优势”，直接在 Response 内给速度加正向奖励。

### 8.2 finesse 的收益也不需要专门加成

finesse 的好处自然来自：

```text
追赶负担下降
风险顾虑下降
```

如果再加一个 `FinesseBonus`，会重复计权。

### 8.3 反应口来自净收益翻转，而不是特殊豁免

当前不需要：

```text
低摄食意愿时
→ Trigger 特殊倍率
```

单纯：

```text
攻击诱因增加正向余量
```

已经足以让边缘案例跨线，同时仍受追赶和风险代价约束。

---

## 9. 当前回归结论

这组 Working Probe 暂未发现必须放弃“加性出手余量”的反例。

当前主体：

```text
出手余量
= 食物价值
+ 攻击诱因
- 追赶负担
- 风险顾虑
- 摄食意愿门槛
```

能够表达以下目标排序：

1. 高活性、低警惕时，快速搜索的单次响应可接受；其整体优势来自更高机会生成率；
2. 低活性、高警惕时，finesse 的单次响应明显翻转；
3. 低摄食意愿时，合法攻击诱因可以显著救回鱼口；
4. 同一强刺激在低活性、高警惕时可以因为自然代价而失效；
5. 不需要额外的 `FastSearchBonus`、`FinesseBonus` 或 `LowMotivationTriggerMultiplier`。

---

## 10. 下一步真正需要验证的内容

目前最大的不确定已经不在顶层公式，而在各子机制的 effect-size 是否能稳定落在合适区间：

- 活性变化究竟应让同样速度的追赶负担改变多大；
- 警惕度变化究竟应让同样异常暴露的风险顾虑改变多大；
- 合法攻击诱因的 0.10~0.15 量级是否足以产生反应口，但又不会成为万能解；
- 单位时间机会生成率与 Response 的产品层组合如何定义，避免把“搜索效率”偷偷重复写入中鱼响应。

这些问题应该通过更完整的策略 fixture 和仿真标定解决，而不是继续增加顶层自由参数。
