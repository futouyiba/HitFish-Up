## 来源事实与问题

A2于2026-09-22保存的《编辑器持久层契约》v16 §3.10/§6.3/§7.1、《编辑器界面》v20 §1.1/§7、《编辑器心智模型与IA》v2 §3/§5提供候选确认、完整影响与日常抽屉职责；没有唯一规定候选正文的空间。仓内Part3保留“不进抽屉”的方向，却无声称的卡内落点。Resolve/Bake独立帧不能充当共享候选面禁抽屉的依据。

阈值用途依据界面v20 §1.1、配置校验v5 §5/§5.2/§6与持久层v16 §7.1。用途、合法编辑能力与既有值校验不能混为一项，也不能用某个消费者Role代表共享模板全部消费者。本批读取来源保存件，不冒称重新实时fetch或测过画布。
