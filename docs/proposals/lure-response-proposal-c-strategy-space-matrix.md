# Proposal C｜玩家策略空间矩阵

状态：Working Closure / Candidate。不是 Current，不是生产参数。

## 1. 目的

本页不继续扩展具体运动学实现，而是先检查 Proposal C 的主体变量是否真的购买了不同的玩家策略。

核心原则：

> 一个机制只有在它让玩家面对不同鱼情时做出不同取舍，才值得保留。

如果某个操作只提高收益而没有成本，它会退化成固定最优解；如果两个变量总是要求同一种应对，它们可能在重复购买同一个策略维度。

## 2. 当前主体变量对应的玩家问题

| 变量 | 鱼侧含义 | 玩家主要应对 |
|---|---|---|
| 食物价值 | 这个目标本身有多值得吃 | 选择匹配食性的猎物类型、尺寸、拟饵 |
| 活性 | 为了追上目标，鱼愿意/能够承担多少主动追赶负担 | 决定搜索速度、移动速度和是否转为慢速精细呈现 |
| 摄食意愿 | 当前整体有多愿意为了食物出手 | 决定正常摄食口是否充足，以及是否需要依赖强攻击诱因越过出手门槛 |
| 警惕度 | 对异常、暴露、机械操控线索有多敏感 | 决定线组隐蔽性、呈现自然度、操作是否需要更细腻 |
| 追赶负担 | 当前目标追起来有多费劲 | 限制过快呈现，尤其限制低活性鱼 |
| 预测困难 | 当前短时运动有多难抓住攻击时机 | 限制过于突然、难以提前判断的运动变化 |
| 风险顾虑 | 呈现是否暴露出值得警惕的异常 | 惩罚不隐蔽、不自然、明显机械的呈现 |
| 攻击诱因 | 当前猎物状态是否额外容易诱发出手 | 支持反应口、受伤/逃逸/刺激性状态，但必须承担其它代价 |

## 3. 策略不是“鱼情 X → 技能 Y”，而是收益和代价重新排序

设计目标：

```text
鱼情状态
→ 改变各类收益 / 代价的重要程度

玩家操作
→ 同时改变若干 Response 分量

最终
→ 不同鱼情下出现不同优势策略
```

因此优先让代价来自已有机制，而不是额外造新的 penalty。

## 4. 主要玩家操作的收益—代价矩阵

| 玩家操作 / 配装 | 主要收益 | 自然代价 | 更适合的鱼情 | 容易失效的鱼情 |
|---|---|---|---|---|
| 快速搜索 / 快速移动 | 单位时间覆盖更多水体，更快获得鱼位置和鱼口信息 | 追赶负担上升；若操作粗糙，还可能增加机械暴露 | 高活性、低警惕 | 低活性；高警惕时若呈现明显机械 |
| 慢速 / 停顿 / 精细呈现 | 降低追赶负担；有机会降低机械暴露和风险顾虑 | 搜索效率下降，单位时间覆盖范围变小 | 低活性、高警惕 | 高活性且当前主要目标是快速定位鱼时机会成本较高 |
| 强逃逸 / 受伤 / 刺激性呈现 | 攻击诱因上升，可帮助低摄食意愿鱼跨过出手门槛 | 可能提高追赶负担；突然变化可提高短时预测困难；粗糙操作可增加风险顾虑 | 低摄食意愿但活性仍高；或目标鱼对该状态有明确攻击诱因 | 低活性；高警惕且机械暴露高；刺激过猛导致预测困难过高 |
| 更隐蔽的线 / 钩组 | 降低装备暴露和风险顾虑 | 可能降低线强度、搏鱼容错；高级材料提高经济成本 | 高警惕 / 高钓压 | 低警惕时收益缩小，成本可能不划算 |
| 更自然的钓组 / 操作 | 降低运动反常和风险顾虑 | 往往牺牲搜索速度、操作直接性，或提高装备/学习成本 | 高警惕 | 低警惕、需要快速覆盖时 |
| 高食性匹配拟饵 | 提高食物价值 | 可能目标范围更窄、搜索效率更低、通用性更差 | 明确目标鱼、明确食性 | 需要快速探鱼或多目标混钓时 |
| 更直接、更强势的钓组 | 提高操作响应、搜索效率、控制力 | 更容易产生机械操控暴露；可能牺牲隐蔽性 | 低警惕、高活性 | 高警惕 |

## 5. 四个主要鱼情轴分别购买什么

### 食物价值：选什么

```text
目标鱼食性 / 当前猎物偏好
→ 选择猎物类型与拟饵
```

它购买“目标匹配”。

边界：Reject 是硬边界；Preferred / Good / Marginal / Poor 是连续价值差异。

### 活性：搜多快

```text
高活性
→ 能承担更高追赶负担
→ 快速搜索更可行

低活性
→ 高速呈现代价迅速上升
→ 慢速、停顿、近身呈现相对受益
```

它购买的是“覆盖效率 vs 单次机会质量”的切换。

### 摄食意愿：正常摄食口有多好，以及是否需要反应口

```text
摄食意愿高
→ 正常食物价值更容易跨过出手门槛

摄食意愿低
→ 整体鱼口差
→ 某些强攻击诱因仍可能帮助越线
```

但强刺激不能成为免费解法。其代价优先来自：

- 更高速度 → 追赶负担上升；
- 突然改变近期趋势 → 预测困难上升；
- 操作粗糙 → 风险顾虑上升。

### 警惕度：能不能露馅

```text
低警惕
→ 对线、钩、机械操作等异常容忍更高
→ 可以更直接、更快、更强势

高警惕
→ 对装备暴露和运动反常更敏感
→ 隐蔽线组、自然呈现、细腻手法相对受益
```

它购买的是“效率 / 强度 / 成本”与“隐蔽 / 自然”的取舍。

## 6. 关键交叉：为什么这些变量不能简单合并

### 活性 × 摄食意愿

两者都会影响“鱼愿不愿意动”，但策略不同：

```text
低活性
→ 主要问题是追赶代价
→ 慢下来

低摄食意愿
→ 主要问题是出手门槛高
→ 可能需要提高食物价值或攻击诱因
```

因此不能把它们压成一个“鱼口强度”。

典型组合：

```text
低摄食意愿 + 高活性
→ 强刺激可能有效

低摄食意愿 + 低活性
→ 强刺激容易被追赶负担抵消
→ 更需要低位移但高诱发性的呈现
```

### 活性 × 警惕度

```text
高活性 + 低警惕
→ 最适合积极快速搜索

低活性 + 高警惕
→ 同时惩罚高速和露馅
→ 慢、自然、隐蔽更重要
```

两者共同决定“快 vs finesse”，但原因不同，因此需要分别保留。

### 摄食意愿 × 警惕度

```text
低摄食意愿
→ 需要更强的正向诱因

高警惕
→ 又限制粗暴、机械的刺激方法
```

这产生一个有价值的策略难题：

> 既要让它想出手，又不能让呈现露馅。

## 7. 攻击诱因必须具备代价，否则会塌成固定最优解

候选原则：

```text
攻击诱因上升
→ 不能免费
```

优先允许已有机制自然承担代价：

```text
强逃窜
→ 追赶负担 ↑

突然违反近期运动趋势
→ 预测困难 ↑

机械操作明显
→ 风险顾虑 ↑
```

不建议新增泛化的“刺激成本”或“乱动惩罚”，除非现有机制无法解释目标体验。

## 8. 对主体公式的含义

当前主体保持：

```text
出手余量
= 食物价值
+ 攻击诱因
- 追赶负担
- 预测困难
- 风险顾虑
- 当前摄食意愿对应的出手门槛
```

这不是声称所有项已经完成生产标定，而是表达一个策略契约：

- 正向项购买“值得吃 / 现在值得出手”；
- 负向项分别购买追赶、攻击时机、警戒风险的不同代价；
- 当前鱼情通过活性、摄食意愿、警惕度改变这些代价和收益的相对重要性；
- 玩家通过配装与操作在多个项之间做取舍。

## 9. 当前审查结论

### 保留价值较高

- 食物价值：独立购买目标匹配；
- 活性 / 追赶负担：独立购买搜索速度与 finesse 的切换；
- 摄食意愿：独立购买整体鱼口和反应口需求；
- 警惕度 / 风险顾虑：独立购买隐蔽性与自然呈现；
- 攻击诱因：有价值，但必须严格限制为具名猎物状态，并确保有自然代价。

### 需要继续验证

- 预测困难是否在足够多的真实策略案例中提供独立价值，而不是只成为攻击诱因或高速移动的重复惩罚；
- “低摄食意愿 + 低活性”是否需要专门的低位移高诱发状态，还是现有猎物状态已经足够；
- 哪些玩家操作应同时作用于多个 Response 分量，哪些会造成重复结算。

## 10. 使用方式

后续新增一个 Response 变量或一个玩家操作机制前，先回答：

1. 它购买了什么新的玩家策略？
2. 玩家通过什么可理解的操作改变它？
3. 它的收益对应什么成本？
4. 这个成本能否由已有机制自然产生？
5. 控制现有变量后，它还能产生独立的策略排序吗？

如果不能回答，不应因为“更真实”就加入主体 Response。
