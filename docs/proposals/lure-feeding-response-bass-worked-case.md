# 大口黑鲈 × 小鱼目标：一组可复算的局部响应推导

日期：2026-10-22  
状态：设计探针；公式、参数和状态隔离均为人工假设，尚未标定或晋升为生产规则。  
讨论入口：[阶段记录与计算缺口](lure-feeding-response-joint-evaluation.md)。

## 1. 这次实际解决什么

比较同一目标的两个当前呈现：持续游动阶段与抽动后的停留阶段。只改变鱼的一个行动能力尺度，计算四个组合；再加入第二种目标大小。

这次用明确函数替代未定义的 selectCurve 和 compare，检验“收益与行动代价竞争”是否能产生可解释的操作差异。两种呈现不另配响应结果；各格结果均由同一组公式生成。

完整性只限本例声明的输入到局部输出。目标身份、可感知性与其他条件固定为已知，未完成从任意饵料推断目标身份的算法。本例也不代表整段抽停操作的平均效果或单位时间中鱼收益。

## 2. 现实案例支持到哪里

- Bernie Schultz 的第一人称文章 [Knowing when to jerk](https://www.bassmaster.com/how-to/news/knowing-when-to-jerk/)（2013-10-02）讨论从较快节奏试起、无响应时减少抽动并延长停留，同时保留有力的抽动；还强调检查咬口发生在运动还是停留阶段。
- Chris Zaldain 的第一人称文章 [Swimbaits and the drop swim](https://www.bassmaster.com/how-to/news/swimbaits-and-the-drop-swim/)（2019-09-13）讨论呈现角度、大小和动作，并指出更快移动可能带来更明显动作，但有时缓慢悬浮更合适。

这些案例支持需要区分动作阶段和情境，不能用平均速度或越慢越好概括。它们没有隔离功能能力、摄食意愿、空间位置和感知变化，也没有证明以下公式。将其中的策略差异解释为“能力变化造成行动代价差异”，是本探针检验的设计假设。

不把现实中的低温或不活跃直接换算成本文的能力降低。饵长偏好、刺激衰减与行动代价的全部数字也没有从上述文章估算。

## 3. 受控情境与输入

鱼种：大口黑鲈。目标：已被解释为可摄食的小鱼；两种呈现都具有足够的鱼形和目标支持。摄食意愿、风险、其他食物、光照、水层等固定。不在本例重新计算目标身份或感知强弱。

使用鱼当前位置的同一个局部评价点：目标在前方 d = 0.20 m，水静止、无遮挡，当前沿远离鱼的方向运动。停留呈现当前速度为零。未生成具体跟随鱼，也不模拟已经发生的追逐。

| 实际事实 | 持续游动阶段 | 抽停的停留阶段 |
|---|---:|---:|
| 当前目标速度 v，亦为本例径向远离速度 | 0.50 m/s | 0 |
| 最近一次已记录的短促速度变化幅度 j | 已知无，取 0 | 0.60 m/s |
| 该事件距评价时刻的时间 a | 无事件时不使用 | 0.50 s |

j 是本例指定类型的近期事件事实，不是钓法名称或任意历史的最大值。事件筛选、时间戳与可感知范围须随输入提供；缺失记录为 Unknown，不能假定无事件。本探针只输入至当前的记录，不读取玩家未来何时再次抽动。

这两行是两个时刻的受控呈现，不是把一整段轨迹平均成两个数。生产中的事件载体、允许的历史支持与回放尚需按 Presentation / Opportunity 契约核实。

鱼状态只改变 V：正常 V = 1.00 m/s，降低 V = 0.45 m/s。V 是将行动要求折算为代价的能力尺度，**不是最大游速或硬可行性阈值**。本例假定两种当前行动均可尝试；加速、转向、耐力的独立限制未建模。

## 4. 同一组计算规则

下列常数固定用于本探针，均为设计选择。它们购买的表达能力在各式下说明，不应按鱼种全部独立配置。

### 4.1 已知小鱼目标上的运动激发

```text
x = v / v0 + (j / j0) × exp(-a / t_signal)
M = 1 - exp(-x)

v0 = 0.25 m/s
j0 = 0.50 m/s
t_signal = 1.00 s
```

已知无事件时，事件项为零。持续运动和近期短促变化都可形成激发；事件影响随时间减弱，整体饱和。

M 是对已成立小鱼目标的局部运动激发假设，不是检测概率、目标身份置信度或通用“像不像”分数。它不适用于任意动物、无生命物体或运动范围。为何鱼形呈现成为小鱼目标，仍是固定前提。

本例算得持续游动 M = 0.865，抽停停留 M = 0.517。停留阶段保留近期运动作用，同时当前行动要求可以下降。t_signal 是信号解释的时间参数，不是鱼的追逐状态寿命。

### 4.2 大小对应的食物价值

```text
F(L) = exp(-0.5 × (ln(L / L_pref) / sigma_size)^2)

L_pref = 0.08 m
sigma_size = 0.70
B = F(L) × (1 + beta × M)
beta = 1.00
```

F 是本情境人为设定的大小偏好，不是食物热量、胃容量或挂钩成功率。8 cm 时 F = 1；16 cm 时 F = 0.612。两种尺寸均保持小鱼目标解释及可尝试攻击的前提。

B 是局部攻击激励。这里的乘法明确表示运动强化这份已支持食物的价值；不是额外添加通用刺激奖励，也不声称所有响应都适用这条式子。F 不是最终响应上限，因为 B 还随运动改变。

### 4.3 当前行动要求与代价

```text
q = d / t_action + v
E = k_effort × (q / V)^2

t_action = 1.00 s
k_effort = 0.50
```

q 是本例直线几何下的参考行动速度要求：以给定时间尺度缩短当前距离，并跟上目标当前的远离速度。它是局部启发式要求，不是最优截击解或对未来停留时长的预测。t_action 与 t_signal 含义不同，数值相同不代表绑定。

平方代价使接近高要求的操作对能力下降更敏感。E 为统一设计效用尺度上的代价，不是焦耳、耗氧量或攻击失败概率；k_effort 负责将这项要求转换到与 B 可比较的尺度。

持续游动 q = 0.70 m/s；停留 q = 0.20 m/s。能力降低只改变 E，不再额外施加状态惩罚。v 同时影响激励与行动要求，分别表达目标运动的吸引作用和追上它的代价，不重复扣同一后果。

### 4.4 净激励到局部响应

```text
U = B - E
U_positive = max(0, U)
R = U_positive / (1 + U_positive)
```

减法表达同一决策中的收益与代价竞争。非负截断表示本假设下净激励不足时不保留这项局部响应；饱和映射给出 [0,1) 的相对结果，映射尺度固定为 1。

R 不是实测概率或可直接接入生产的 captureRetention。R = 0 不证明目标不可感知、Mode 不合法或物理上不可攻击；它只是本局部决策式的输出。完整响应还需其他必要语义闭合。

## 5. 四格结果与大小扩展

| 目标大小 | 能力状态 | 当前呈现 | B：激励 | E：代价 | U：净激励 | R：局部响应 |
|---|---|---|---:|---:|---:|---:|
| 8 cm | 正常 | 持续游动 | 1.865 | 0.245 | 1.620 | 0.618 |
| 8 cm | 正常 | 抽停：停留阶段 | 1.517 | 0.020 | 1.497 | 0.600 |
| 8 cm | 降低 | 持续游动 | 1.865 | 1.210 | 0.655 | 0.396 |
| 8 cm | 降低 | 抽停：停留阶段 | 1.517 | 0.099 | 1.418 | 0.586 |
| 16 cm | 正常 | 持续游动 | 1.142 | 0.245 | 0.897 | 0.473 |
| 16 cm | 正常 | 抽停：停留阶段 | 0.929 | 0.020 | 0.909 | 0.476 |
| 16 cm | 降低 | 持续游动 | 1.142 | 1.210 | -0.068 | 0.000 |
| 16 cm | 降低 | 抽停：停留阶段 | 0.929 | 0.099 | 0.830 | 0.454 |

以 8 cm 为例：正常能力下，持续游动增加的激励约 0.348，大于增加的代价 0.225，因而略优；能力降低后，这项代价差升为约 1.111，停留阶段更优。反转来自同一组规则，不按状态另填答案。

这只支持局部呈现选择：降低能力时，将目标留在低行动要求阶段可能更好。不能据此宣布整段抽停一定优于持续收线；前段抽动、停留长度、经过的位置及评价支持尚未共同结算。

## 6. 大小究竟进入哪里

上表的大小扩展保持绝对运动、距离与 V 不变。因此大小只改变食物价值 F，q 和 E 完全不变。没有为“大目标”再增加行动惩罚。

若改为保持每秒移动多少个目标体长相同，则实际速度 v = L × 体长速度；大小通过实际速度同时改变 M 与 q。这是呈现事实变化的后果，不需要再附加一个大小系数。本例尚未计算该实验，也不能据此推断鱼对大型猎物的其他攻击限制。

16 cm、正常能力下，停留比持续游动只高约 0.003，属于敏感结果。它来自较低食物价值使同一行动代价更难抵偿，不应写成“大饵必须抽停”的规则。

## 7. 检查、敏感性与反例

已计算并核对八个组合：

- 8 cm 的四格出现预期的局部排序反转。
- 能力变化不改变 M、F、B；仅改变 E。
- 大小变化且绝对运动固定时，不改变 q、E。
- R 落在 [0,1)；已知无近期动作的静止目标，其 M = 0，区别于刚抽动后的停留。
- 在本参数下正常能力的持续游动优于完全静止，说明没有编码成越慢越好。

不是单点调参才会反转：固定其余输入，8 cm 的四格反转在约 0.647 < beta < 3.196 内成立；实际核对 beta = 0.8、1.0、1.2，均保留反转。这仅检验一个参数，不能称为全面稳健性验证。

结构也暴露出限制：

1. 运动激发随 v 饱和，无法解释过于异常的运动怎样破坏小鱼解释。若案例要求这种现象，必须补目标解释规则，不能继续靠提高行动代价代替。
2. 同样当前速度与最近事件、但不同转向和轨迹的呈现会得到同一结果。需要不同结果的真实案例会击穿这个输入压缩。
3. 两种能力状态为人工隔离，并非真实低温鱼情的解释证明；现实中的意愿与能力须分别取证。
4. 本式允许长期静止、仍被支持为食物的目标保留基础激励。若特定鱼种情境不支持，需修订摄食评价，不能加一个无来源的通用零门槛。
5. 正常能力下持续游动的优势较小，16 cm 的排序尤其敏感；尚未进行多参数扰动或真实案例拟合。
6. 没有估计全部参数的可识别性、跨鱼种共享率或配置成本。当前不据此建立四条曲线或每鱼一套参数。

## 8. 可复算代码

Python 3 标准库即可运行；输入记录已知且有效，生产的 Unknown、非法输入和契约校验不在这段演示代码中。

```python
from math import exp, log

motions = [
    ("swim", 0.50, 0.0, 0.0),   # known no recent event
    ("pause", 0.0, 0.60, 0.50), # recorded speed-change event
]

def evaluate(length, capacity, v, event_dv, event_age, beta=1.0):
    m = 1 - exp(-(v / 0.25 + event_dv / 0.50 * exp(-event_age / 1.0)))
    f = exp(-0.5 * (log(length / 0.08) / 0.70) ** 2)
    b = f * (1 + beta * m)
    q = 0.20 / 1.0 + v
    e = 0.50 * (q / capacity) ** 2
    u = b - e
    positive = max(0.0, u)
    return m, f, q, b, e, u, positive / (1 + positive)

for length in (0.08, 0.16):
    for capacity in (1.0, 0.45):
        for name, v, event_dv, event_age in motions:
            result = evaluate(length, capacity, v, event_dv, event_age)
            print(length, capacity, name, *(round(x, 6) for x in result))
```

## 9. 当前可以继续推敲的结论

收益与代价竞争是一种已在本例走通的候选计算关系；不需要先配置每个组合的最终响应曲线。目标类型仍限定解释语义，运动分别进入激励与行动要求，大小是否进入两处取决于它实际改变什么。

本例没有完成目标识别、完整抽停节奏或全部行动约束。下一步用真实策略反例攻击上述输入压缩和运算关系，再决定是否保留这套公式。示例算通本身不构成采用授权或生物学验证。
