## 方案B主体方向

实际呈现提供猎物线索；线索组合支持一个或多个猎物类型；运动与情境在支持范围内形成呈现状态；鱼再分别评价这份目标的食物价值与行动要求。

主文档：[猎物解释：线索支持、呈现状态与鱼的响应](lure-feeding-target-interpretation.md)。支持规则、状态样本、计算公式、输出状态、案例依据及验收结果只在该文维护。

摄食动机推导见 [Feeding motivation](lure-feeding-motivation.md)：从参考倾向、时段偏移和已解析近期摄食负荷生成 H，再进入激励与代价的权衡。

## 方案B边界

当前已给出明确的感知输入口径、有限支持组合、条件状态评价、食物价值与行动代价公式，并运行单目标及多目标案例。多种解释分别完成局部响应后，本候选按完整替代摄食路径取 max；未知支持或未闭合路径仍阻止最终输出。该规则不推广为任意不确定解释的通用聚合。

主要未决问题：

1. Mesh、材质、物理及环境源如何产生可重放的接收者感知线索；新增事实如何接入 Presentation / Opportunity 契约。
2. 哪些支持组合与状态规则具有策略或生物证据，哪些只是人工近似；门槛与最近状态切换是否需要连续化。
3. 检验完整替代摄食响应的 max 候选是否购买了需要的策略能力；若涉及真实概率混合或竞争，须重新定义结构，不能把当前 max 当通则。
4. 加速、转向、耐力、风险等如何进入完整响应；摄食动机已有局部公式，其参数、其他来源及与食物偏好的边界仍需验证。
5. 状态参数及跨鱼种共享是否能控制配置成本；完整时序、其他 Mode 与生产 captureRetention 接口仍需闭合。

后续优先沿具体反例检验这些规则。不能因某个探针已可执行，就把它当作完整中鱼算法。
