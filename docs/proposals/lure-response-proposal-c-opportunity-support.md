# Proposal C｜机会量与单位时间收益（Candidate 玩具模型）

状态：Working Design / Candidate。本文只用于解释为什么 Response 单项无法完成快搜与隐蔽的策略翻转，不是生产函数，也不改变 `L` 的 owner。

来源与约束：[响应与机会契约](lure-response-proposal-c-response-opportunity.md) 与 Proposal C Working Closure（PR [#130](https://github.com/futouyiba/HitFish-Up/pull/130) 提交 `5caf1f119ab6e5a5c595a4ba913e7962aa338ec3`）：`L` 的正式 owner 是 Opportunity，Spatial 只提供空间事实；`q = L × C` 只乘一次；`L(duration)` 的生产函数未冻结。本文的公式是**可替换的玩具模型**。

## 1. 为什么需要这一层

第一轮策略 probe 已经显示：

- 快搜在 Response 内只比慢速差约 25%，Activity 从高到低也只让快搜再降约 8.5%；
- 隐蔽方案在高警戒时保留响应，但在低警戒时也没有成本，因此永远占优。

两项都缺少同一半：**单位时间的机会量**。Response 回答“遇到这个呈现时鱼多愿意出手”，不回答“单位时间遇到多少次”。

## 2. 玩具模型

```text
每个姿态颗粒：
L(q) = D / (D + q)            # 停留越久，单颗粒机会支持越高
R(q) = q / (1 + q / Q_cap)    # 单位时间遇到的颗粒数，随速度饱和
Y(q) = coverage × R(q) × L(q) × C(q)

Working: D = 0.80, Q_cap = 1.00
```

三个玩具参数的读法：

- `D` 是停留/机会量随速度衰减的尺度：速度越快，单个颗粒被鱼遇到后有效停留的时间越短；
- `Q_cap` 是单位时间遭遇率开始饱和的速度尺度：速度再高，遇到颗粒数的增长也会放缓；
- `coverage` 是该方案实际覆盖多少空间，用来给隐蔽方案记上覆盖成本。

- `C(q)` 来自现有响应链（`M0=0 / M1=0.40`，`K_close=0.76`）；
- `Y` 是分析量，不是运行时字段，也不进入 Candidate；
- `coverage` 表示该方案能覆盖的空间比例；隐蔽方案的覆盖损失由此进入。

## 3. 扫描结果

食物价值 0.70、Motivation 0.5、无风险、无触发。

| Activity 倍率 | 最优 q | 最优 Y | Y(q=0.45) | Y(q=0.90) | Y(q=1.50) |
|---|---|---|---|---|---|
| 0.8（高活性） | 0.49 | 0.134 | 0.134 | 0.113 | 0.094 |
| 1.0 | 0.47 | 0.130 | 0.130 | 0.110 | 0.092 |
| 1.6（低活性） | 0.39 | 0.120 | 0.118 | 0.104 | 0.089 |

观察：

1. 加入遭遇饱和与停留衰减后，单位时间收益出现内部最优；
2. 低活性把最优速度从约 0.49 压到约 0.39，方向正确，但幅度不大；
3. 在全部 Activity 下，快速（0.90 / 1.50）都不如中等速度。这个玩具模型**没有**让“快搜在高活性时更优”，因为快搜的真实收益是探索与信息覆盖，不是单颗粒遭遇率。

## 4. 隐蔽方案

`coverage = 0.55`，直接方案 `coverage = 1.0`，同一 cue 强度差异。

| Wariness | 直接 Y | 隐蔽 Y |
|---|---|---|
| 0.1 | 0.089 | 0.058 |
| 0.4 | 0.033 | 0.051 |
| 0.8 | 0.000 | 0.043 |

观察：

- 低警戒时直接方案占优；
- 高警戒时隐蔽方案占优；
- 翻转点由 `coverage` 损失与 `RiskCost` 共同决定，缺一不可。

## 5. 结论

- **Case A（快搜）**：Response + 单颗粒机会量仍不足；快搜要成立，必须显式建模“探索/信息覆盖”的收益，而不是把它塞进响应或单颗粒 `L`。
- **Case C（隐蔽）**：只要给隐蔽方案一个覆盖成本，策略翻转就能成立；覆盖成本的大小是最敏感的 Working 参数。
- 时间与覆盖全部留在 Opportunity 侧，不进入出手余量。

## 6. 边界

- `L` 的 owner 是 Opportunity；Spatial 只提供空间事实。本文不实现 reducer；
- `D`、`Q_cap`、`coverage` 都是玩具参数，不是生产标定；
- 不把 `Y` 写入 Candidate 或 Response；
- 垂直运动仍通过有效窗口影响 `L`，不进入 Closing。

## 7. 未决

- 遭遇率是否真的随速度饱和，还是由空间结构决定；
- 停留长度 `D` 与有效区域尺寸的关系；
- 探索/信息覆盖如何成为可计算收益，是否需要独立机制；
- 隐蔽方案的覆盖损失如何从实际配置推导；
- 各鱼情下的 `coverage` 与 `RiskCost` 联合标定。
