# Feeding motivation：从行为上下文到摄食激励

日期：2026-10-23  
状态：候选数值模型。参考值、时段偏移、负荷灵敏度与衰减时间均为人工参数，未作生物学标定。  
主文：[猎物线索、状态与响应](lure-feeding-target-interpretation.md)。代码：[feeding_motivation_probe.py](../../prototypes/lure-response/feeding_motivation_probe.py)。

## 1. 本轮确定的职责

| 输入 | 表达什么 | 本轮不承担什么 |
|---|---|---|
| p_t | 基础食物偏好经 diet shift 调整后的当前食物评价 | 猎物身份、运动能力或所有食物统一的摄食开关 |
| H | 当前基础摄食动机，对获取食物的激励敏感程度 | 空间鱼量、拟饵匹配、其他 Mode 的动机 |
| V | 当前行动代价能力尺度 | 摄食意愿 |
| S_t、g_t | 对实际猎物呈现的支持及其状态激励 | 再派生一遍基础 H |

已核对项目 Natural Bite Readiness Current v9：motivation 为派生上下文，由 Interaction 在响应内部解释，不是 Candidate Weight 最后再乘的通用 bonus。近期消费记住 Cause，而不是持久化 H；Interaction 不重读原始消费历史。本候选不改写该外部契约。

## 2. H 的第一版明确计算

本轮先取三个具体原因：Species / 已准入 Cohort 的参考摄食倾向、当前时段偏移、已准入近期摄食负荷。未加入泛化的“环境／状态惩罚”。

```text
eta = ln(H_ref/(1-H_ref)) + b_period - k_consume × C
H = 1/(1+exp(-eta))
```

| 参数／输入 | 含义 | 演示取值 |
|---|---|---|
| H_ref | 命名参照时段、C=0 时的参考动机，严格在0和1之间 | 0.60 |
| b_period | 当前既有 Period 对动机的偏移 | 偏弱=-0.80，参照=0，偏强=+0.80 |
| C | 已归因、已结算近期消费历史的归一化负荷，非负 | 0、0.5、1等 |
| k_consume | 本 profile 对该负荷的灵敏度 | 1.50 |

这里的 logistic 是有界合成曲线，不意味着 H 是“鱼决定吃东西的概率”，也不假设多个原因统计独立。命名参照点使 H_ref 的含义可检查；不使用每个任意状态一个自由偏移量。

偏强／参照／偏弱只是本探针三个输入场景，不是新建一套 Period，不代表实际钟点或真实鱼种的日节律。生产需要把偏移绑定现有 Period profile，并分别取证。

C=1 只表示 profile 定义的一单位参考摄食负荷，不是“胃已全满”。缺少历史不等于 C=0；参数缺失、负荷缺失均保持 Unknown。本探针实例明确启用消费效应；若某 Phase 显式不启用，需要独立声明覆盖，不得把一个缺失的启用输入偷换成零。

繁殖、警戒、压力等仍按已有模式启用与具名行为上下文解释；未因其存在就追加匿名 FinalCoeff。当前三输入模型不声称穷尽摄食动机来源。

## 3. 近期负荷怎样恢复

为展示历史如何影响 H，探针单独给出一版可选 Cause reducer 数学例子：

```text
C_after = C_before × 2^(-elapsed_hours / half_life_hours)
          + authoritative_increment_at_interval_end
```

演示 half_life=4小时。每个事件按自己的权威时间依次推进，先衰减再加入该时点已经归因、已经结算的负荷增量；不能把多个不同时点的事件都挪到区间末尾。

该 helper 不是生产 reducer，也不验证事件权限、归因或时间切面。不在 Interaction 内运行它；生产由近期消费 Cause 的唯一上游责任方处理，Readiness 消费相容 profile/context 派生 H，Interaction 只取得已解析的 H。

只允许已接受且已归因的消费增量。抛投、中鱼候选、预测会被吃掉、普通资源减少、FishSpawnCommit 本身都不能填入这个增量。消费归因或记录缺失不能靠函数默认值变成已知零。

Spawn 前默认不是某条虚构鱼的胃状态；历史使用已准入的 Species × EcologicalLocality 等作用范围。C 的参考量必须与该作用范围相容，不能把区域总摄食量直接当单鱼饱腹量。

4小时衰减不是自然规律或全鱼种规则。若现有权威 Cause 使用其他 quantity、时间核或 reducer，本 helper 不能并行重解释它，必须显式适配或重推模型。新增摄食只作用于 causally-later support，不回填 earlier resolution。

## 4. 接入当前响应

```text
B0_t = S_t × p_t × F_t × g_t
B_t = H × B0_t
E_t = 0.50 × ((d/1秒 + v_away)/V)^2
U_t = max(0, B_t-E_t)
R_t = U_t/(1+U_t)
```

S_t 的语义是该解释的激励保留比例，不是分类概率。当前代码只对受线索支持的类型使用其状态匹配 Q 作为数值代理，即 S_t=Q_t；连续外形支持尚未闭合。未来生成完整联合 S 时，应替换这个代理，不能再乘一个独立 Q 重算同一匹配。

H 只乘一次激励，不再乘最终 R、总体 Candidate Weight 或物理能力。H=0 仅令当前摄食局部响应为零，不改变目标支持、状态解释或 Mode eligibility。

同一消费历史有条件地影响能力，属于另一条需要直接证据的 Functional consequence，不能把 H 降低再自动换算成 V 降低。

多解释合成仍开放。本轮不会用 H 或更高的 R_t 帮鱼选择它眼前究竟是什么目标。

## 5. 执行结果

固定前篇米诺的几何、动作和能力 V=1。它的游动／抽停激励 B0 分别为1.865、1.517，行动代价 E 分别为0.245、0.020。

| 场景 | b_period | C | 派生 H | 游动 R | 抽停 R |
|---|---:|---:|---:|---:|---:|
| 较弱摄食时段，无近期负荷 | -0.80 | 0 | 0.403 | 0.336 | 0.371 |
| 较强摄食时段，无近期负荷 | +0.80 | 0 | 0.769 | 0.543 | 0.534 |
| 同一较强时段，负荷增加至1 | +0.80 | 1 | 0.427 | 0.355 | 0.386 |
| 固定时段输入，负荷恢复至0.5 | +0.80 | 0.5 | 0.612 | 0.473 | 0.476 |
| 固定时段输入，负荷恢复至0.25 | +0.80 | 0.25 | 0.696 | 0.513 | 0.509 |

最后两行是固定时段影响的隔离试验；实际时间推进时须重新取得对应 Period 输入，不能把它们当作一天中真实鱼情的预测。

动机较强时，游动增加的激励抵过额外代价；动机降低后，便宜的停留呈现更优。无需改变鱼的运动能力，也没有在每个时段另配最终响应值。优势差距较小，尚未达到稳健玩法参数结论。

未把 H 乘在最终 R 上，因为那只能同比改变响应，不能在同一组操作间改变排序。

## 6. 已完成的检查与尚未闭合的输入

已运行五个派生场景，并与主探针联算；主探针的原13个案例以明确 H=1 作为对照。检查包括：

- 参考时段、零负荷恢复到 H_ref。
- 固定其他条件，负荷增加使本候选 H 降低；衰减使它恢复到当前时段基线，不凭空恢复到1。
- 负荷衰减的区间拆分等价；已知区间末事件仅加一次。
- H 变化不改变猎物解释、状态匹配和能力代价；可以改变操作排序。
- 动机缺失保持未决；H=0 不撤销目标支持；强动机不能创造无线索支持的猎物。
- 缺失负荷、非法负值、无效参数区分处理。

p_t 与 H 的乘积存在尺度混淆：如果 diet shift 将全部食物偏好一起放大，与提升 H 很难区分。偏好配置应固定参照锚，diet shift 优先表达食物之间的相对调整；真正共同的摄食倾向变化由 H 承担，除非另有明确语义。

本轮完成从给定 profile、Period 偏移、已解析负荷到 H，再到响应的局部数值链。实际鱼种时段曲线、负荷参考量与历史 reducer 的生产参数仍需证据与作用范围；不因例子可运行就自动启用该历史复杂度。
