# 方案 C：从路亚实际呈现到猎物解释与状态

日期：2026-10-23  
状态：设计提案。规则与数值为可检查的设计假设，尚未完成生产接入与效果验证。  
相关提案：[方案B](lure-feeding-target-interpretation.md)。两份提案独立；本页只定义方案C当前讨论的机制。

可执行局部原型：[proposal_c_interpretation_probe.py](../../prototypes/lure-response/proposal_c_interpretation_probe.py)。输入为记录好的轨迹与环境样本，输出为猎物支持map；不含Unity数据采集、视觉识别或鱼侧响应。

## 1. 目标与范围

本提案集中处理“1实际呈现 → 2猎物解释 → 3类型条件状态”：一件具体饵装配提供哪些证据，当前呈现分别支持哪些猎物解释，以及按各类猎物理解时呈现怎样的当前状态与过程。

整体主线如下。本页展开前三步，鱼侧评价与响应保留职责边界。

| 节点 | 回答的问题 |
|---|---|
| 1 实际呈现 | 当前装配实际提供了什么形态、运动及环境关系？ |
| 2 猎物解释 | 这些证据分别在多大程度上支持不同猎物类型？ |
| 3 类型条件状态 | 按该猎物理解，它表现为怎样的移动、停留、失衡或逃窜状态？ |
| 4 鱼侧评价 | 对这条鱼，食物价值、捕获要求与摄食意愿如何？ |
| 5 响应 | 上述评价怎样形成行动响应？ |

第2步输出猎物支持map，各项不要求之和为1，也不强制选择唯一类型。支持值表示“有多少依据可以按该猎物理解”，不是整体动作逼真度、食物偏好、可得程度或咬口概率。

运动可以参与第2步解释，也可参与后续状态与捕获评价，但同一作用不能重复结算。第2步不读取diet shift、feeding motivation或鱼的追赶能力来改写目标身份。

### 猎物范围

以下是工作分类，不直接等于七个固定计算通道。是否细分，以判断机制或鱼侧评价是否存在重要差异为依据。

| 猎物家族 | 包含哪些对象 | 需要检验的判断差异 |
|---|---|---|
| **鱼类** | 小型饵鱼、较高体型的小鱼、底栖鱼、细长鱼等 | 轮廓、摆动、反光；游动、悬停、下落、失衡等呈现 |
| **甲壳类** | 虾、小龙虾、蟹等 | 身体与附肢线索；游动、爬行、弹跳、逃逸与底部关系 |
| **两栖类** | 蛙、蝌蚪等 | 不同发育形态；水面、水下运动与停留 |
| **蠕虫、水蛭类** | 蚯蚓、水生蠕虫、水蛭等 | 柔软细长的形态、弯曲、蠕动、漂移等 |
| **昆虫类** | 水生幼虫、若虫、成虫，以及落水陆生昆虫 | 发育阶段、漂流、上浮、水面挣扎等差异 |
| **头足类** | 鱿鱼、章鱼等 | 海水路亚中的躯体、触腕与运动呈现 |
| **特殊猎物，暂作扩展** | 鼠、幼鸟、蜥蜴等 | 特定鱼种与场景下的较大猎物呈现 |

首批设计对象为小型饵鱼、小龙虾、蛙。鱼类与Shad等子类不能重复当作独立的响应机会；具体层级仍待确定。贴底爬行、走停、抽停是呈现方式或过程，不与猎物家族并列。

## 2. 两类逻辑与数据分工

### 先走一遍：裙丝Jig＋鱼形T尾

可以先把第1步到第2步理解成：**这件饵提供哪些线索，本次呈现补充哪些线索，再分别汇总它们对各类猎物的支持。**下面使用第4节的配置与P3近底移动案例，数值只用于说明规则。

**先看装配上有哪些可用证据。**假设鱼形T尾的轮廓仍可辨认，裙丝也保留了相应线索，配置选择以下三份证据：

| 证据 | 支持哪类猎物 | 形态基值 |
|---|---|---|
| 鱼形T尾 | 小鱼 | 0.90 |
| 裙丝 | 小鱼 | 0.40 |
| 裙丝 | 小龙虾 | 0.40 |

这里保存的是各份证据自己的基值。它们是否适用，要看当前装配；不能只要部件名称出现，就无条件把证据全部加入。

**再看这次实际发生了什么。**饵侧提供近底时间比例、水平移动、裙丝展开变化等数据。它们来自实际记录或明确的代理计算；玩家按下收线键，并不直接等于“饵正在以某种速度移动”。

**随后，各条猎物解释路径读取自己需要的数据。**本例的小龙虾路径读取近底、移动和裙丝变化，得到一次动态匹配程度；小鱼的下落偏摆路径则读取下落与轨迹弯曲。两者共用执行与汇总接口，判断条件各自定义。裙丝变化只是本例选用的一项线索，其他路径可以采用不同线索。

**动态匹配只更新所属证据。**裙丝的小龙虾证据，基值为0.40，当前路径上限为0.75。完全匹配时得到0.75；匹配程度为0.20时，得到：

\[
0.40+(0.75-0.40)\times0.20=0.47
\]

鱼形T尾的0.90不会被借来充当这条路径的基值。本例近底呈现也未满足小鱼下落路径，因此裙丝的小鱼支持仍为0.40。

**最后，按猎物分别取最强证据。**在P3中，小龙虾路径完全匹配，结果为：

| 猎物 | 汇总 | 输出支持 |
|---|---|---|
| 小鱼 | 鱼形T尾0.90与裙丝0.40取最大值 | 0.90 |
| 小龙虾 | 裙丝动态证据 | 0.75 |
| 蛙 | 已评价范围内，没有适用证据 | 0 |

这表示装配同时提供较强的小鱼与小龙虾线索，无须先选出唯一身份，也无须把数值归一化。若去掉鱼形T尾并保持相同近底呈现，本例的小鱼支持会降为0.40，小龙虾仍为0.75。

动态条件不匹配时，证据保留自己的形态基值；必要记录缺失时，则保留未知或支持区间。例如缺少裙丝变化数据，小龙虾支持可能仍在[0.40, 0.75]之间，不能直接当作0.40。到这里得到的只是猎物类型支持；食物偏好、捕获难度和进食意愿留给后续节点评价。

### 饵侧呈现逻辑

饵侧接收已有的实际运动与环境记录，生成或提取这件饵特有的表现，例如下落轨迹、尾摆、裙丝展开变化。实现可以使用现有动画、配置曲线代理或必要的物理记录；不要求先自动识别Mesh或模拟每根柔性条束。

同样的操作指令，对不同装配未必产生同样呈现。停收线也不等于饵停止运动。判断应读取实际记录或明确的代理结果。

### 猎物解释逻辑

猎物侧读取形态证据与本次呈现，运行适用的解释路径，输出支持map。不同猎物可以使用不同条件、时序模式与特征，不要求共用一个几维距离公式。

### 配置关系

配置明确：这件装配选择哪些证据，证据针对哪类猎物，读取哪个对象或部位，使用哪条解释路径与参数。

| 内容 | 负责什么 | 例子 |
|---|---|---|
| 装配配置 | 选择可用证据与来源；声明已评价的猎物范围 | 裙丝Jig＋鱼形T尾，选择裙丝证据与鱼形证据 |
| 饵侧呈现配置 | 定义如何产生饵特有的运行时数据 | 相对水速到裙丝展开程度的代理曲线 |
| 解释证据配置 | 保存该份证据自己的形态基值、动态路径和上限 | 裙丝的小鱼证据基值0.40，下落偏摆路径上限0.75 |
| 运行时呈现 | 提供本次实际发生的数据 | 位移轨迹、近底比例、绑定裙丝的变化 |
| 猎物解释器 | 评价每份证据，按猎物汇总 | 分别得到小鱼、小龙虾、蛙的支持 |

来源可默认整饵。只有某条路径实际需要局部数据时，才绑定对应部位。部位组、后腿伸收等精细信息不是统一必填项。

本页算例固定形态线索可见、可辨认。遮挡、水色与距离如何改变可获得线索，尚未接入；配置基值不冒充这些效果的实时计算结果。

### 第1步交给第2步的最小数据

配置与实际记录分开传入。解释器先按装配配置知道要读哪些记录，再提取路径所需特征。

| 输入 | 具体内容与口径 | 哪些判断需要 |
|---|---|---|
| 装配快照 | 部件集合、证据绑定、适用标记、已评价猎物范围 | 选择与核验可用证据 |
| 参考长度 | 配置在装配上的固定参考长度L，单位米；不能随裙丝瞬时展开而变化 | 需要长度归一化的路径 |
| 评价窗口 | 明确起止时刻；示例为1秒 | 动态路径 |
| 主体记录 | 时间戳、三维位置，米，向上为z正向 | 下落、轨迹偏摆、水平路程 |
| 环境记录 | 与主体时刻对应的离底间距，米；由环境查询提供 | 近底比例 |
| 可选部位记录 | 时间戳、绑定部位的展开宽度，米；记录或代理应注明来源 | 使用O的示例路径 |

形态基值来自解释证据配置，不伪装成第1步已经测出的像鱼程度。只有明确形态证据的T尾或蛙形饵，可以在没有运动历史时完成本步类型解释；其历史状态仍未评价。

本原型要求所需记录覆盖窗口起止，时间戳递增，量纲一致。窗口未覆盖或必要列缺失就保留未知。样点之间采用分段线性近似，这是一项明确的数据假设，不保证任意采样频率都能识别真实细微摆动。原型未实现Unity侧记录接口。


## 3. 配置与计算规则

### 3.1 每份证据拥有自己的基值与上限

配置与计算的基本单元是一份“针对某种猎物的证据”。它可以来自某个部件，也可以来自装配后的整体轮廓。装配需要明确选择适用证据，不机械地把所有部件分数合并；例如拖尾被遮挡或组合轮廓改变后，应检查相应证据是否仍适用。

每份证据e保存：

| 字段 | 含义 |
|---|---|
| prey_type | 该证据支持的猎物类型 |
| base_support，记为b_e | 形态证据的支持基值，0～1，由策划配置并说明依据 |
| routes | 该证据允许使用的动态解释路径，可以为空 |
| pattern | 动态路径引用的判断机制 |
| support_ceiling，记为u_ej | 该路径可达到的支持上限，满足b_e≤u_ej≤1 |
| sources | 该证据和路径读取的装配、轨迹、环境或部位来源 |

b_e是人工形态近似，不是已实现的视觉分类器输出。0.40、0.75、0.90等数值均为设计值，不是生物标定。

不额外设置一个独立的“整装配基值”。需要表达整体轮廓时，将它配置为一份整体证据，与其他证据采用同一计算接口。整装配只负责选择与汇总证据。

**证据是否适用，由装配配置显式给出。**每个绑定带有适用标记与来源。选择一份证据，是作者确认当前装配确实保留了这份形态线索；不是看到部件名称就自动加入。

例如裙丝Jig加装鱼形T尾，若组合后鱼体轮廓仍可辨认，就启用tail_fish；若这份轮廓被装配形态破坏，则不启用或显式标为不适用。裙丝证据仍可保留。更换部件后重新解析装配快照，不在评价过程中改写其他证据的参数。

不适用证据不参与汇总。已启用却引用不存在的部件是配置错误，不能偷偷当作不适用。这里处理的是装配适用性；动态遮挡等感知变化尚未纳入。

**形态基值按同一猎物的参照配置。**首轮使用以下锚点：

| 情况 | 配置锚点 | 判断依据 |
|---|---:|---|
| 静态形态未提供该类型支持 | 0 | 可以仍有动态路径，不能因此提前剪掉 |
| 有相关但区分力有限的形态线索 | 0.40 | 例如本例柔性轮廓，可能支持多种解释 |
| 形态线索已较明确 | 0.90 | 例如装配中可辨认的鱼形拖尾或蛙形主体 |

这些锚点建立作者配置的一致口径，不声称是自然概率。中间值允许使用，但应说明相对哪件同类型参考呈现更强或更弱。配置依据不能使用“这条鱼更爱吃”“更容易抓”或某种操作中鱼更多；那些属于后续评价。

动态上限同样按这份证据的表达能力配置：形态不明确、某组合能加强解释时，可以从0.40增强到本例的0.75。不会因装配同时具有另一份0.90证据而抬高上限。当前小鱼与小龙虾的0.40只共享配置档位，不代表严格校准成了跨类型概率。


### 3.2 动态路径匹配

每条路径按自己的机制输出f_ej∈[0,1]。路径内部可以使用连续条件、离散条件或时序关系；具体读取哪些数据由该路径决定。

匹配为0表示这条动态组合未提供增强，不自动改换猎物类型。部分匹配提供部分增强。负证据压低形态基值的机制不在本版中；若需要否定已有类型线索，必须说明具体依据。

### 3.3 统一评价与汇总

```text
动态路径分数：
s_ej = b_e + (u_ej-b_e) × f_ej

一份证据的结果：
s_e = max(b_e, s_e1, s_e2, ...)

某类猎物的装配结果：
S_k = max(所有针对猎物k、适用证据的s_e)
```

没有动态路径时，s_e=b_e。这里的乘法只是在该份证据的基值与路径上限之间插值。max用于组合替代证据，不规定第5步响应也必须取max。

装配中更强的其他证据不会改写本证据的b_e或u_ej。例如T尾提供0.90小鱼支持，裙丝证据仍可在自己的0.40～0.75范围内计算，装配最后取最强结果。

同一份证据重复登记不会数值叠加。若两种线索确实需要联合判断，应明确配置联合证据或路径，不能靠重复枚举获得额外奖励。不同证据共用路径时，只共享机制与适用参数，不要求来源相同。

### 3.4 执行过程

```text
读取装配声明的评价范围与证据绑定
对每份适用证据：
    读取自己的形态基值
    获取已启用路径需要的本次呈现数据
    运行路径，得到匹配与该份证据的支持
按猎物类型分别汇总证据
输出每种猎物的状态、支持值与可检查的依据
```

统一执行器调用不同pattern，而非为每种商品写一个专属函数。饵侧的数据生产逻辑与猎物侧的解释规则各自复用。

运行时的顺序为：核验装配绑定 → 按路径提取所需特征 → 计算路径匹配 → 计算每份证据 → 按猎物汇总。形态基值不在运行时重新猜测；动态路径也不按“抽停”等玩家指令直接赋分。

构建装配快照时核验：来源存在，证据目标在已评价范围内，b与每条路径上限均为有效的0～1数，且上限不低于该份证据的b。校验只比较本证据的参数，不拿其他证据的分数作约束。


### 3.5 零、缺失与覆盖范围

装配须声明本模型已经评价哪些猎物。明确声明覆盖某类型、且确认没有适用证据时，才可以输出该模型下的已知零。未配置、未评价的类型标记为未覆盖，不自动填零。

必要运行时事实缺失、且可能改变结果时，保留Unknown。例如b_e=0.40、上限0.75的路径未决，则该证据结果范围为[0.40,0.75]。若另一份已知证据达到0.90，这份未决路径不影响该类型支持闭合；相应历史状态仍可能未知。

绑定引用不存在的部件属于配置错误。来源存在但必要记录未取得属于数据缺失，两者分开。

不能因为b_e=0就提前剪掉动态路径；只有最终类型支持已解析为0，才跳过该类型后续评价。首版不设置任意低支持裁剪阈值。Unknown如何影响完整响应，留到响应阶段明确。

未决路径可以用匹配区间[f_min,f_max]继续计算支持上下界：

```text
路径下界 = b_e + (u_ej-b_e) × f_min
路径上界 = b_e + (u_ej-b_e) × f_max
证据下界／上界：分别对本证据的基值与各路径边界取max
类型下界／上界：分别对适用证据边界取max
上下界相同：Resolved；否则Unknown
```

区间是缺失输入导致的可能范围，不是置信区间或分类概率。对于本页的连续AND示例，某项已知为0，就能确定路径为0；不必因另一项缺失而阻断已能确定的结果。


## 4. 配置、输入与结果对照

以下算例用于检查机制与数据关系。全部数值均为人工设计；运行时特征由样例直接提供，尚未从项目物理或动画提取。

### 4.1 两条示例动态路径

观察窗取完整1秒，L为该装配参考长度，sat(x)=min(1,max(0,x))。原型直接从带时间戳记录提取下列量，形态配置与路径参数保持不变。

| 特征 | 样例定义 | 数据来源 |
|---|---|---|
| D | 向下净位移的非负值/L | 窗内实际位置轨迹 |
| W | 轨迹到起终点连线的最大最短距离/L | 窗内实际位置轨迹；起终点重合时按距起点最大距离 |
| B | 离底间距≤0.50L的累计时间/1秒 | 轨迹与局部底部参照 |
| X | 窗内水平路程/L | 实际位置轨迹 |
| O | 指定柔性部分的展开宽度变化范围/L | 动画记录或配置代理，来源需明确 |

原型的提取方式：

- D使用窗口起终点高度差。
- W逐点计算到起终点连线的最短距离，取最大值；点到连线的投影不依赖世界原点。
- X累加相邻位置样点的水平距离。
- B按时间积分，不按低于阈值的样点数量计数。相邻两个离底样本跨越0.50L时，按线性插值求阈值穿越时刻，累加实际低于阈值的时长。
- O仅从本绑定指定的宽度记录取最大值减最小值；缺记录保持未知。

这些规则把实际记录转成可复算特征；并不要求饵侧重新实现已有的主体运动。展开宽度仍是可选的示例数据，不以细致条束系统为前置要求。


**小鱼下落偏摆：**

```text
f_fall = min(sat(D), sat(W/0.50))
```

直线斜落的W=0，不会仅因存在横向位移而通过偏摆路径。该路径不直接产生受伤或濒死标签。

**小龙虾近底附属部分运动：**

```text
f_bottom = min(
    sat((B-0.20)/0.50),
    sat(X/0.50),
    sat(O/0.15)
)
```

min是本示例的连续AND：一项很强不能无限补偿另一项不足。不要求所有猎物或所有路径都采用min。

O在这里仅用于展示“一条规则读取饵特有数据”的案例，不是所有小龙虾呈现的必要条件，也不要求首版建设精细条束系统。它测量变化而非稳定展开形态，该限制应随此示例保留，不由此推定O越大越好。

如果选择保留这条路径，O可由“实际相对水速→目标展开程度”的配置曲线与恢复时间生成，也可读取已有动画。未实现来源时，保留未决；不能补O=0，或把T尾的左右摆动振幅冒充裙丝张合。更粗的近底路径可以另行定义，但应同步重算结果。

## 5. 第3步：按猎物解释当前呈现状态

第2步回答“有哪些依据把它理解成哪类猎物”，第3步回答“如果按这类猎物理解，它现在呈现什么状态”。第3步同时读取第1步的实际记录与第2步的类型支持，不能只拿支持map继续计算。相同的0.90蛙类支持，可以对应水面移动、移动后停留，也可以对应水下下沉。

本节是设计推导，尚未加入可执行原型。以下阈值用于使规则可检查，不是生物标定值。

### 5.1 输入与输出边界

| 输入 | 用途 |
|---|---|
| 第2步的类型支持、解析状态与证据来源 | 确定需要保留哪些猎物解释；知道形态与局部线索来自哪里 |
| 第1步的实际轨迹、时间与环境关系 | 提取速度、加速度、离底／离水面距离、移动与停留过程 |
| 按需提供的水流、姿态、局部动作记录 | 区分随流漂移、姿态失衡等；没有记录就不作相应推断 |
| 猎物状态规则 | 定义该类猎物的状态判据、必要数据与时间条件 |
| 持续保存的过程记忆 | 保留移动段、停留起点与最近转换，避免滑动窗口抹掉前史 |

已解析为零的类型可以跳过；未覆盖类型仍为未覆盖。支持未知但可能大于零时，可条件性地提取状态，不把类型支持区间改成确定值。

第3步的输出保留以下内容：

| 内容 | 示例 | 含义 |
|---|---|---|
| 共用实际事实 | 世界速度0.01m/s、离水面0.01m、已低位移0.40秒 | 第4步仍可直接读取的物理量与过程量 |
| 按类型解释的状态维度 | 蛙：水面、低位移、姿态正常 | 多个维度可以同时成立，不压成一个好坏分 |
| 时序关系 | 低位移前有0.60秒移动，距该段结束0.40秒 | 表达走停、抽停等过程；保留实际时长 |
| 有依据的状态假设 | 失衡样下沉：匹配／不匹配／未知 | 由专门规则判断，附条件与来源；尚不强行配置置信系数 |
| 独立的类型支持 | 蛙0.90 | 沿用第2步结果，不乘进每个速度、时长或状态标签 |

同一件装配可以保留小鱼和小龙虾两套状态解释，但两套解释引用同一段实际呈现。不同解释不是额外生成两件猎物，也不在本步产生两次响应机会。

### 5.2 共用事实与分类型规则

先提取可复用的事实，再由各猎物规则组织这些事实。共用事实不预先包含“受伤”“惊恐”“容易抓”等结论。

| 共用事实 | 可以直接描述 | 不能单独推出 |
|---|---|---|
| 轨迹与时间 | 速度、加速度、方向变化、下落、低位移 | 游得自然、疲惫、受伤 |
| 相对水流的运动 | 随流漂移，或相对水体仍有运动 | 主动游动意图 |
| 底部／水面关系 | 近底、接触底部、处于水面、进入水下 | 近底必然爬行；下沉必然异常 |
| 实际姿态 | 侧翻、姿态恢复、持续失衡样表现 | 真实受伤或濒死 |
| 局部动作与信号 | 尾摆、裙丝变化、反光、振动、声音的实际变化 | 所有变化都表示挣扎或逃窜 |

速度至少区分世界速度与相对水体速度：v_water=v_world-u_water。世界速度可供后续捕获评价使用，相对水体速度有助于解释漂移与运动；近底判断另读取底部关系。缺水流时仍能描述世界位移，但不能据此断言相对水体静止。只有实际需要的路径才要求相应输入。

首轮三类猎物采用以下规则组织：

| 猎物解释 | 先描述的状态维度 | 需要另行判断的状态 |
|---|---|---|
| 小型饵鱼 | 水中位置关系；移动／低位移；上升／下落；姿态与转向 | 有尾摆与姿态依据才进一步描述游动；有连续失衡依据才描述失衡样运动 |
| 小龙虾 | 近底／离底；接触关系；移动／低位移；弹起与回落过程 | 仅有近底位移时称近底移动；需要接触与适用动作依据才称爬行 |
| 蛙 | 水面／水下；移动／低位移；入水与下沉；姿态 | 水面移动后停留；正常入水与失衡样下沉分别判断 |

共享接口与事实提取，不要求三类猎物使用同一套状态判断公式。规则属于猎物解释层；饵侧负责提供具体装配实际表现出的运动与信号。不同饵可以表达同一状态，但所需数据的产生方式和来源可以不同。

### 5.3 移动、停留与“移动后停留”怎样形成

先用一个明确的位移分段规则贯通流程。例中水流为零，轨迹位于同一局部参考系。根据相邻位置与实际时间差计算速度，记录视为分段线性；生产接入时需另外确定采样与滤波口径。

示例参数：进入移动的速度阈值为0.04m/s，进入低位移的阈值为0.02m/s；分别持续0.10秒与0.15秒才确认转换。两个阈值之间保持已确认状态，避免在单一阈值附近反复切换。初始无已确认状态时，保持未决，直到满足其中一个持续条件。

~~~text
连续速度≥0.04m/s达0.10秒：
    确认移动段，段起点记为本次连续满足条件的起点

连续速度≤0.02m/s达0.15秒：
    确认低位移段，段起点记为本次连续满足条件的起点
    若此前存在已确认移动段，保存它的结束与持续时间

连续条件中断：
    清除尚未确认的转换计时，保留已确认状态

已确认低位移，且最近移动段结束距今不超过3秒：
    同时保留“移动后停留”的时序关系
~~~

确认需要等待，但时长从条件开始满足时计算，不从确认时刻重新计时。3秒是本例保留短期转换关系的参数，不是所有猎物的固定记忆时长，也不直接增加响应。

这里的“停留”只指低位移，不要求尾、裙丝或腿完全停止动作；若需要判断这些局部动作，另读对应来源。相对水体低运动与世界低位移分别记录，不能混用。

“移动后停留”不是和“停留”互斥的另一个身份。输出同时保留当前低位移、持续时长、前一移动段和转换时间，后续规则按需读取。若没有前史，只能输出当前低位移、前史未知，不能补造一次停顿诱发效果。记录开始时已经在移动或低位移的，时长只表示已观测的持续时间，不推定动作恰好从记录起点开始。

运动段的记忆跨评价窗口保存。第2步的1秒窗口不强制成为第3步的全部记忆；否则连续停留超过1秒，就会错误丢失“此前移动过”的信息。缺失记录跨越转换时，不把缺口当作已知停留或已知连续运动。

### 5.4 同样0.90蛙类支持，三种呈现怎样不同

例中使用相同明确蛙形装配；观察2秒，水流为零、水面高度固定。水面与水下边界按该装配的主体参照及浸没数据配置，不直接把某个任意中心点当作所有饵的水面判据。

| 实际记录 | 第3步输出 | 此时不作的结论 |
|---|---|---|
| 全程在水面以0.20m/s移动 | 蛙0.90；水面移动；已观测移动2秒 | 不因速度较快就判为更差或更好 |
| 前0.60秒在水面以0.20m/s移动，随后低位移1.40秒 | 蛙0.90；水面低位移1.40秒；前一移动段已观测0.60秒；移动后停留 | 不把停顿直接判成受伤或额外吸引奖励 |
| 离开水面后以0.05m/s下沉，未提供姿态记录 | 蛙0.90；水下下沉；姿态未知 | 不能仅因下沉就判为异常或受伤 |

第一行没有移动后的停留关系。第二行经过0.15秒低位移确认后，保留起点与1.40秒实际时长。第三行的类型支持不因下沉自动变成甲壳类；需要的变化首先是空间与运动状态。

若确实需要“异常下沉”这一玩法语义，先将它收窄为有可见依据的“失衡样下沉”。例如对本例正常保持背部向上的蛙形呈现，配置：下沉速度至少0.02m/s，同时主体侧翻角绝对值大于60度（绕前后轴的滚转，不能用低头入水的俯仰角代入），二者共同持续至少0.20秒，才匹配“失衡样下沉”。这里检查持续侧翻，不能把正常低头入水等同于侧翻；其他形态需要自己的姿态规则。这些阈值仍是可替换的设计假设。

缺少姿态数据、且可能改变结论时保留未知；若已经确认没有下沉，就可排除这条组合，不因姿态缺失一律未知。单纯下沉且姿态正常时不匹配。

即使匹配，也只表示呈现了失衡样线索，不证明真实生物受伤。不要求首版为了这个可选规则新增姿态采集；没有这些输入时，基础的水下下沉描述仍然有效。

### 5.5 走停、抽停如何进入本步

走停、抽停是产生过程的操作方式，运行时不按操作名称直接贴状态标签。

- 走停：实际轨迹产生移动段与低位移段，记录两段时长及转换。若水流仍推动饵，停收线可能只形成减速或漂移。
- 抽停：实际轨迹可能产生短促加速、转向或姿态变化，随后停留，也可能继续下落；按实际发生的序列保存。
- 若需要识别“短促加速后下落”等复合状态，就明确配置先后次序、各段判据与允许间隔，读取持续记忆。只用一个窗口平均速度无法替代这些关系。

例如，为小鱼或蛙配置一条“短促提速后停留”规则：已知速度从不超过0.04m/s在0.15秒内升到至少0.20m/s，随后在到达该高速阈值后的0.50秒内降到不超过0.02m/s，再维持低速0.15秒，才确认该过程。必须保存这个有序事件，不能只检查窗口里同时出现过高速和低速；若中间记录缺失而不能确定顺序或时限，就保留未知。该规则可用相对水体速度，但来源必须完整；不能悄悄换用世界速度。

这些条件只识别短促提速后的停留，不直接证明惊恐逃窜。反光、声音或振动也只有进入某条明确状态规则时才参与，不能一律转换为受伤或惊恐分。

### 5.6 交给第4步什么

第3步交付类型支持、共用实际事实、分类型状态、时序关系和依据，不提前算可得程度或响应强度。鱼侧再结合食物价值、鱼的位置与运动能力、摄食意愿，评价这些呈现。

例如水面移动转为停留，已确认的速度下降可以在第4步降低追赶要求；不必再给“移动后停留”一个自动奖励。只有另有明确机制需要解释这种时序关系时，才引入独立作用，并说明它与速度下降有何不同。

同一事实可以服务不同问题：近底运动可在第2步支持小龙虾解释，在第3步描述近底移动，在第4步影响接近或捕获要求。重复读取事实允许；重复添加同一种“更像”“更容易抓”的收益不允许。

第2步的max只汇总类型证据，不删除第3步所需的其他真实记录。第3步也不把S_k再乘入速度、时长或每个状态标签；支持如何影响最终响应，留到第4、5步共同确定。

### 5.7 最小数据契约

这里约定数据语义，不固定编程语言、类名或序列化格式。首轮只要求支持上文已有的状态规则，不先建立完整行为分类库。

| 数据组 | 最少包含 | 约束 |
|---|---|---|
| 帧标识 | 饵实例、呈现连续段ID、装配版本、评价时刻 | 第1步记录与第2步结果必须对应同一实例、版本和时刻；不能拼接新记录与旧支持 |
| 共用事实 | 值、单位／参考系、有效时段、来源、解析状态 | 速度须说明世界／相对水体；时长须说明精确起点还是仅已观测下界 |
| 类型结果 | 猎物键、原样保留的类型支持及状态、是否执行状态评价 | 已知零可跳过；未覆盖仍为未覆盖；支持未决时状态按该类型条件性计算 |
| 状态维度 | 空间关系、移动状态、垂直趋势；按需增加姿态等 | 按维度保留结果，一项未知不抹掉其他已知项 |
| 过程结果 | 模式ID、规则版本、匹配状态、事件起止／关键时刻、来源 | 不把缺少规则写成不匹配；不把缺记录写成零 |
| 持续记忆 | 最后处理时刻、各来源最后有效样点、候选转换起点、已确认分段、边界是否已知、近期事件及有效期 | 是执行所需数据，不是额外吸引力参数 |

数值事实和状态维度分别使用已解析／未知／未配置。未配置表示本轮没有启用相应数据或判断，不是输入缺失的替代值。过程规则另外区分匹配、不匹配、未知、未配置：配置了规则且已知条件排除时才是不匹配；必要数据缺失且可能改变结论时为未知；没有注册相应规则就是未配置，不得猜一个结论。

“水面／水下”与“近底／离底”分开表示，不能放进同一个互斥枚举：浅水中的饵可以同时处于水面且近底。移动、垂直趋势和姿态也分别保留。离水面、离底等连续值同时保留，避免后续只剩标签。

事件的开始与结束标记对应实际满足条件的时间；另存确认时刻。开始前史不全时，持续时间只给已观测下界。例如记录从移动中途开始，观测0.60秒后停留，可以确认“此前有移动”，但不能声称完整移动段恰好只有0.60秒。

5.4第二行在t=2秒时，交付的语义为：蛙支持0.90；水面；当前世界低位移；低位移自t=0.60开始、t=0.75确认、持续1.40秒；此前至少观测到0.60秒移动；近期移动后停留匹配。低位移期间的腿或裙丝动作仍可另有记录。

### 5.8 持续记忆、缺口与装配变化

共用运动记录与分段不因某类猎物本帧支持变为零就停止维护。某类解释稍后重新进入时，读取仍在保留期内的事实与事件，不能把“现在开始评价该类型”误当作“现在开始运动”。

首轮按已启用规则的最大回看时长保存必要记录或等价摘要。移动／低位移分段持续维护；本例近期移动后停留关系取3秒，其他复合规则使用自己的时限。新增规则时要声明所需历史，不能读取不存在的完整前史。

| 情况 | 处理 |
|---|---|
| 正常连续更新 | 按时间顺序处理新记录，保留候选计时、分段和必要事件 |
| 重复／重叠输入 | 按时间游标去重，不重复累计时长或重复生成事件；同一来源同一时刻若值冲突，报告输入错误 |
| 乱序记录 | 首轮报告输入错误，不悄悄重排并修改已输出历史 |
| 数据中断 | 中断需要连续性的计时；当前相关状态保持未知，直至新记录足以重新确认；内部旧状态不冒充当前已知值 |
| 缺口之后已有足够新记录 | 可恢复当前移动／低位移判断；涉及缺口的前后关系仍未知，除非后续完整事件或已知排除条件使结果闭合 |
| 换拖尾或装配版本变化 | 重新绑定证据与局部来源，失效的局部计时和事件清除；同一主体连续轨迹可保留，但跨越变化的类型过程不沿用，除非规则明确与装配变化无关 |
| 新抛投、瞬移或主体实例更换 | 开始新的呈现连续段，旧段事件不跨入新段 |
| 因整体坐标重定位而跳变 | 先由上游恢复同一参考系，或声明连续段中断；不能把坐标跳变识别成爆发运动 |

上游必须声明哪些时间区间有有效连续记录。首轮原型采用分段线性记录语义，允许的插值区间需明确；不凭长间隔两端的位置相等就认定中间静止。生产采样最大允许间隔与滤波方案尚未确定，不在此伪造一个通用常数。

“移动后停留”的3秒规则具体表示近期关系：当前已确认低位移，且最近移动段结束距今不超过3秒。超过3秒后，该近期模式不匹配，当前低位移及其时长继续保留。若回看范围有可能改变结论的缺口，结果为未知；若已知当前正在移动，则可直接排除该模式。

### 5.9 首轮状态覆盖与验收案例

首轮覆盖以下可交付范围：

| 判断 | 覆盖情况 |
|---|---|
| 实际速度、移动／低位移、垂直趋势、环境距离 | 共用事实；由所需输入是否齐全决定解析状态 |
| 小鱼／小龙虾／蛙的基础状态 | 各自组织空间、运动与过程维度，不新增综合好坏系数 |
| 近期移动后停留 | 使用5.3的连续分段与3秒近期条件 |
| 短促提速后停留 | 使用5.5的有序阈值规则；按配置选择适用类型与参考系 |
| 蛙的失衡样下沉 | 使用5.4的下沉与侧翻持续组合；姿态来源为可选输入 |
| 完整爬行、惊恐逃窜、真实受伤／濒死解释 | 尚未配置；不把这些名称当作已有可执行结论 |
| 可得程度、feeding motivation、食物价值与最终响应 | 第4、5步，不在状态解释中提前结算 |

为避免垂直趋势仍只剩字段名，示例另约定：以向上为正，垂直速度≥0.02m/s持续0.15秒确认上升，≤-0.02m/s持续0.15秒确认下落；绝对值≤0.01m/s持续0.15秒确认垂直低运动。阈值之间保持已确认趋势，初始则未决；同样区分起点、确认时刻与已观测时长。失衡样下沉规则的0.20秒组合仍独立检查，不能仅凭一个下落标签代替。

以下是待执行的验收向量，不是已通过的测试。除特别说明外，记录连续、所需来源齐全，水流为零，使用本节示例参数。

| 案例 | 输入要点 | 必须得到的结果 |
|---|---|---|
| A 持续移动 | 蛙支持0.90，水面0.20m/s持续2秒 | 水面移动；近期移动后停留不匹配；完整开始时间未知时只报已观测时长 |
| B 移动后停留 | 同A，前0.60秒移动，后1.40秒速度为0 | t=0.75确认低位移，但起点为0.60；t=2时持续1.40秒，近期关系匹配 |
| C 停留超过近期时限 | 同B，停留延长至3.40秒 | 当前低位移持续3.40秒；3秒近期模式不匹配，不重置为移动 |
| D 只有停留前史 | 记录开始即速度0，至t=0.20 | 确认低位移；移动前史未知，不能生成一次移动后停留 |
| E 阈值间波动 | 已确认移动，随后速度在0.025～0.035m/s波动 | 保持移动分段，不反复制造走停；实际速度照常输出 |
| F 下沉与姿态缺失 | 蛙0.90，水下以0.05m/s下沉，无侧翻记录 | 下落可解析；失衡样下沉未知；不改写类型支持 |
| G 正常姿态下沉 | 同F，侧翻角为0 | 失衡样下沉不匹配，水下下落仍保留 |
| H 持续侧翻下沉 | 同F，侧翻角75度，组合连续0.25秒 | 失衡样下沉匹配；不输出真实受伤或额外响应奖励 |
| I 停收线仍漂移 | 世界速度0.10m/s，与水流速度相同 | 世界移动、相对水体低运动；不因操作停止而贴世界停留标签 |
| J 记录缺口 | 移动记录与后续静止记录间声明无数据 | 不把缺口累计为停留；新记录可重新确认当前低位移，跨缺口转换未知 |
| K 类型重新进入 | 某类型暂时支持为零，其间主体完成移动后停留；1秒后支持恢复 | 从共用连续记忆恢复近期关系，不伪造新的运动起点 |
| L 新抛投 | 前一抛投存在移动后停留，随后开启新连续段 | 新段不继承旧事件；初始前史按实际记录处理 |
| M 同时支持两类猎物 | 同一段近底轨迹，小鱼0.90、小龙虾0.75 | 两套状态解释引用同一事实来源；不自动变成两次响应 |
| N 复合过程次序 | 速度0在0.10秒内升至0.25，0.20秒后降至0，再维持0.20秒 | 短促提速后停留匹配；同样高低速若顺序相反或间隔超限则不匹配 |
| O 改变分批方式 | 同一连续记录整段送入与切成连续小批送入 | 最终分段起点、时长与事件结果一致，重复批次不重复计时 |
| P 浅水与局部换装 | 饵同时近底且在水面；随后替换裙丝来源 | 两种空间关系可共存；旧裙丝事件不沿用，新证据版本与当前帧一致 |

下一轮优先把这些案例做成只覆盖第3步的独立原型，检查契约、连续处理与分类型规则。保留第1～2步既有原型及结果，必要时通过同一帧标识串联；先不实现第4、5步，也不要求为未覆盖状态建设精细物理系统。原型通过后，再讨论哪项状态确实改变了玩家判断、哪些字段需要删减，以及第4步怎样使用这些结果。
