# 走停与抽停：同位移轨迹推算

日期：2026-10-23  
状态：Development 算例与失败记录，不是已采纳的节奏规则或生物学标定。  
代码：[temporal_presentation_probe.py](../../prototypes/lure-response/temporal_presentation_probe.py)。沿用[主文](lure-feeding-target-interpretation.md)的状态表、激励、代价和响应公式，不修改主探针。

## 1. 本轮计算什么

固定 8cm 鱼形悬停米诺，只支持小鱼解释；H=0.6、p=1、大小价值 F=1。比较四种实际速度轨迹。名称只用于阅读，计算不读取“抽停”等标签。

鱼固定在原点，饵从距离0.20m开始沿水平方向远离。d 随实际位移增加，不能一边设 v_away>0 一边保持 d 不变。两秒结束时四种轨迹均移动0.20m，距离均为0.40m。V=0.45为主要对照，V=1另算；V是代价尺度，不是最大游速。未模拟鱼的接近、追随或注意变化。

| 轨迹 | 两秒内实际速度，m/s | 总位移 |
|---|---|---:|
| 匀收 | 0～2秒保持0.10；此前静止，t=0发生启动 | 0.20m |
| 走停 | 0～0.25秒线性升至0.20，保持至1秒；1～1.25秒降至0，此后停顿 | 0.20m |
| 单次抽停 | 0～0.10秒升至0.80，保持至0.25秒；0.25～0.35秒降至0，此后停顿 | 0.20m |
| 高频重复抽动 | 每0.50秒一次三角速度脉冲：0.05秒升至1.0，再0.05秒降至0；共4次 | 0.20m |

最后一项是规则的高频压力测试，不等于已经模拟了随机“乱抽”。不同中间时刻的距离并不一致；同总位移仅控制总路程，不消除路径与几何影响。

## 2. 时序输入怎样产生

主文已有 e=(j/L) exp(-age/1秒)，本轮不另乘一个运动记忆奖励。为处理多事件，本适配器明确采用“最强的已衰减事件”：

```text
固定线索采样间隔 h=0.05秒
J_n = abs(v(t_n)-v(t_n-h))/L
e_n = max(e_previous × exp(-elapsed/1秒), J_n)
样点之间 e 按相同时间常数衰减
```

初始速度历史已知为零；加速与减速都产生事件。这里只是一维速度变化，没有转向模型。J依赖明确的固定线索采样间隔，不声称换任意采样间隔仍保持相同识别结果。动力积分步长可以独立改变。

这是新增的输入适配假设：单事件时与既有 j、age 表达一致；多事件采用最强衰减残留，不是默认只保留最后一次。它会丢失事件数量、方向和部分先后关系，尚不能表示所有复合节奏。

把 j=e×L、age=0输入旧探针，其余公式不变：

```text
x = [ln(1+v/L), ln(1+e), vertical_v/L]
最近状态 → Q和g
B = 0.6 × Q × g
E = 0.5 × ((d/1秒 + v_away)/V)²
U = max(0,B-E)
R = U/(1+U)
```

近期事件既可来自启动也可来自制动；不能把它直接叫作受伤证据。状态名“短促动作后停留”仍只是本项目的人工样本标签。

## 3. 单次抽停逐时刻算例

主要对照 V=0.45。以下时间从抽动启动计。

| 时间s | 速度m/s | 距离m | e | B | E | R |
|---:|---:|---:|---:|---:|---:|---:|
| 0.10 | 0.80 | 0.24 | 5.000 | 0.183 | 2.671 | 0 |
| 0.35 | 0 | 0.40 | 5.000 | 0.907 | 0.395 | 0.339 |
| 0.50 | 0 | 0.40 | 4.304 | 0.909 | 0.395 | 0.340 |
| 1.25 | 0 | 0.40 | 2.033 | 0.758 | 0.395 | 0.266 |
| 1.50 | 0 | 0.40 | 1.583 | 0.680 | 0.395 | 0.221 |
| 1.65 | 0 | 0.40 | 1.363 | 0.632 | 0.395 | 0.192 |
| 1.66 | 0 | 0.40 | 1.349 | 0.417 | 0.395 | 0.021 |
| 2.00 | 0 | 0.40 | 0.960 | 0.478 | 0.395 | 0.077 |

0.50秒的示范：B=0.9093，E=0.3951，U=0.5142，因此R=0.3396。短促运动信息仍在，而当前径向追赶要求降低，二者确实能通过现有结构同时影响结果。不是把移动阶段与停顿阶段的响应相加。

但激励优势的一部分由旧表 g=1.517 人为给定；本算例只显示这份假设如何工作，不证明抽停自然具有该倍数。

## 4. 四种曲线的诊断

下表的时间均值为两秒内 R(t) 的梯形积分除以时长，只描述曲线，不是复合动作的总响应、中鱼率或行动判定。峰值也不作为动作评分；走停与抽停的初始静止点会影响峰值。

| V | 轨迹 | R时间均值 |
|---:|---|---:|
| 0.45 | 匀收 | 0.0000 |
| 0.45 | 走停 | 0.0807 |
| 0.45 | 单次抽停 | 0.2028 |
| 0.45 | 高频重复抽动 | 0.2487 |
| 1.00 | 匀收 | 0.1436 |
| 1.00 | 走停 | 0.2965 |
| 1.00 | 单次抽停 | 0.3312 |

V=0.45时匀收为零，是本次速度、距离、状态样本及代价参数共同导致的结果，不能外推为匀收无效。尤其0.10m/s的移动被最近样本归为“停留”，暴露现有状态表稀疏，标签不能当作生物判断。

## 5. 推算没有通过的地方

### 最近状态切换产生假跳变

1.65～1.66秒之间，位置与速度完全不变，e平滑衰减；最近状态从“短促动作后停留”切到“停留”，g从1.517换成1.0，导致R从0.192突然降到0.021，随后又逐渐回升。

这是状态离散切换造成的结构问题，不能解释为鱼突然改变主意。原有单点算例没暴露它。下一轮应让类型内部的状态评价连续化，再检查整段暂停；猎物类型支持及跨类型max无需因此改成分类概率。

### max事件残留不保证合理节奏

同样总时长、同样总位移，高频重复抽动可以持续刷新e，时间均值高于单次抽停。max避免了事件数值相加，却没有消除刷新收益。该结果本身不证明高频操作不该有效，但不支持“已经排除无条件重复抽动占优”的结论。

不能临时加一个“乱抽惩罚”来修饰排序。应先检验连续状态评价、不同强度与间隔、采样尺度及实际行动要求，再决定是否确实缺少机制。

### 不能从局部曲线推出最优停顿长度

停顿初期的R较高不等于整次操作更容易中鱼。鱼的注意、追随、是否已采取行动，以及观察窗口与机会结算尚未接入。对所有时刻取max会忽略持续时间；逐帧独立抽签会依赖帧率；直接积分也需要明确行动率的量纲。此轮均未采用。

## 6. 验证与下一步

代码验证四条轨迹总位移相同、所有时刻保持已解析；固定0.05秒线索采样，将积分步长0.01秒减半至0.005秒，共同时刻的距离、e及R在1e-10内一致。这只验证本组对齐的分段线性轨迹，不代表采样频率无关。

另将状态跳变与高频刷新结果记录为缺陷／风险复现检查，检查通过不代表玩法验收通过。所有参数为人工设计值。

下一步优先修正类型内部的硬状态切换，并保留本页原始结果对照。之后再推停顿长度、重复间隔和鱼行动的连接；不先扩充动作名称表。
