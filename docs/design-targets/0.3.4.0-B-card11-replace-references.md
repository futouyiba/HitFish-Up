## 1. 帧清单与逐字文案

### 态1｜选 A → 选 B（发起换绑候选）

- **验证的 interaction topology**：卡11 Actions「选 A → 选 B → 将本次换绑候选交共享N2预览／确认，提交只执行下述直接绑定 mutation」；B 侧只列合法 ACTIVE 模板（汇编 §14「归档后…不可新建引用」＋卡9 Must not「普通 Source Picker 按该节隐藏／降级归档项」；断链侧汇编 §8「禁止任何自动 fallback…必须由作者显式选新的合法来源」）。
- **帧内控件／文案**：

| 节点 | 文案（逐字） |
|---|---|
| `[st]` | `换绑 · 模板 A → 模板 B` |
| `[rs]` | `只重写 DirectReferenceSet(A) 的 durable 绑定` |
| `[a]` | `模板 A｜类型名 A（示意）· ROCK 0.40 · 直接引用 12` |
| `[b]` | `模板 B｜类型名 B（示意）· ROCK 0.55` |
| `[bl]` | `B 侧只列 ACTIVE 模板 —— 归档不列、不 fallback、不自动找相似` |
| `[n1]` | `候选交共用N2 预览／确认；提交只执行直接绑定 mutation` |
| `[n2]` | `不自动 pin；不为维持旧 Effective Value 生成 SET` |
| `label` | `态1｜选 A → 选 B（发起候选 · B 只列 ACTIVE）` |

### 态2｜预览分区：直接改绑对象 × 有效影响对象（复用共用N2）

### 态3｜提交后：patch 保留 · 无新增 pin

## 4. 验收判据

**状态齐**：
1. 三态齐备（发起／预览分区／提交后）；组名含「（三态）」。
2. 态2 两分区标签各 ≥1 枚；四统计四节点分列。

**动作走通**：
3. 态1 → 态2 → 态3 的候选链在帧序可读；态2 `[n3]` 复用声明指向共用N2 组（跨组抽查：N2 组已在 `#62` 批落地；`#63` 批不得改动它——邻居判据）。
4. **态2 分区一（`[p1]` 及其子行）内「经继承」0 命中**——证「继承 child 不进直接改绑分区」。

**异常有落点**：
5. 态3 三类消费者行齐：直接绑定＋op 保留／经继承＋无新增 sourceOverride／已有 SET 保留·结果未变；`[n1]`「受遮罩未变 ≠ 无影响」句在。
6. 态3 `[n3]` 的三否定（不自动 pin／不保值 SET／同值不改拓扑）逐字在。
7. 态1 `[bl]` 归档约束句在。

**annotation／证据**：
8. 三帧 annotation 四段齐、`⚑UNIMPL（GAP 号待补）` 在、锚点命中、`&` 计数＝0 报原始数。
9. 整组回读邻居未变（含共用N2 组与卡10 组——本批未动它们的证明）；节点数 Δ＝新建数；新增宿主按区域枚举探针覆盖。
