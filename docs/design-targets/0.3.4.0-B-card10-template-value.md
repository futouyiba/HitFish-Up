## 1. 帧清单与逐字文案

### 态1｜模板完整值编辑（水温载体 · 候选态）

- **验证的 interaction topology**：模板是**完整值资产**、编辑面**不出现操作语义控件**——卡10 Actions 逐字「⚠️ **本卡不出现 `ADD`／`SET`／`CLEAR` 这类 operation 语义** —— 模板是**完整值资产**，**operation 只存在于物种 Recipe 与桶 patch 上**」。
- **帧内控件／文案**：

| 节点 | 文案（逐字） |
|---|---|
| `[st]` | `模板 · 水温 · 类型名 T（示意）` |
| `[rs]` | `完整值资产 —— 编辑面不提供操作语义控件` |
| `[p1]` | `temp_accept_min 20.0` |
| `[p2]` | `temp_fav_min 24.0` |
| `[p3]` | `temp_fav_max 26.0 → 28.0（候选）` |
| `[p4]` | `temp_accept_max 25.0` |
| `[p5]` | `temp_threshold 0.50` |
| `[p6]` | `falloff_shape LINEAR ▾` |
| `[cur]` | `曲线（只读）—— 不支持拖拽编辑；参数仍按项编辑` |
| `[use]` | `temp_threshold 用途｜供 CORE 消费者门控使用（共享模板无唯一当前 Role）` |
| `[tag]` | `候选（未确认）` |
| `[n1]` | `operation 只存在于物种 Recipe 与桶 patch，不进模板` |
| `[n2]` | `水温曲线只读 ≠ 温度档案不可编辑` |

- 参数行用**字段位长形标签**（`temp_accept_min` 等）＋ `falloff_shape` 显示标签，按卡3 两层名规定（项名位 `falloff`／字段位显示 `falloff_shape`，两处各按其位）。

## 4. 验收判据

**状态齐**：
1. 四态齐备且对应 `#62` 四阶段（候选／预览／确认后／Publish）；组名含「（四态）」。
2. 态1 参数六行齐（5 数值＋1 枚举）；`[p6]` 值段文本以字面 `▾`（U+25BE）结尾——沿画布下拉值惯例（档位 chip `Custom ▾`、来源 picker `未选 ▾` 均字面形；Role 角标的矢量 `roleCaret` 属另一控件族，不适用此判据）；无「调整」入口控件。

**动作走通**：
3. **态1 控件行**（`[p1]`–`[p6]`、`[btn]` 类节点）内操作词「仅使用来源／调整／设置为／INHERIT／ADD／SET／CLEAR」**0 命中**；说明行（`[n1]`）允许出现且必须处于否定语境（「不提供」「只存在于…不进模板」）——判据按「控件行 0 命中＋说明行否定语境」两段执行，不做全文 0 命中。
4. 态2 有「进入影响预览」入口与指向共用N2 组的 `[ref]`；帧内四统计词 0 命中（正文不复制）。
5. 态4「Publish」与 N2 组态4 的「确认变更」不在同一容器／不是同一按钮（跨组抽查）。

**异常有落点**：
6. 态3「已保存 · 有错误」「ERROR」「Publish 阻断」三要素并存；帧内文本节点「保存失败／保存 I/O 失败」0 命中（探针面＝帧文本节点，不含 annotation——「诊断不呈现成保存失败」的摘要在态3 annotation，属规则住所）。
7. 态4 `[blk]` 阻断态给出「进入校验清单」出口（对应卡6 校验节定位）。

**annotation／证据**：
8. 四帧 annotation 四段齐、`⚑UNIMPL（GAP 号待补）` 在、锚点可命中、`&` 计数＝0 报原始数。
9. 整组回读邻居未变（尤其相邻的共用N2 组与 A②-卡12 组）；节点数 Δ＝新建数；新增宿主用按区域枚举探针覆盖。
