## 4. 验收判据（writer 落完后怎么验）

**状态齐**：
1. 四态齐备，`label` 文案与帧内 `[st]` 对应；组名含「（四态）」。
2. 态2 帧文本中四统计词（`直接引用数`／`Effective consumer 数`／`最终结果变化数`／`新增 Error·Warning`）**0 命中**——证「Local 无伪造全局统计」。
3. 态3 四统计词**各 ≥1 命中**且分列为四个独立文本节点——证「分列」而非并串。
