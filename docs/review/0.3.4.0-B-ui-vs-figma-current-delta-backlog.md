### 顶栏 topbar

**T1 · Publish 入口与 preflight 缺失**（控件/行为类）
- 位置：Figma 顶栏 btn_Publish（'Publish'，作者面/模板面 actions=full 五帧都有）；编辑器 [index.html · 顶栏按钮（#btnReset／#btnExport／#btnPreset）](../../../preCompute/FishHabitEditor-0.3.4.0-b/index.html) 无顶栏 Publish，工作区已有 `#publishBar` / 写回通路（`app.ts` `runWriteBack`）。
- 目标：顶栏显示 `发布到生产配置…`，**只进入 / 聚焦 canonical Publish 区，不直接 writeback**；唯一 executor 留在 Publish 区。顶栏 Autosave 文案明确为 `编辑器已保存 / 编辑器已保存 · 有错误 / 编辑器保存中… / 编辑器保存失败`。
- Publish preflight：最新 Editor state 已 durable、full validation 无 blocking ERROR、整组 Production generation 可验证且未变化。Generation mismatch / unverifiable 均 BLOCK，不 auto-merge；成功写回后重新读取**整组 Production generation**作为下一次 baseline（当前实现为 7 本工作簿同刻度身份）。Partial failure 不得显示成功，也不得按 target 拼 baseline，必须先重读整组 generation。
- V1 不要求 `有未发布修改`、last-published diff 或 durable Publish History。
- 量级：**控件/行为级** ｜ 可开工度：**现在就能改**——产品语义已闭合；不得另造第二套顶栏 executor。
