## 二、审什么（七条，按优先级）

**总原则**：Figma 是**执行投影**——它要"照着契约画"。所以每一条都是同一句话的两种问法：**该画出来的画了没有？画出来的有没有画成别的意思？**

1. **Structure 的表示**（`108:311`）：选中 Structure 后是否在**右侧 460px 焦点编辑栏**、以**2 列紧凑字段控件**编辑？**有没有残留 5×5 卡阵的形态**（该形态已作废、已移入归档页）。
2. **五支用户语言**（`A①-卡2` 组内 **态9**）：物种层「仅使用来源／调整／设置为」＋ Affinity 层「沿用物种调整／沿用物种设置为／仅使用当前来源／调整／设置为」是否画全？
   - **「沿用物种调整／沿用物种设置为」是随实际继承到的操作变化的** —— 图上有没有把这个**动态形态**表达出来？
   - 是否做到**不显示泛称「沿用物种操作」**？
   - ⚠️ 该帧已自标**「取值是示意、非规定」**，且写了"另一支同理" —— **请核这个标注是否足够**（会不会仍被当成规定读）。
3. **`CLEAR` 那一态的区分度**（**态10**）：它必须在行内可见「**移除了哪条继承操作**」（图上用删除线表示视觉降级），**且不许只靠文字两字之差**与「本层什么都没表达」区分。
   - **请判**：单看这一帧，作者能不能分清 `CLEAR` 与「本层无表达」这两态？**若不能，指出缺什么。**
4. **两种密度**（**态10**）：折叠＝字段名／操作摘要／Effective／Diagnostic；展开＝当前来源／被替代的上级操作／本层操作／Effective／provenance 算式。**字段集是否齐**？是否**原地展开、没有二级 drawer**？
5. **校验分级配色**：`<0` 的 ERROR 与 `>1` 的 WARNING **都应为红标**（分级靠文案与阻断性，不靠颜色）。核这两处是否已改红；**同时核「注意类」的琥珀色 badge 没有被误改**（它们不是校验分级）。
6. **Policy 不是第五张习性卡**（`组件集 SpatialOpportunityPolicy`）：它应是**策略区块**（表格／规则行），与习性组件的**布局与控件结构**明显不同，**颜色只辅助**。**核它有没有靠"只换个颜色"来做差异。**
7. **记号与自洽**：
   - 未实现/未核是否都标了（`⚑UNIMPL（GAP-ED-NN）` ／ `⚐UNVERIFIED` ／ `⏸BLOCKED`）？**「未标」不得被读成「已实现」** —— 有没有该标而没标的？
   - **有没有把沿革画进 Current**（"原来…后来改成…"这类）？
   - 图上的说明**应是 annotation、不是 comment**；有没有说明被画进了画面主体？

## 三、输出格式（与材料侧同一套）

```
ID: FIG-01
范围: node id + 帧名（**指到具体节点**，不要只说"某帧"）
严重度: BLOCKER | MAJOR | MINOR | NOTE
类型: 与契约相抵 / 缺 / 表达不清 / 记号缺失 / 沿革混入 / 其它
依据: 契约侧的逐字（`component-contract-consolidated.md` 的小节）／或卡片侧逐字
建议: 一句话；**不写实现方案、不动手改**
```

**四条纪律（同材料侧）**
- **逐条给出处**；给不出出处的结论**标「未核」**。
- **发现相抵先报、不要自行调和**（"两侧各有可取、合成新形态"这类结论不要你自己下）。
- **不许发明新术语、新标识符、新机制**。
- **不要重述你认同的部分**，只报问题。

**末节 `总评`**：三句以内，只回答 **"这套投影现在能不能作为实现依据"**（能／不能／在哪一条上不能）。
