## 这三样东西的关系
**契约**＝"现在是什么"；**冻结卡**＝"实现按这个做"；**Figma**＝"图上现在画了什么"。

## 两件必须说清的事
1. **本目录是派生物，不是权威**。冲突时以项目内的 Current 文档与裁决记录为准；**本目录不含任何内部链接**（按项目对外规则，内部链接一律不进仓），因此读者只能按**内容自洽性**审。
2. **材料里的 `《页名》§N` / `记录页 §N` / `冻结卡 `A①-卡N`` 是项目内载体的引用**，在本目录里读不到 —— 遇到这类引用，**审"这句话本身是否自洽"，不要去核出处**；若某条离开出处就不可判，用 `NOTE` 标出来即可（那本身是有用的信号）。
