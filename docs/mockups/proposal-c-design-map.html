Proposal C / working design

鱼有多愿意出手，取决于还剩多少余量

一次实际呈现先被解释成猎物和状态，再换算成五个评价项：食物价值、攻击诱因、追赶负担、风险顾虑和摄食意愿门槛。它们的净值决定响应；机会量与响应相乘一次，进入候选。参数仍是 Working，不是生产规则。

出手余量

值得出手的理由，减去需要承担的代价 各子机制先换算到同一标尺，顶层只做竞争

增加余量

  • 食物价值：这个目标本身值不值得吃
  • 攻击诱因：当前猎物状态是否额外促使出手
−

减少余量

  • 追赶负担：当前呈现对这条鱼有多难追
  • 风险顾虑：当前呈现有多容易露馅
摄食意愿门槛 Motivation 不是奖励项，而是移动出手门槛；极高 Motivation 只额外提供很窄的 tail relief 
出手余量
= 食物价值
+ 攻击诱因
- 追赶负担
- 风险顾虑
- 摄食意愿门槛

响应 = clamp(余量 / 0.40, 0, 1)   # Working M0=0, M1=0.40

预测困难当前不在第一版主体内。它是否值得作为独立局部代价，留待证明：只有在控制其它因素后仍能产生稳定排序，才重新加入。

  1. 实际呈现位置、轨迹、速度、停顿、环境关系，带来源和状态

  3. 猎物解释support 是贡献保留比例，不是概率

支持度怎么合成

每份证据有自己的形态基值，动态路径只在基值与上限之间插值；同一猎物的多份证据取最强，不逐个相加。

sat(x)   = min(1, max(0, x))
路径分数 = 基值 + (上限 − 基值) × sat(动态匹配)
一份证据 = max(基值, 各路径分数)
某类猎物 = max(各适用证据)

例：裙丝 Jig + 鱼形 T 尾，近底移动
小鱼   = max(裙丝 0.40, 鱼形 0.90) = 0.90
小龙虾 = 裙丝 0.40 + (0.75 − 0.40) × 1.0 = 0.75

缺记录不是零：若裙丝展开变化未取得，小龙虾支持变成区间 [0.40, 0.75]；小鱼的 0.90 已闭合，不受影响。未评价的猎物类型保持未覆盖，也不自动填零。

每一项购买什么策略

鱼情变化改变收益和代价，玩家因此换打法，而不是只换一个系数
评价项回答的问题玩家选择
食物价值这个目标本身值不值得吃广谱泛用，还是高匹配专攻
攻击诱因当前猎物状态是否额外促使出手普通自然呈现，还是强诱因反应口
追赶负担当前呈现对这条鱼有多难追快速搜索，还是慢速精细
风险顾虑当前呈现有多容易露馅直接强势，还是隐蔽自然
摄食意愿现在需要多强的理由才愿意出手门槛高低决定普通口够不够用

每项怎么算

Working 形式；系数与 tail 参数仍待标定
评价项Working 合成
食物价值clamp(BaseDietAffinity + SizePreferenceAdjustment + DietaryShiftDelta, 0, 1)
攻击诱因TriggerBudget × TriggerIntensity，预算约 0.10~0.15
追赶负担K_close × u_close² × ActivityCostMultiplier，其中 u_close = max(0, q·cosθ)
风险顾虑K_wary × Wariness × SuspicionLoad
摄食意愿门槛M ≤ 0.8: 0.60 − 0.40M；M > 0.8 再减 0.50(M − 0.8)

食物价值不用多个匿名乘数连乘；活动度只改追赶倍率，不改速度上限；风险顾虑只放大已解析的可疑线索，没有线索就不凭空处罚。

从余量到候选

C(θ)      = clamp(余量 / 0.40, 0, 1)      # 每个方位先算，再聚合
C_prey    = support × E_θ[C]
L_feed    = max(L_i)   U_feed = max(U_i)   # sibling 区间
C_feed    = 标量，仅当 L_feed == U_feed
q         = L × C                          # 只乘一次，进入候选

区间没有收敛时保持 ResolutionIncomplete，携带上下界，不进入 roll；不能拿已知下界冒充最终值。机会量 L 由机会侧给出，时间与停留只影响 L，不回写余量。

状态不是零

  • Unknown必要事实缺失，结果可能改变。
  • NotConfigured规则或归属方不存在。
  • NoMatch规则已检查，没有命中；规则给出数值零才是零，否则保持非数值。
  • ResolutionIncomplete归约仍不能形成最终标量。
  • ResolvedNonResponsive输入完整，结果为零。
  • ResolvedResponsive输入完整，结果为正响应。
  • Reject类型硬边界，不进入连续计算，也不写成超大 cost。

四个能反驳错误实现的案例

兄弟解释的区间收敛

小鱼 [0.80, 0.80]，小龙虾 [0.20, 0.60]。上界取最大后仍是 0.80，未解析路径不可能改变赢家，可以输出标量。

若换成 [0.45, 0.45] 与 [0.10, 0.90]，就必须保持 ResolutionIncomplete，并携带区间。

快速搜索的收益不在响应里

快速搜索提高的是单位时间覆盖，不是单次遭遇的响应。它的代价由追赶负担、风险顾虑和机会量表达。

若在响应里加搜索奖励，就会和覆盖收益重复计权。

垂直运动归机会

垂直 jigging 的水平相对速度接近零，Closing 几乎不增加负担；垂直运动按候选边界交给机会侧，通过“多久处在可交互区域”影响 L。该 seam 的正式 owner 尚未落仓。

不要虚构 3D 鱼方位把它塞进 Closing。

攻击诱因不能免费

低摄食意愿下换用强逃逸样呈现，诱因帮助跨线，但追随难度和机械暴露的代价由已有机制产生。

只加诱因不加代价，会退化成固定最优解。

第一轮玩法闭合结果

  • 攻击诱因只准入逃逸样；受伤挣扎与失衡样虚弱仍未闭合（CandidateUnresolved）；停顿本身不作为触发。
  • 风险顾虑只立装备显眼度（TackleConspicuousness），可后置实现；实现前 RiskCost 为 0。
  • 反应口策略成立；快搜与隐蔽只完成一半，另一半代价需要机会量 L 或外部成本。

还没有收口的部分

  • Prediction 是否值得作为独立局部代价重入主体；
  • 攻击诱因第一版准入哪些具名猎物状态；
  • 风险顾虑的最低实现层，以及完整 Naturalness 的边界；
  • Fish Condition 的数量，应由 Response 与其它消费者反推；
  • Opportunity 侧 L 的 reducer 与生产实现；
  • 生产标定：tail 起点、触发器预算、追赶快慢的系数、机会分布护栏。
