颜色说明

  • 蓝色 / 事实带来源、单位、参考系和有效时段。
  • 紫色 / 解释多个猎物解释可以并存。
  • 琥珀色 / 状态描述发生了什么，不自动等于奖励。

  • 灰色 / 机会与候选处理时间机会，不反写上游事实。

一次机会，多个解释

两个解释可以同时存在，但同一个呈现段、局部机会窗口和摄食路径只生成一条机会记录。

不生成两次机会

状态不是零

  • Unknown事实缺失，结果可能改变。
  • NotConfigured规则或归属方不存在。
  • NoMatch规则检查完成，没有命中。
  • ResolutionIncomplete归约仍不能形成最终标量。
  • ResolvedNonResponsive输入完整，结果是零。
  • Reject类型硬边界，不进入连续计算。

决策裕量

DecisionMargin(theta)
= CurrentFoodValue
+ StateTriggerValue
- ClosingCost(theta)
- PredictionCost
- RiskCost
- WillingnessThreshold(FeedingMotivation)

只有所有必需输入已解析，DecisionMargin 才能进入响应投影。Unknown 不能偷偷变成 0。

当前边界

  • 时间长度进入 Temporal Opportunity，不直接成为 DecisionMargin bonus。
  • Closing 只表达径向远离造成的负担，不是完整拦截模拟。
  • sudden turn 可以同时影响状态触发和预测负担，但不能产生第三个匿名加成。
  • Reject 不能被高 Motivation 复活。
  • Candidate 后段不能再次乘同一份 Response。

还没有冻结的部分

  • M0 / M1 的生产标定；
  • sibling Unknown 的正式归约 owner；
  • Temporal Opportunity 到 Candidate 的正式 owner；
  • vertical-dominant presentation 的适用范围；
  • 真实鱼种能力、曝光数据和 encounter geometry 来源。
