CoreProduct = Π_CORE fit # 核心相乘 SecondaryProduct = Π_SECONDARY fit # 次要原始乘积 SecondaryFactor = 1 − (1 − SecondaryProduct) / 4 # 差额缩到四分之一 RawEnvCoeff = CoreProduct × SecondaryFactor # 环境权重系数 FinalEnvCoeff = 门控失败 ? (背景鱼 ? envCoeffMin : fail_env_coeff) : max(RawEnvCoeff, envCoeffMin) SpatialDistributionWeight = BaseOpportunityIntensity × FinalEnvCoeff # Base 只乘一次

越差的环境 → fit 越小 → 核心乘积越小、次要折减越大 → 环境系数越小。次要整体最多扣 25%，不比最弱的核心更狠；这一条链是整机制“因果可解释”的根。

开关一

角色三态：CORE / SECONDARY / IGNORED

每个条件槽位选一个，互斥。这是策划购买“差异化”的唯一杠杆。

● CORE｜核心

进 Core 损失池，自动拥有门控（没有单独的门控开关）。

例：水温、结构 —— 值得形成完整环境选择差异。

● SECONDARY｜次要

全部次要条件合起来最多扣 25%，无门控。挡不住鱼，只让机会变差。

例：觅食水层 —— 真实但较弱的静态差异。

○ IGNORED｜忽略因子

本执行面自动不消费该条件。不是错误，不阻断。

例：时段 —— 本版没有足够静态校准，就先不配。

旧写法 OFF / EXCLUDED 只作为迁移别名读入，不是现行状态。

开关二

门控：随 CORE 自动存在，没有 Gate 控件

作者只需要把条件配成 CORE，门控就自动生效；没有 GatePolicy 字段，编辑器里也没有门控开关。判据是写死的两条：

离散查表条件

系数恰好等于 0 即门控失败。

想真正排除某结构 → 在编辑器里把它调到 0.00。留一点点非零 = 极低概率，不是排除。

水温（连续曲线）

适配值低于 temp_threshold 即门控失败（超出可接受区间的点 fit 本来就是 0）。

阈值线画在温度曲线控件上，作者看得见自己划在哪。

门控失败之后，只有两条路

✕ 背景鱼（保底鱼）
FinalEnvCoeff = envCoeffMin

保底鱼在任何环境都得有点机会，所以直接给它的下限。

✕ 非背景鱼
FinalEnvCoeff = fail_env_coeff

默认 0.01：以极低机会存在；若配置为 0，才表示该条件组中不存在。

✓ 门控全通过时，背景鱼才吃 envCoeffMin 这个下限（比较大小取大者）。envCoeffMin 只对背景鱼存在，范围 (0, 0.30]。

看得见的一条曲线

水温：6 个参数决定一条曲线

可接受区间 temp_accept_min~temp_accept_max · 偏好区间 temp_fav_min~temp_fav_max · 阈值 temp_threshold · 衰减形状 falloff_shape（LINEAR / SMOOTHSTEP）。连续曲线不套四档——档位是离散查表条件的事。

编辑器

编辑器的核心：species 底板 + mode / affinity 逐项覆盖

本期为了降低批量 authoring 成本，species 是主要编辑对象；每个 Compat Mode / FishEnvAffinity 只保存与底板不同的项。这个 delta 只存在于编辑器持久层，导出时会被物化成完整生产值。

Species Base

先编辑这个物种的常规习性：4 个 Component Profile + Spatial Opportunity Role。

底板不是新的生产表，也不是 Runtime identity。

Per-mode Delta

某个 FishEnvAffinity / Compat Mode 需要不同习性时，只覆盖变化项。

底板改动会传播到未覆盖项；已覆盖项保持不变。

Export Materialization

Editor Resolve 把 Base + Delta 合成每个档案的完整 numeric values，再写回生产 Excel。

Runtime 直接读完整值，不做 Base + Delta 合并。
