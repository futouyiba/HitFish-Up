8. 三个会议案例：证明策略翻转，同时守住机制边界

Case A｜追赶
快搜 vs 慢速 finesse
  • 适合追：快搜局部 C 仍可接受。
  • 不适合追：高速 Closing 明显上升。
  • ClosingLoad≈0 时，低 Activity 不应额外扣分。
Case B｜摄食动机
普通口 vs 反应口
  • 高动机：普通优质猎物已经够。
  • 低动机：合法攻击诱因帮助边缘目标跨线（第一版仅逃逸样）。
  • 受伤 / 挣扎与虚弱仍是 CandidateUnresolved，暂不进第一版。
  • 代价来自 Closing / Risk / L，不造 StrongStimulusPenalty。
Case C｜警戒度
直接强势 vs 隐蔽自然
  • 低警戒：直接方案仍有竞争力。
  • 高警戒：同样暴露产生更强 Risk。
  • Risk 只消费已经解析的具体可疑线索；Wariness 只决定对线索有多敏感。
  • 高速 / 转向 / 低 support 不能自动变成匿名 Suspicion。
  • 环境压力若已提高警戒度，不再重复进入 SuspicionLoad。

9. 台钓 / 浮钓带走的是原则，不是路亚公式

先解析，再评价
原始字段不直接当 Bonus

轨迹、配方比例、味型百分比都先变成领域状态。

因果职责分开
同一事实只结算一次

Food、Flavor、Particle、Physical Release 不先压成四个并列加分。

持久与即时分开
窝点状态 ≠ 当前呈现

打窝 / 补窝走持续路径；当前钩饵 / 拟饵走即时路径。

会议主旨
我们先用路亚回答：当前的鱼况、食性和拟饵呈现，为什么会让不同玩家打法的相对收益发生明显变化。Response 负责形成单次局部响应 C；Opportunity 负责局部机会 L；两者只在下游做一次 L × C。第一版先让“选什么、搜多快、要不要刺激、能不能露馅”稳定成立，再闭合 Fish Condition 的生成逻辑，并把同一套分层原则带回台钓和浮钓。
