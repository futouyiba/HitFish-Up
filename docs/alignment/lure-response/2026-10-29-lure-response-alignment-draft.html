路亚 Response：把鱼情变化转成玩家策略变化

这次会议不审批所有数值，也不设计完整鱼类 AI。目标是先对齐：我们想让玩家根据什么鱼情改变什么打法，为了做到这一点，Response 需要拆成哪些评价问题。

本轮重点：路亚 后续带回：台钓 / 浮钓 不定生产参数 不定最终 Fish Condition 数量

1. Response 是共同问题，但三种钓法的重点不同

共同问题是：当前这个食物目标，以当前方式呈现给当前状态的鱼，鱼有多愿意出手。不同钓法只是输入重心不同。

路亚｜本轮重点
更偏运动与呈现

拟饵形态、运动、速度、停顿、贴底、水层、猎物状态。

共同仍要解决：选什么饵。
台钓｜后置
更偏食物组合与窝点

成分、味型、混合、物性、雾化/残留、窝点，同时也有钩饵位置和状态。

共同仍要解决：食物是否匹配。
浮钓｜后置
更偏钩饵、水层与漂流

钩饵 / 天然饵、水层、漂流、状态；具体玩法也可能涉及味型、混合或窝料。

共同仍要解决：食物与鱼情匹配。
本轮策略：先用路亚把 Response 的评价骨架闭合，再把可复用的 Takeaway 带回台钓和浮钓。

2. 我们真正想买的是四种“策略翻转”

每个鱼侧状态轴，都应该改变两种玩家方案的相对收益。状态量存在的理由，不是“生物学上听起来重要”，而是它能改变玩家打法。

4. 快速搜索的价值：不是“多发抽奖”，而是更快收敛探索

更快移动单位时间走过更多空间
→
尝试更多位置结构 / 水层 / 区域
→
更快排除无效区得到更多探索反馈
→
更快收敛鱼位判断找到信号后再精钓
快速搜索的收益
空间覆盖 / 信息效率

更快知道哪里值得继续投入时间。

快速搜索的代价
局部 Response 质量可能下降

局部停留更短，高速呈现还可能提高追赶负担。

希望出现的循环：快速搜索 → 找到信号 → 降速 / finesse 深挖。Response 不需要额外给“搜索速度奖励”。

5. 为了达到这些策略目标，鱼的评价需要拆细

顶层保持简单：先把每个子机制换算成统一的“出手余量”，再比较值得出手的理由、需要承担的代价和当前门槛。

出手余量
= 食物价值
+ 攻击诱因
- 追赶负担
- 风险顾虑
- 摄食意愿门槛

出手余量 → Response
食物价值
值不值得吃？

主要决定“选什么”。

攻击诱因
现在是否特别诱发出手？

服务反应口，但不是“动作越大越加分”。

追赶负担
这个速度有多难接受？

主要决定“搜多快”。

风险 + 门槛
会不会露馅？现在有多挑？

警惕度影响风险，摄食意愿影响门槛。

6. Capacity + Activity：上游可分，Response 端可合

两者语义不同，但玩家侧主要都影响“当前应该把拟饵放多快”。因此可以把它们折叠成一个追赶状态倍率。

Capacity｜能力
客观能调用多少运动能力

能力下降后，同样拟饵速度会占用更高比例的能力。

能不能
＋
Activity｜活性
对能力调用的行为容忍

活性下降后，同样的能力调用变得更“不值得”。

愿不愿
追赶负担
= K × (拟饵径向远离速度 / BaseAbility)²
× 追赶状态倍率

追赶状态倍率
= ActivityCostMultiplier / Capacity²
关键点：这只是 Response 端的聚合。它不要求删除 Capacity 或 Activity 的上游来源。如果 Capacity 未来还被搏鱼、逃逸、迁移等系统消费，可以保留；如果它只服务这里且能直接推导，就没必要为了名字而 Bake 成一级 Fish Condition。

7. 三个会议案例：只证明“排序翻转”

Case A｜追赶状态

快速搜索 vs 慢速 finesse

  • 追赶状态好：高速负担较低，快搜更可用。
  • 追赶状态差：高速负担高，慢速呈现相对受益。
  • 目标不是“高活性必须快钓”，而是改变快速探索的代价。
Case B｜摄食意愿

普通口 vs 反应口

  • 摄食意愿高：普通优质猎物已经够。
  • 摄食意愿低：普通呈现可能过不了线。
  • 合法攻击诱因可以帮助越线，但同时可能增加追赶与风险代价。
Case C｜警惕度

直接强势 vs 隐蔽自然

  • 低警惕：同样暴露成本低。
  • 高警惕：异常暴露更容易形成风险顾虑。
  • 本轮只对齐方向，不审批完整 Naturalness。

9. 这次要对齐什么，刻意不闭合什么

需要对齐
  • 本轮先集中路亚，后续再回到台钓 / 浮钓。
  • 四个策略方向是否成立。
  • 是否认可“状态 → 评价项 → 玩家策略翻转”。
  • 是否认可加性出手余量主体。
  • Capacity / Activity 是否允许在追赶消费端聚合。
  • Fish Condition 数量由消费需求反推。
刻意不闭合
  • 台钓 / 浮钓味型、混饵、窝料算法。
  • 完整 Naturalness / 异常暴露模型。
  • 最终 Fish Condition 数量。
  • Functional Capacity 是否最终独立 Bake。
  • 生产参数和最终曲线。
  • 轨迹预测困难是否保留。
  • 非摄食攻击与完整单位时间中鱼效率。
会议主旨
我们不是在增加一组更复杂的中鱼系数，而是在建立一层把鱼情变化转译成玩家策略变化的 Response：让玩家根据鱼的食性、追赶状态、摄食意愿和警惕程度，改变选饵、搜索速度、刺激方式与隐蔽程度。第一版先用路亚把骨架闭合，再反推需要哪些 Fish Conditions，并把可复用框架带回台钓和浮钓。
