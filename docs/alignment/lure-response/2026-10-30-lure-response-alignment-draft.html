路亚响应（Response）：先讲玩家为什么要换策略，再讲系统怎么计算

这版从 4 个真实钓鱼策略故事出发，再把拟饵表达、猎物解释、鱼况、体型档、五项响应评价和机会量拆成清楚模块。目标不是堆公式，而是让每种复杂度都购买一个玩家能感受到的策略差异。

猎物解释器（Prey Interpreter）并行解释 C = 适配系数 去掉运动可预测性（Prediction） 去掉隐藏方位角 θ 一竿一鱼况快照（Snapshot）

1. 先讲 4 个钓鱼策略故事

响应系统存在的理由，不是“更像真实鱼脑”，而是条件变化后，玩家真的会换饵、换速度、换刺激方式、换隐蔽程度。

故事一｜选什么
今天它到底想吃什么？

鱼当前没有明显食性偏转时，泛用饵应保持竞争力；当鱼明显偏向小鱼、小龙虾或蛙时，高匹配方案应明显更值得换上去。

购买的策略：换不换饵、换成什么饵。
故事二｜搜多快
现在该快搜，还是慢下来精钓？

鱼适合追时，快速搜索的局部响应仍可接受；鱼不适合追时，高速呈现明显吃亏。快搜的额外价值来自真实空间覆盖，不由响应系统发“搜索奖励”。

购买的策略：什么时候快搜，什么时候降速。
故事三｜反应口
鱼不开口时，能不能靠猎物状态把它“激”出来？

普通自然呈现可能缺少“现在就出手”的理由；逃逸样状态可以额外促发捕食。但“游得更像”只提高猎物表达，不等于攻击诱因。

购买的策略：普通呈现与反应口什么时候分别有价值。
故事四｜能不能露馅
高警戒鱼，值不值得换更隐蔽的终端钓组？

低警戒时，前导线、钩、别针等可以更直接；高警戒时，终端钓组的显眼度应该产生更高代价，让隐蔽配置值得付成本。

购买的策略：什么时候值得为了隐蔽付成本。
四个故事共同推出五个评价问题：食物价值、攻击诱因、追赶负担、风险顾虑、摄食意愿门槛。后面的模块设计都服务于这四个玩家故事。

2. 四个故事怎样汇成适配系数

出手余量（Decision Margin）
= 食物价值（Food Value）
+ 攻击诱因（Attack Trigger）
- 追赶负担（Closing Cost）
- 风险顾虑（Risk Cost）
- 摄食意愿门槛（Willingness Threshold）

出手余量 → 适配系数（Adaptation Coefficient）C，且 0 ≤ C ≤ 1
注意：适配系数不是放大器。C=1 只表示本次响应不再衰减基础强度；攻击诱因再强，也不能把 C 推到 1 以上。

3. 核心模块图：先解释“像什么”，再评价“值不值得出手”

一个拟饵可以同时表达多种猎物。系统不先强行选唯一身份，而是让多个猎物解释器并行读取同一份事实，各自输出“表达支持度 + 当前状态”，鱼再分别评价。

核心理解：拟饵不是猎物类型。一个拟饵可以表达多个猎物类型；猎物解释器分别回答“像不像”和“现在是什么状态”，鱼再进行评价。

5. 动态表达与攻击诱因：两个问题，不要混在一起

动态表达规则（Dynamic Expression Rule）

“这样运动以后，更像不像这类猎物？”

鱼形外观已经提供基础小鱼支持度；正常游动 + 尾摆可以把这份支持度向上增强。原来的 Dynamic Route 降级为解释器内部实现细节。

攻击诱因（Attack Trigger）

“已经像猎物了，现在有没有额外理由立刻扑？”

当前第一版只正式准入逃逸样（Escape-like）。自然游动、正常尾摆可以很像小鱼，但不必产生攻击诱因。

防重复计权：一次逃逸动作可能同时包含转向、爆发和加速度，但不能拆成三份通用奖励。先解释成一个猎物状态，再只结算一次攻击诱因。

7. 第一版追赶负担：去掉隐藏方位角 θ

没有鱼的真实世界坐标时，不再积分各种“鱼可能从哪里追”的隐藏方位。首版统一采用一个产品假设：形成摄食机会时，鱼正在追拟饵。

速度需求比 q = 拟饵相对水体水平速度 / 追赶能力基线

追赶负担（Closing Cost） = K_close × q² × 活跃度成本倍率
刻意省略：“拟饵虽然很快，但刚好迎面朝鱼游来，所以不用追”第一版不处理。不是说现实没有，而是没有鱼坐标时不伪造遭遇几何精度。

8. 风险：先把终端钓组显眼度做简单

只计算目标饵以外、鱼能感知的终端钓组部件，例如前导线、钩、别针、转环。拟饵主体属于猎物表达，不放进“露馅”里重复计算。

终端钓组显眼度（Tackle Conspicuousness）
= 1 - Π(1 - cᵢ)

可疑负荷（Suspicion Load）≈ 终端钓组显眼度
风险顾虑（Risk Cost）= K_wary × 警戒度（Wariness） × 可疑负荷
第一版优点：一个特别显眼的部件会明显影响总值，多个中等部件也能共同提高风险，但结果天然保持在 0~1 范围。

10. 适配系数 C 与机会量 L 各管什么

适配系数 C

这个机会摆在鱼面前时，有多适配？

由猎物表达、鱼的食性、鱼况、追赶负担、风险和摄食门槛共同决定。范围固定 0~1。

机会量 L

这个机会实际上有没有形成、形成多少？

负责有效时间 / 空间窗口、覆盖、垂直可交互窗口等。停留时间只是输入，不保证“停越久 L 越大”。

候选贡献 q = L × C

11. 会议里要主动讲清的“刻意不做”

第一版刻意不做为什么
运动可预测性（Prediction）与猎物表达、攻击诱因、追赶负担、机会量高度重叠，尚未证明剩余的独立策略价值。
隐藏方位角 θ 积分没有鱼的真实位置时，不伪造遭遇几何；统一按“鱼在追拟饵”估算。
通用停顿奖励停顿已经可以进入猎物姿态、追赶负担和机会量，不再匿名加分。
“停越久机会量越大”停留时间不是单调奖励，是否形成更多有效机会由机会量机制决定。
先生成具体鱼个体先用体型档计算响应，候选命中后再抽具体长度、重量和品质。
复杂视觉显眼度模型先用终端钓组部件的简单饱和聚合，数据不足时不提前模拟。
