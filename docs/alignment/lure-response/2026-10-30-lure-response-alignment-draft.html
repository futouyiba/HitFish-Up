0. 响应分两部分，不同钓法重点不同

先统一范围，避免把路亚、台钓、浮钓一次混在一起讨论。

持久响应

处理会持续一段时间的玩家影响

例如打窝、补窝、窝点形成后的持续作用。

姿态响应

处理当前这一竿的即时呈现

当前饵、运动、速度、停顿、水层和即时操作。

钓法更偏哪一部分典型内容
路亚姿态响应为主拟饵像什么、怎么游、速度、停顿、逃逸样、终端钓组是否显眼
台钓持久响应更重，同时保留即时钩饵响应窝料、补窝、味型与食物持续作用；钩饵位置和状态仍影响出手
浮钓即时呈现为主，部分玩法也有持久影响钩饵、水层、漂流、状态；涉及窝料时再接持久响应
本次会议范围：先把路亚即时呈现这条链闭合。后续台钓、浮钓复用“先解析语义，再由鱼评价”的分层原则，不复制路亚公式。

1. 先看 4 个玩家会做的选择

选什么

今天它到底想吃什么？

食性没有明显偏向时，泛用饵仍有竞争力；偏向某类猎物时，高匹配方案值得换上去。

搜多快

现在该快搜，还是慢下来精钓？

适合追时，快速搜索的局部响应仍可接受；不适合追时，高速明显吃亏。

反应口

鱼不开口时，能不能把它激出来？

自然呈现已经合理但摄食动机低时，逃逸样等猎物状态可以额外促发捕食动作。

隐蔽性

高警戒鱼，值不值得换更隐蔽的钓组？

低警戒时可以更直接；高警戒时，前导线、钩、别针等终端钓组过于显眼应付出代价。

2. 4 个选择，最后收成 5 个评价问题

出手余量
= 食物价值
+ 攻击诱因
− 追赶负担
− 风险顾虑
− 摄食意愿门槛

出手余量 → 适配系数 C，且 0 ≤ C ≤ 1

攻击诱因再强，也只能把适配系数推到 1，不会反过来放大基础鱼权重。

3. 模块图：先解释“像什么”，再评价“值不值得出手”

一句话：拟饵不是猎物类型。一个拟饵可以同时表达多种猎物；系统先分别解释“像不像、现在是什么状态”，再让鱼分别评价。

4. 猎物解释器：先看“像不像”，再看“现在是什么状态”

表达支持度

现在有多像这种猎物？

由外观、整体运动、局部动作和空间关系等证据解释。

当前状态

如果把它当成这种猎物，它现在在干什么？

例如正常游动、停顿、逃逸样等。状态本身不自动等于奖励。

5. 第一版猎物证据：四类

证据回答什么典型输入边界
外观证据（Appearance）看起来像什么轮廓、比例、颜色 / 反光、部件布局不读整体运动
整体运动证据（Whole-body Motion）整体怎么运动像什么速度模式、方向变化、游 / 爬 / 跳 / 漂 / 下沉不重复局部动作
局部动作证据（Articulation）局部怎么动像什么尾摆、腿踢、裙丝动作不重复整体轨迹
空间关系证据（Spatial Relation）出现在哪里更符合什么猎物水面、近底、中层、触底、离底高度默认只做弱证据

同一猎物类型有多份替代证据时默认取最强，不把相近证据直接相加。只有 A+B 同时存在才形成新语义时，再显式配置联合证据。

6. 姿态：一个原子姿态 + 最多一个主导分子姿态

原子姿态

当前这一刻是什么

移动、停顿、上升、下落等。

分子姿态

当前姿态 + 必要前史

例如抽动→停顿、爆发→停顿、爆发→转向→停顿。

停顿有价值，但不做通用“停顿奖励”。它可以组成猎物特定的分子姿态，也会改变追赶负担和机会量；不预设“停越久，L 必然越大”。

7. “游得更像”与“额外促发攻击”分开

更像猎物

进入猎物表达支持度

自然匀速游、正常尾摆可以让拟饵更像小鱼，但不必产生攻击诱因。

额外促发攻击

进入攻击诱因

已经接受“这是可吃猎物”以后，当前状态是否额外制造“现在扑上去”的理由。第一版采用逃逸样。

8. 鱼侧第一版：用体型档，不先生成具体鱼

鱼种 × 中鱼习性模式 × 体型档

捕食鱼体型档 + 猎物大小 → 猎物尺寸偏好修正
鱼种 × 体型档 → 追赶能力基线

先按体型档算候选权重；选中候选后，再在体型档内生成具体长度、重量和品质。

9. 追赶第一版：不做鱼和拟饵的相对方位积分

产品假设：当前形成摄食机会时，鱼正在追拟饵。

速度需求比 = 拟饵相对水体水平速度 / 追赶能力基线
追赶负担 = K_close × 速度需求比² × 活跃度成本倍率

不考虑“虽然很快，但刚好迎面朝鱼游来”的特殊情况。当前没有真实鱼世界坐标，就不为二阶遭遇几何伪造精度。

10. 运动可预测性：考虑过，第一版主动删掉

像不像猎物

由猎物表达支持度承接。

是不是逃逸 / 脆弱

由攻击诱因承接。

是否太快 / 窗口是否有效 / 是否露馅

分别由追赶负担、机会量和风险顾虑承接。

只有以后控制这些因素后，“纯运动可预测性”仍能稳定改变玩家选择，才值得重开。

11. 风险第一版：终端钓组显眼度简单聚合

终端钓组显眼度 = 1 - Π(1-cᵢ)

可疑负荷 ≈ 终端钓组显眼度
风险顾虑 = K_wary × 警戒度 × 可疑负荷

只算目标饵以外、鱼能感知的终端钓组部件。拟饵主体属于猎物表达，不属于“是否露馅”。

12. 鱼况：一竿一个快照

抛竿开始 → 解析当前派生环境场 / 环境条件组 → 读取鱼况基线 → 生成本竿鱼况快照 → 本竿只读 → 下一竿重新解析

例如 05:59 抛竿、06:00 切时段，本竿继续使用 05:59 的快照，下一竿再读新鱼况。

13. 最终只接一次：机会量 L × 适配系数 C

机会量 L

机会有没有真正形成

回答时间、空间和有效交互窗口。

适配系数 C

这个机会摆在鱼面前时，有多适配

由五项响应评价产生，范围 0~1。

候选贡献 = L × C
同一个物理目标的多个猎物解释 → 取最大适配系数
