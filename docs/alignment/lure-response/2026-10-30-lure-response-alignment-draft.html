1. 玩家实际在做的 4 个选择

响应必须让玩家在不同鱼情下真的有理由换打法。

选什么

泛用，还是专精匹配？

食性没有明显偏向时，泛用饵仍有竞争力；偏向某类猎物时，专精匹配值得换上去。玩家选的是换不换饵、换成什么。

搜多快

快搜，还是慢钓？

适合追时，快速搜索的局部响应仍可接受；不适合追时，高速明显吃亏。玩家选的是什么时候快搜、什么时候降速。

反应口

自然呈现，还是反应口？

自然呈现已经合理但摄食动机低时，逃逸样等猎物状态可以额外促发捕食动作。玩家选的是什么时候值得做反应口。

隐蔽性

直接，还是隐蔽？

低警戒时可以更直接；高警戒时，前导线、钩、别针等终端钓组过于显眼应付出更高代价。玩家选的是什么时候为隐蔽付成本。

2. 从这 4 个选择，推出我们需要 5 个评价问题

玩家选择要回答的问题落到哪个评价项
泛用还是专精这个目标本身值不值得吃食物价值
快搜还是慢钓当前呈现对这条鱼有多难追追赶负担
自然还是反应口当前猎物状态是否额外促发出手攻击诱因
直接还是隐蔽这次呈现有多容易露馅风险顾虑
共同前提现在需要多强的理由才出手摄食意愿门槛
出手余量
= 食物价值
+ 攻击诱因
− 追赶负担
− 风险顾虑
− 摄食意愿门槛

出手余量 → 适配系数 C，且 0 ≤ C ≤ 1

攻击诱因再强，也只能把适配系数推到 1，不会反过来放大基础鱼权重。

3. 系统怎么走：先解释，再评价，最后乘机会

第一步

拆共同事实

速度、轨迹、姿态、水层、部件动作；先不判断“它是什么”。

第二步

每种猎物分别解释

每个解释器回答两件事：有多像（表达支持度）；按这种猎物看现在在干什么（当前状态）。

第三步

鱼侧评价

五项评价合成适配系数 C；机会量 L 只乘一次，得到候选贡献。

一句话：拟饵不是猎物类型；系统先分别解释“像不像、现在什么状态”，再让鱼评价。

4. 猎物解释器的价值：一个饵，多种解释，分开买策略

为什么不选唯一身份

一个饵可以同时像小鱼和小龙虾

强行选一个，等于替玩家和鱼做了系统自己没做的判断。

它输出什么

表达支持度 + 当前状态

像不像这种猎物；按这种猎物看，它现在在干什么。

它买什么策略

泛用与专精的分工

泛用饵靠多个中等解释，专精饵押一种高解释；鱼侧偏向变化时，两者排序翻转。

同一物理目标的多个解释互斥，不叠加：
最终适配系数 = max(各猎物解释的适配系数)

5. 第一版猎物证据：四类

证据回答什么典型输入边界
外观证据（Appearance）看起来像什么轮廓、比例、颜色 / 反光、部件布局不读整体运动
整体运动证据（Whole-body Motion）整体怎么运动像什么速度模式、方向变化、游 / 爬 / 跳 / 漂 / 下沉不重复局部动作
局部动作证据（Articulation）局部怎么动像什么尾摆、腿踢、裙丝动作不重复整体轨迹
空间关系证据（Spatial Relation）出现在哪里更符合什么猎物水面、近底、中层、触底、离底高度默认只做弱证据

同一猎物类型有多份替代证据时默认取最强，不把相近证据直接相加。只有 A+B 同时存在才形成新语义时，再显式配置联合证据。

6. 姿态：一个原子姿态 + 最多一个主导分子姿态

原子姿态

当前这一刻是什么

移动、停顿、上升、下落等。

分子姿态

当前姿态 + 必要前史

例如抽动→停顿、爆发→停顿、爆发→转向→停顿。

停顿有价值，但不做通用“停顿奖励”。它可以组成猎物特定的分子姿态，也会改变追赶负担和机会量；不预设“停越久，L 必然越大”。

7. “游得更像”与“额外促发攻击”分开

更像猎物

进入猎物表达支持度

自然匀速游、正常尾摆可以让拟饵更像小鱼，但不必产生攻击诱因。

额外促发攻击

进入攻击诱因

已经接受“这是可吃猎物”以后，当前状态是否额外制造“现在扑上去”的理由。第一版采用逃逸样。

8. 鱼侧第一版：用体型档，不先生成具体鱼

鱼种 × 中鱼习性模式 × 体型档

捕食鱼体型档 + 猎物大小 → 猎物尺寸偏好修正
鱼种 × 体型档 → 追赶能力基线

先按体型档算候选权重；选中候选后，再在体型档内生成具体长度、重量和品质。

9. 追赶第一版：不做鱼和拟饵的相对方位积分

产品假设：当前形成摄食机会时，鱼正在追拟饵。

速度需求比 = 拟饵相对水体水平速度 / 追赶能力基线
追赶负担 = K_close × 速度需求比² × 活跃度成本倍率

不考虑“虽然很快，但刚好迎面朝鱼游来”的特殊情况。当前没有真实鱼世界坐标，就不为二阶遭遇几何伪造精度。

10. 运动可预测性：考虑过，第一版主动删掉

像不像猎物

由猎物表达支持度承接。

是不是逃逸 / 脆弱

由攻击诱因承接。

是否太快 / 窗口是否有效 / 是否露馅

分别由追赶负担、机会量和风险顾虑承接。

只有以后控制这些因素后，“纯运动可预测性”仍能稳定改变玩家选择，才值得重开。

11. 风险第一版：终端钓组显眼度简单聚合

终端钓组显眼度 = 1 - Π(1-cᵢ)

可疑负荷 ≈ 终端钓组显眼度
风险顾虑 = K_wary × 警戒度 × 可疑负荷

只算目标饵以外、鱼能感知的终端钓组部件。拟饵主体属于猎物表达，不属于“是否露馅”。

12. 鱼况：一竿一个快照

抛竿开始 → 解析当前派生环境场 / 环境条件组 → 读取鱼况基线 → 生成本竿鱼况快照 → 本竿只读 → 下一竿重新解析

例如 05:59 抛竿、06:00 切时段，本竿继续使用 05:59 的快照，下一竿再读新鱼况。

13. 最终只接一次：机会量 L × 适配系数 C

机会量 L

机会有没有真正形成

回答时间、空间和有效交互窗口。

适配系数 C

这个机会摆在鱼面前时，有多适配

由五项响应评价产生，范围 0~1。

候选贡献 = L × C
同一个物理目标的多个猎物解释 → 取最大适配系数

14. 概念清单：有哪些概念，谁流向谁

概念回答什么由谁产生流向
实际呈现这一竿实际是什么玩家操作 + 环境共同事实
共同事实可复用的客观输入事实提取各猎物解释器
表达支持度有多像这种猎物猎物解释器五项评价
当前状态按这种猎物看，现在在干什么猎物解释器攻击诱因
鱼侧上下文鱼是谁、当前状态如何鱼种配置 + 本竿鱼况快照五项评价
五项评价值不值得出手评价规则出手余量
出手余量五项净值相加适配系数
适配系数 C这个机会有多适配投影候选贡献
机会量 L机会形成了多少Opportunity候选贡献
候选贡献最终进入候选的量L × C候选
实际呈现 → 共同事实 → 各猎物解释（支持度 + 状态）
→ 五项评价（鱼侧上下文参与）→ 出手余量 → 适配系数 C
→ 候选贡献（L × C）
