# 跨阶段不变量与最小验证

> 状态：Candidate / Working Design
> 日期：2026-10-29
> 边界：本页只整理完整中鱼链的不变量和结构反例，不定义生产公式，不替代各阶段 Current Contract。

## 1. 用途

不同阶段的具体公式可能仍为 OPEN。但有些性质不能等到公式确定才检查，否则后面会用“看起来合理”的实现掩盖重复计权。

本页列出跨阶段不变量，作为评审和后续实现的最低门槛。

## 2. 不变量

| ID | 不变量 | 主要阶段 |
|---|---|---|
| I-01 | 每个派生事实只有一个主要生产者 | 全链 |
| I-02 | 同一环境、Cue、Food、Particle 或 Physical 事实不能在两个阶段各产生一份效果 | 烘焙、响应、Groundbait |
| I-03 | 环境权重不被响应重新生成，响应不写回 DEF | 烘焙、响应 |
| I-04 | 配方对象只能在当前地点、离开、不可接触、不可处理、被摄食、转态之间守恒转移 | Groundbait |
| I-05 | Base Weight、SpatialDistributionWeight、AdaptationCoeff、Roundtable Weight 和抽样概率不能混名 | 全链 |
| I-06 | 一次 Feeding Event 不因多个 Feeding Mechanism 直接求和 | Feeding Event |
| I-07 | 持久响应、鱼况记忆、对象消耗和圆桌动态调整分别拥有时间状态 | 响应、Groundbait、圆桌 |
| I-08 | 移除 Groundbait Candidate 不应改变环境烘焙、Current Fish Condition 或圆桌规则 | 全链 |
| I-09 | 0.3.4.0-B 不实现 OUT 层；刺鱼、搏鱼不在本仓补造 | 范围 |
| I-10 | Current、Reference、Candidate、OPEN 每次引用都带路径、版本和范围 | 全链 |
| I-11 | 每个权重或候选携带声明的身份轴元组 | 烘焙、响应、圆桌 |
| I-12 | 权重和系数非负；边界显式；没有静默 clamp | 全链 |
| I-13 | 背景鱼不低于兜底下限；非背景鱼不得获得背景兜底 | 烘焙 |
| I-14 | 缺失不等于忽略；显式 IGNORED 合法，缺失绑定是错误 | 烘焙 |

| I-16 | 0.3.4.1 空鱼扩张不修改单鱼实鱼权重，不替代现有挤占和裁剪 | 圆桌 |
| I-17 | 可交换聚合顺序无关；相同输入产生相同输出 | 全链 |

## 3. 最小结构反例

以下反例只检查阶段边界和所有权，不检查数值。

### 3.1 环境与响应

- 环境事实改变只影响烘焙和 DEF，不直接改变响应系数。
- 响应前后 `SpatialDistributionWeight` 发生变化，视为响应越权。
- 同一温度既进环境系数又进 Fish Condition，且两处都乘最终权重，视为重复计权。

### 3.2 Groundbait 与响应

- Groundbait 释放改变 Feeding Place State，不直接改变 `AdaptationCoeff`。
- Flavor 改变发现或选择，不改变尺寸成功。
- Particle 状态改变动作可行性或成功，不改变 Cue Exposure。
- 重复动作路径不增加一次事件收益。
- 摄食成功后对象仍保留完整价值，视为守恒失败。

### 3.3 响应与圆桌

- 响应直接输出概率，视为阶段混用。
- 圆桌权重在归一化前被当成概率，视为阶段混用。
- 同一窝料效果同时写持久字段和即时条件，且没有来源和增量区分，视为双计。

### 3.4 圆桌与抽鱼

- 前置计算失败被伪装成一次空鱼结果，视为失败语义错误。
- `WΣ = A` 或 `WΣ < A` 仍然扩张空鱼权重，视为边界错误。
- 抽中空鱼后仍生成鱼对象，视为抽鱼与生成边界错误。

## 4. 评审顺序

1. 先核对每个量是否有唯一生产者和声明阶段。
2. 再核对权重、系数和概率是否混名。
3. 再核对 Groundbait 的对象守恒和四条路径分流。
4. 再核对响应与圆桌的汇合点。
5. 最后才看具体数值和 Fixture。

## 5. 不做什么

- 不用不变量替代 Current Contract。
- 不用反例数量衡量完成度。
- 不在语义未定时写生产参数。
- 不把 Candidate 的通过当作 Owner 批准。
