# 钩饵与窝料：背景不能替钩饵完成摄食

> Candidate / Working Experiment，2026-11-04。承接本轮用户的“窝料走持久响应、钩饵走实时响应”方向，不改 Current Response 公式。

## 1. 两份选择解决不同问题

窝料让指定地点持续存在对象和线索。钩饵是这次有钩呈现的对象。玩家应当能用窝料筛选背景，再用钩饵的食物、尺寸、形态和水层进一步筛选。但窝料强，不代表鱼能吞下或愿意处理当前钩饵。

“同味”没有独立奖励。相同签名在同一消费语义中去重，不能两处各加一次。不同味也没有自动“突出钩饵”的奖励。要引入学习、熟悉或新奇，需要各自证据、时间状态和重开决定。

## 2. 工作组合式

先单独形成钩饵可处理价值：

```text
H = FoodHook × UHook
```

`FoodHook` 使用实验选定的 Food 算子；`UHook` 是可行动作加权成功率。尺寸不再进入 Food。非法呈现、明确 Reject 在此前短路。合法空钩是否支持其它非摄食模式不由本页决定，本实验只研究有饵摄食。

背景由当前可用可食对象形成：

```text
B_f = Σ_lot available_mass_lot × food_value_f,lot
C_trial = H × (1 + β B_f/(1+B_f)) / (1+γ B_f) × exp(-P)
```

`C_trial` 只是实验响应指标，不是 Proposal C 的 C、生产 AdaptationCoeff 或概率。β、γ 是非负工作参数；P 是经确认摄食事件形成的地点级响应压力，不是 Fish Condition。

这个式子显式购买两个不同后果：有限背景收益，与免费食物竞争钩饵的负效应。B 的单位须由标尺归一化；当前把1工作质量单位作为参考，不使用气味浓度。它不是给 Food 在两个模块各打一次分：H 仅代表有钩对象，B 仅代表不同来源的免费对象，两份实体不可混淆。

竞争项需要 Owner 准入。若只保留正收益，过量投放不会出现负反馈；若删除正收益，打窝永远不改善本式。不能先要求所有参数下都存在最佳窝量：β≤γ 时，该式可能从零开始就不值得投窝；实验采用 β=6、γ=0.5，仅证明存在非单调分支。

## 3. 可证伪结果

固定 H=0.4、P=0，工作样本得到：

| B | C_trial | 解释 |
|---:|---:|---|
| 0 | 0.4000 | 无背景，不把合法钩饵清零 |
| 1 | 1.0667 | 有限背景收益超过竞争 |
| 20 | 0.2442 | 免费对象竞争更强；没有声称鱼已吃饱 |

输出可以超过1，不能作概率。H=0 时任何背景都不能救活；提高 B 不改合法姿态、机会量 L、DEF 或 Fish Condition。

## 4. 味型如何接入，哪些还不能算

每个有效来源保留 `(source_id, signature, role, validity)`。同一来源重发不增加集合；窝料背景与钩饵可保留来源区别，但当前同一“签名解释”只解析一次。若未来分开嗅觉远端发现与口腔适口性，必须证明两次消费有不同后果，再添加不同消费键，不凭来源不同自动加奖。

Probe 只返回 Flavor 标签，不把它映射成数值。这样避免偷偷选定“排斥就是零”或固定小药倍率。代价是：尚不能用本式给蒜面团和奶渣面团排数值高低。离散签名可以支持少量关系差异，不能支持加浓、稀释或过量效应。

## 5. 失败与双算检查

- 钩饵不适合但窝料很强：H仍低或为零，不从背景借用钩饵适口性。
- 钩饵粒径排除小鱼：只改其处理路径，不在 Food 和动作中各罚一次。
- 同一窝料保存两次：事件ID去重；物理事实与缓存不能各消费一次。
- 持久场已给 B：实时响应不再读取原始投放事件额外加奖。
- 不把 B 回写为空间权重、鱼况或 Opportunity；两种组装接口仍由调用者显式选择。

本页关闭的是实验的计算歧义，不关闭 C-01、C-02、C-03、C-04 或 Response 聚合的 Owner 决策。即使实验通过，生产仍需验证其上游合法性和完整候选集上的排序。
