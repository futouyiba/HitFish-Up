# 食物的正价值：觅食投入与处理时间

> Candidate / Behavioral Hypothesis，2026-11-05。用户明确否决“食物仅用于竞争与筛鱼”的缩减版，要求推导独立正向机制。该指令确定研究目标，不批准本页公式、行为状态或生产接口。基线 `7f5e26aa`。

## 1. 食物提供可兑现的觅食对象

化学线索只给出信息，食物提供可处理、可摄入的对象。候选正向后果是：已经具备合法机会条件的鱼，在存在可兑现食物的地点，更可能把当前行为时间投入觅食，而不是继续无定向搜索。

这不是提高食物自身偏好，也不是把鱼变饿，更不是把鱼群搬进钓点。它提出一个新的持续响应行为抽象：**有食物支持的觅食投入**。独立负向后果则是处理免费对象占用时间，使当前钩饵不能同时获得这段处理时间。

两种作用不能用“Food Bonus”合并。正向作用改变搜索与投入的时间分配；负向作用占用处理时间。纯线索可以提示地点，但本假设不让它凭空生成可兑现食物；它如何改变搜索转投入的基础过程仍归Cue消费候选，不在本轮再次加奖。

## 2. 四个互斥时间份额

对固定鱼侧候选上下文，使用四种行为时间份额，不是四群鱼或局地人口：

- S：未投入当前觅食任务。
- E：投入当前觅食任务，可处理钩饵或免费对象。
- F：正在处理免费食物。
- H：正在处理钩饵。

`S+E+F+H=1`。它们是实验概率/时间预算，不是Fish Condition，不落DEF，不修改Opportunity L。转移率的单位为工作时间的倒数。

```text
S → E : a(food)
E → S : d
E → F : f(food)
F → E : c
E → H : h(hook)
H → E : k
```

候选稳态：

```text
E* = 1 / [1+d/a+f/c+h/k]
钩饵尝试率 = h E*
```

食物可提高a，让更多行为时间投入当前任务；大量免费食物提高f，增加处理占用。h仍由钩饵自身决定，h=0时背景无法救活。没有吞饵、刺鱼或上鱼模型，因此尝试率不等于中鱼率。

这比V1单背景量的峰形式多购买了可以分别否定的行为过程。若无法为a的食物依赖提供独立依据，这个模型仍必须被否决，不能因能生成峰形曲线就定案。

## 3. 明确参数假设，不伪装科学定律

[探针](../../../tools/probe_float_food_value.py)使用：

```text
a(x)=0.1+2x/(1+x)
f(x)=0.5x
d=0.5，c=1，k=1，h=0.2
```

x是预先保证当前地点可接触、可处理、鱼接受的食物支持工作量，不是气味浓度，也不是任意投放质量。当前未接原料/动作模型，真实食物支持的单位、归一化与鱼种关系未定。

a的饱和形式仍是工作假设，不是从资料导出的生产函数。a和f可以读取同一对象事实，但必须分别证明“投入”和“处理”后果；两个参数名不自动证明没有重复计权。

## 4. 消融比峰形曲线更重要

- 删除食物对a的作用：食物只增加处理负担，退回用户否决的缩减版。
- 删除免费处理f：食物收益单调增加，失去过量的时间竞争。
- h=0：始终没有钩饵尝试，强窝料不能代替钩饵。
- 移除食物后：a与f回基础值，行为份额逐渐恢复，不立即清零、不写饱食状态。
- 连续在线与单次推进使用同一转移过程；概率守恒，保存恢复不改变后续结果。

实际输出见 [工作结果](../fixtures/float-food-value-results.json)。5项测试覆盖上述关系、稳态保持、非负守恒及时间半群。动态计算使用均匀化方法，不能按Euler步长任意造负份额。

## 5. 与持久场和现有抽鱼链的接入限制

该模型尚未接入V3，不能将 `hE*` 再乘V2的G与`1/(1+F)`：那会把背景投入或处理竞争再算一次。下一实验若采用本模型，应替换相应背景/竞争支路，保留钩饵接受与动作约束的独立来源。

本探针没有确认摄食事件或消耗物料。F表示时间占用，不能从中直接扣某质量或产生饱食；若后续要形成摄食事件，必须声明单次处理质量、成功条件与事件唯一生产者，再做质量账本。

不新增顶层系统、不偷偷使用人口迁移。若生产响应的既有含义已经覆盖觅食投入，应在其内部承接或拒绝此模型，不能再加一层独立乘数。GenericFCF与ProposalCOpportunity接口依旧待对应Owner确认。

## 6. 玩家选择与待证条件

- 好闻但无食物：可能获得线索语境，不保证维持食物支持的觅食投入。
- 少量可处理食物：若a效应成立，可以提高钩饵尝试窗口。
- 大量易处理免费对象：处理时间占用增加，补窝不一定值得。
- 食物太硬、太大或在错误水层：不应算作有效支持x，也不能既加a又不付任何处理代价；具体过滤须由动作模型产生。
- 不同钩饵处理时间：k影响占用，不能拿它当任意平衡惩罚，必须有对象处理依据。

关键证据缺口已经收窄为：是否存在可复核的“可兑现食物提高觅食投入”过程，以及其对不同对象/鱼种的适用条件。当前没有真实物种证据，不为欧鳊、鲫/鲤填参数。玩家观测应采用固定钩饵、线索和地点、只改变可处理食物的重复时间对照，区分线索效应与食物效应。

当前推荐：保留该时间预算模型作为食物正价值的优先实验，替代匿名背景奖励的研究方向；不批准为生产机制。它使下一轮能明确验证一个独立后果，而不是继续为纯Cue加罚或给主料加分。
